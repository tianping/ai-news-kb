## 概述

广东省智能科学与技术研究院、香港理工大学等团队发表了对话式多智能体系统 CopilotJ。研究者用自然语言描述任务，Agent 先读取 Fiji/ImageJ 的软件状态，给出计划，用户确认后执行宏与插件。分析结果被接受后，可以保存成**不再调用 LLM 的工作流**，用来批量重放。

## 演示：肾小球定量

- 输入：一张 8-bit 灰度肾脏图像；要求分割肾小球，输出掩膜、计数和汇总表
- CopilotJ 先读图像元数据，查本地保存的分析方法与操作知识，再给出计划：复制图像 → 减背景 → Otsu 暗背景阈值分割 → Analyze Particles 计数和测量 → 画统计图
- **用户确认计划后才执行**。阈值和步骤会直接影响分割结果，需要先核对

## 架构

- **四个 Agent**，都按 ReAct 循环工作（想一步、做一步、看结果、再修正）：
  - **Leader**：理解意图、拆步骤、分派任务、校验结果
  - **Kernel**：通过 Bridge 连接 ImageJ，查询会话、元数据、ROI 和运行状态，执行菜单命令、插件和宏
  - **Research**：查 Fiji/ImageJ 文档和 Image.sc 论坛等社区资料
  - **Enhancement**：调用 Python 库和 Cellpose 等分割模型，结果写回磁盘再载入 ImageJ
- **CopilotJ Bridge 插件**：装在 Fiji 里，通过 WebSocket 与后端双向通信
  - 读给 Agent：图像尺寸、通道、位深、标定、窗口状态、ROI、操作历史
  - 接收 Agent 发来的宏和命令，在 ImageJ 里执行
  - 意义：只靠截图和鼠标点击，Agent 很难知道图像是 8-bit 还是 RGB，也看不到插件报了什么错；Bridge 把这些变成可查询的数据
- **自反思**：报错时读日志和 ImageJ 错误信息，修改参数、命令语法或步骤顺序后重试（补充图 10：修正 RGB 通道合并宏的参数结构错误后重跑成功）
- **视觉检查**：多模态模型查看截图，检查中间结果，评估亮度、对比度和噪声
- **人机协作**：遇到没有宏接口的插件或需要人判断的地方会停下，用户手动改参数或画 ROI 后，Agent 读取工作区状态再继续

## 可复用工作流

- 存成 JSON 或 Markdown。每一步记录工具、参数、可执行的宏或 Python 脚本，以及输入输出接口（肾小球例子：rolling=50、Otsu 暗背景阈值、颗粒大小 5–500 像素²）
- 重放时脚本原样交给解释器执行，**不经过 LLM**。可以在 CopilotJ 里用一条指令触发，也可以从命令行独立运行；支持整目录批量执行，可导出成 ZIP 或 Markdown 分享
- 补充图 2：对 20 张切片逐张执行，结果按图像分文件夹存放，最后生成带图表和统计的报告
- 注意：换了染色、成像模态或像素标定，原来的阈值和颗粒大小未必合适，需要重新确认

## 评测（三组）

| 测什么 | 设计 | 结果 |
|---|---|---|
| 任务完成稳定性 | 5 项任务（凝胶电泳、细胞划痕、基础图像操作、批量后处理、肾小球）× 3 个底层模型（Gemini 2.5 Pro、GPT-4.1、GLM 4.6）× 每组合重复 15 次；成功指生成预期输出，不要求步骤顺序一致 | 汇总完成稳定率 84%–93%；个别任务与模型的组合低于 84% |
| 细胞计数准确性 | BBBC004（20 张）、BBBC005（200 张）、BBBC031（216 张）合成图像，均有真值；提示词固定，过程中不人工干预 | 计数与真值完全一致的比例：55.0% / 78.5% / 53.2%；误差集中在 0 附近，三组分布不同 |
| 操作成本 | 10 名参与者（新手 + 有经验用户），五项任务各限时 30 分钟；CopilotJ（Gemini 2.5 Pro）对比「问 ChatGPT-5.2 + 手动操作 ImageJ」 | CopilotJ 完成时间更短、交互次数更少 |
