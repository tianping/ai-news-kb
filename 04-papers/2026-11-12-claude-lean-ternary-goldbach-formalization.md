## 一句话

独立开发者 Charlie Reams 用 Claude Code，把 Helfgott 2013 年的三元哥德巴赫猜想证明完整翻译成 Lean 4（约 19.4 万行，含脚本和文档），**零 sorry**；过程中发现原证明 11 处与书不符的地方并修好，证明仍然成立，只是余量小了很多。

## 背景

- **三元（弱）哥德巴赫猜想**：任何大于 5 的奇数都能写成三个质数之和。注意不是“1+1”（强哥德巴赫，至今未证）
- 2013 年秘鲁数学家 **Harald Helfgott** 宣布证明，主干手稿约 300 页，满是不等式放缩和常数计算，后来他自己又修订了好几版；几乎没人有精力逐个核对常数
- 方法是**圆法**：主弧是“收入”，劣弧是“开销”，收入稳稳大于开销，定理就成立

## 分工

- Reams：定顶层目标、拆任务
- Claude Code：绝大部分 Lean 代码、自动化脚本和文档
- **零 sorry**：Lean 里 sorry 表示“这步先跳过”；零 sorry 意味着每一步推理都过了机器检查

## 找到的问题（README 列了 11 处，文中挑了几个）

| 位置 | 问题 | 处理 |
|---|---|---|
| 式 (6.77) | 关键常数写成 0.5，正确应为 0.8102 | 连带修正后项目最终用 0.8764 |
| 式 (5.32) | v=2 时不成立：积分实际 0.53344，超过书中上界 0.37273·log 4 ≈ 0.5167 | 修正 |
| 引用 Ramaré 1995 论文的一步 | 声称某乘积 ≤ 8，实际约 8.0845（原论文 (3.9) 式本身是错的） | 换一种拆法绕开，得到 7.04，仍在所需的 7.284 以内 |
| 定理 13.2.1 | 把两种尺度的主弧混在一起 | 这段重新搭了一遍 |

**修完后的账**：

| | 原书 | 修正后 |
|---|---|---|
| 主弧“收入” | 1.058259 | 1.049 |
| 劣弧“开销” | 1.00948 | 1.0376 |
| 安全垫（差值） | 0.04877 x²/κ | 0.0114 x²/κ |

安全垫缩水四分之三以上，**但仍大于零**——定理依然成立。

## 原作者回应与剩余前提

- Helfgott 在 X 上回应、态度坦诚；Reams 早在 **10-04** 就私下告诉他形式化已跑通
- 此后一个月，外部假设从 5 项砍到 **2 项**，均为已发表的数值验证结果：
  1. **PlattGRH**：Platt 的广义黎曼猜想数值验证
  2. **BinaryGoldbachInput**：偶数哥德巴赫猜想验证到 4×10¹⁸
- 解析数论推导部分 100% 形式化；这两块“人类早已算好的巨型数字”还没搬进 Lean 内核，作为显式前提挂在外面

## 核实补充（非原文，2026-11-12 查看仓库 README）

- README 确认：证明完成、无 sorry，主定理只用 Lean 标准三公理，另以 PlattGRH 和 BinaryGoldbachInput 作为显式假设；依据的是 Helfgott 的 arXiv:1501.05438v2
- **n ≥ 10²⁷ 的情形只需要 PlattGRH**，不需要偶数哥德巴赫验证；10²⁷ 以下才用到 4×10¹⁸ 的验证
- Ramaré 的 Möbius 界 0.03/log x 已从 PlattGRH 推出（不再是额外假设），所用的是 **Helfgott 自己和 Claude 一起做的 RSBounds** 形式化（2429 个模块原样引入）——所以原作者本人也参与了“用 Claude 形式化”这件事
- README 写明 Ramaré 1995 论文 (3.9) 式不成立，项目绕开了它（HYPOTHESES.md Finding 5），与文章一致
