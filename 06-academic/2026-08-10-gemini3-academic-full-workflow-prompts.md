# Gemini 3.0 学术指令集：从选题到返修全流程

## 一句话简介

适配 Gemini 3.0/3.1 Pro 的学术指令集，覆盖论文完整流程：选题→文献→大纲→各章节撰写→图表→润色→返修→参考文献。每条指令独立可直接发送给 Gemini。

## 使用说明

- 【】内文字自行替换为你的课题信息
- 全部指令适配 Gemini 3.0/3.1 Pro
- 每条指令独立可直接发送

## 一、前置角色与课题调研

### 指令 1 | 学术专家基础角色设定

```
你是【你的学科方向】领域资深研究员、SCI 期刊审稿人。全程遵守学术规范，杜绝虚假引用、主观臆断。输出逻辑严谨、语言客观，所有观点尽可能标注文献来源；禁止编造不存在论文。后续所有对话统一沿用该身份。
```

### 指令 2 | 研究课题可行性分析

```
课题名称：【粘贴论文题目】。帮我全面评估选题可行性。输出结构：
1. 领域研究热度
2. 现存研究空白
3. 潜在创新切入点
4. 研究难点
5. 适合投稿期刊梯队
6. 建议的检索关键词组合
```

### 指令 3 | 检索式构建

```
研究主题【粘贴主题】，生成 5 套中英文高级文献检索布尔表达式，适配 Google Scholar、Web of Science、中国知网，区分宽泛检索与精准检索，标注检索时间范围建议。
```

### 指令 4 | 批量文献精读摘要提取

```
我将上传多篇文献PDF，请对每篇文献输出结构化笔记：
1. 核心研究问题
2. 研究方法
3. 关键结论
4. 研究局限性
5. 和我的课题【粘贴课题】关联点
以表格形式输出。
```

### 指令 5 | 文献观点对比矩阵

```
基于我提供的多篇文献，构建对比表格：作者年份、研究方法、样本/实验条件、核心结论、观点共识、观点冲突、研究缺陷，清晰展示领域内争议。
```

### 指令 6 | 自动挖掘研究Gap

```
汇总以上所有文献信息，系统性梳理现有研究局限，列出至少5个可行研究缺口，区分：已被部分研究关注、完全未被探索、存在结论矛盾三类缺口。
```

### 指令 7 | 开题报告完整大纲生成

```
课题【论文题目】，生成硕士/博士开题报告标准大纲，包含：研究背景与意义、国内外研究现状、研究内容、研究思路与技术路线、研究方法、创新点、进度安排、参考文献清单框架。
```

### 指令 8 | 论文标题批量生成

```
基于课题【主题】，生成15个中文标题+15个英文标题，分为偏综述型、偏实证实验型、方法创新型三类，每个标题附带简短优势说明。
```
