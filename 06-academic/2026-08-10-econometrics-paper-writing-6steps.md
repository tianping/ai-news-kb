# 经管实证论文写作6步法：从选题到结论的完整 Prompt 集

> 来源：[经管实证论文怎么写？把这6步走通，逻辑也就顺了](https://mp.weixin.qq.com/s/ZOeijfkijojBKbEuDsAHKg) · 2026-08-10

## 一句话简介

把经管类实证论文拆解为选题→文献综述→构建模型→获取数据→实证分析→结论升华6个步骤，每步配一个可直接使用的 Prompt 模板。

## 六步流程

### 01 慎重选题

**要点**：两个选题思路——追热点（AI、数字经济、ESG等新兴议题×经管问题）或找"反差"（经典理论与现实表现的差异）。最大坑：选好题目先确认能不能找到数据。

```
我准备撰写一篇经管类实证论文，研究领域为【填写研究领域】，目前关注的现实问题或研究方向为【填写】。请结合当前具有研究价值的议题，如人工智能、数字经济、ESG、绿色金融、企业创新或公司治理等，提出5个具有可行性的论文选题。

选题可以从以下两个方向展开：
- 将新兴议题与金融、会计、管理或经济问题相结合
- 寻找经典理论与现实表现之间的差异，或识别现有研究尚未充分解释的问题

请对每个选题分别说明：核心研究问题、可能的理论依据、自变量和因变量、研究创新点、可获得的数据来源、数据获取难度、实证研究的可行性。

优先推荐数据能够从CSMAR、Wind、国家统计局、上市公司年报或其他公开数据库中获得的题目。避免推荐研究范围过大、变量无法测量或缺乏数据支持的选题。
```

### 02 文献综述

**要点**：不要写成"谁说了什么"的流水账，核心是梳理研究脉络、总结不足、引出切入点。

```
请围绕论文主题【填写论文题目或研究问题】，系统梳理相关中英文文献。不要按照"某位作者提出了什么"的方式逐篇罗列，而应根据研究问题、理论视角、研究方法、变量关系和研究结论进行分类整合。

请完成以下任务：
- 概括该领域的主要研究脉络
- 总结现有研究已经形成的主要共识
- 分析不同研究之间的结论分歧及其可能原因
- 比较现有研究采用的数据、样本和研究方法
- 指出现有研究尚未解决的问题
- 从文献不足中自然引出本文的研究切入点和潜在创新

引用的文献必须真实、可核验，不得虚构作者、题目、期刊、年份、数据或研究结论。最终形成一篇具有跨文献整合能力的文献综述，而不是文献摘要的简单拼接。
```

### 03 构建模型

**要点**：定义变量、选择模型（面板数据用固定效应，政策评估用DID），确保变量关系、理论假设和实证模型一致。

```
我的论文主题是【填写题目】，拟研究【填写核心变量关系】。请帮助我构建完整的实证研究设计，具体包括：
- 明确核心自变量、因变量、中介变量、调节变量和控制变量
- 对各变量进行概念界定和可操作化说明
- 推荐变量的常见测量方法和数据来源
- 根据研究问题提出具有理论依据的研究假设
- 构建基准回归模型，并解释模型中各项参数的含义
- 判断是否适合使用固定效应、随机效应、双重差分法、工具变量法、中介效应模型或其他方法
- 说明模型选择的理由、适用条件和潜在局限
- 检查变量关系、理论假设和实证模型之间是否保持一致

研究设计应参考同类高质量论文，但不能机械照搬。对于缺乏理论依据或数据支持的变量，不要强行加入模型。
```

### 04 获取数据

**要点**：经管数据通常来自CSMAR、Wind、国家统计局。拿到数据先清洗（缺失值、缩尾处理、异常值剔除）。

```
我的研究主题是【填写】，研究对象为【填写】，样本期间为【填写】，需要使用的核心变量包括【填写】。请为我制定一套数据获取与清洗方案，具体包括：
- 推荐适合的数据来源（CSMAR、Wind、国家统计局、上市公司年报等）
- 说明每个变量对应的数据来源和获取方式
- 明确样本筛选标准和排除规则
- 识别可能出现的缺失值、重复值、异常值和口径不一致问题
- 提出缺失值处理方案
- 判断是否需要进行缩尾处理、标准化、对数化或滞后处理
- 说明极端值处理的合理依据
- 给出可在Stata、SPSS、Python或Excel中执行的数据清洗步骤
- 建立变量名称、变量定义、计算方式、单位和数据来源对应表
- 检查数据处理是否可能引入样本选择偏误

不得随意填补或虚构缺失数据。所有数据处理规则都应保留记录，以保证研究过程可以复现。
```

### 05 实证分析

**要点**：描述性统计→相关性分析→回归分析→稳健性检验→机制检验→异质性分析。区分统计显著性与经济意义。

```
请根据我的论文主题【填写】、研究假设【填写】和数据文件【上传或说明】，设计并执行完整的实证分析流程。分析内容包括：
- 描述性统计
- 相关性分析
- 多重共线性检验
- 基准回归分析
- 固定效应或随机效应模型选择
- 内生性检验
- 稳健性检验
- 机制检验
- 异质性分析

请重点完成以下工作：
- 解释变量的均值、标准差、最小值和最大值
- 判断变量之间是否存在较强相关性或多重共线性
- 解释回归系数的方向、大小和统计显著性
- 检查结果是否支持研究假设
- 分析可能存在的反向因果、遗漏变量和测量误差
- 根据研究条件选择工具变量法、滞后变量法、倾向得分匹配或其他内生性处理方法
- 通过替换变量测量方式、调整样本范围、改变模型设定或剔除特殊样本进行稳健性检验
- 区分统计显著性与经济意义，不要只根据P值下结论

请同时提供可执行的Stata或SPSS操作步骤，并对每项结果进行规范、谨慎的学术解释。不得捏造回归结果或将不显著结果强行解释为显著。
```

### 06 结论升华

**要点**：不只重复数字，要解释结果意味着什么、与理论对话、提炼贡献和实践启示。

```
请根据论文主题【填写】、理论假设【填写】和实证结果【填写或上传】，撰写论文的研究结论、讨论与政策启示部分。请完成以下内容：
- 概括主要研究发现，但不要简单重复回归表中的数字
- 说明研究结果是否支持原有假设
- 将研究结果与理论基础和既有文献进行对话
- 解释结果背后的可能作用机制
- 对不符合预期或不显著的结果进行谨慎分析
- 提炼论文的理论贡献
- 提炼论文的现实意义
- 分别提出对企业管理者、投资者或政策制定者的建议
- 说明研究的数据、样本、变量和方法局限
- 提出具有可操作性的未来研究方向

讨论部分应重点回答"为什么会得到这一结果""这一结果与已有研究相比增加了什么认识""这一结果在什么条件下成立"。避免使用"首次发现""填补空白""完全证明"等绝对化表述。政策建议必须由实证结果支持，不能超出论文证据范围。
```

## 常见踩坑提醒

- **理论基础要扎实**：别光堆砌理论而不结合问题
- **数据绝对不能造假**：这是底线
- **学术规范**：引用文献格式一定要对
