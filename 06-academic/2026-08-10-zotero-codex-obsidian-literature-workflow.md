# Zotero + Codex + Obsidian 文献阅读工作流

> 来源：[Zotero + Codex + Obsidian：一套可复用的文献阅读工作流](https://mp.weixin.qq.com/s/d8HHqaM4Be8pay8j8M3p2g) · 2026-08-10

## 一句话简介

把 Zotero（文献收藏与批注）、Codex（结构化整理与笔记生成）、Obsidian（知识沉淀与索引）串联成一条稳定的文献阅读工作流，让每篇论文按统一标准进入个人学术知识系统。

## 工具分工

| 工具 | 职责 |
|------|------|
| Zotero | 文献收藏、元数据管理、PDF 阅读与批注 |
| Codex | 检索文献、整理内容、生成结构化笔记 |
| Obsidian | 长期保存笔记、维护标签与文献索引 |

## 完整流程

### 01. 在 Zotero 中整理目标文献

Zotero 是文献入口和证据来源。阅读时重点标记：
- 研究背景、概念定义、理论基础、核心观点、作用机制

批注不需要很长，说明用途即可：
- 【可用于文献综述中的研究背景】
- 【这里解释了数字化影响商业模式创新的作用机制】

### 02. 链接 Zotero 与 Codex

1. 打开 Zotero 桌面端 → 设置 → 高级 → 勾选【允许使用计算机上的其他应用程序与 Zotero 通讯】
2. 退出并重新打开 Zotero
3. 在 Codex 中验证连接：`请检查 Zotero 是否已经连接。`

连接成功后，Codex 可检索 Zotero 文献，并在全文已建立索引的情况下读取正文。

### 03. 在 Codex 中检索并选择论文

**搜索文献：**
```
请在 Zotero 中搜索【目标目录】。列出匹配文献的题目、作者、年份和 Zotero 条目编号，暂时不要进行内容分析。
```

**读取指定文献：**
```
请读取 Zotero 条目 ABCD1234，获取文献基本信息、附件和可用全文。
```
> 使用 Zotero 条目编号可避免同名或相似题目导致误匹配。

### 04. 让 Codex 生成结构化精读笔记

不要只输入"帮我总结这篇论文"——普通总结缺少稳定结构。使用固定模板：

```
请根据 Zotero 中这篇论文的全文和我提供的批注，生成一份中文 Markdown 精读笔记。

笔记包括：
1. 文献基本信息
2. 研究背景
3. 核心研究问题
4. 主要概念
5. 理论基础
6. 核心观点与作用机制
7. 研究设计与研究方法
8. 主要研究结论
9. 理论贡献
10. 实践启示
11. 研究局限
12. 可用于文献综述的内容
13. 后续需要继续思考的问题

写作要求：
- 区分作者观点与个人批注
- 不补充原文中没有的信息
- 不将相关关系直接表述为因果关系
- 证据不足的内容标记为"待复核"
- 保留重要概念在原文中的定义
```

**生成后检查不确定内容：**
```
请列出这份笔记中所有标记为"待复核"的内容，并说明需要回看论文的哪个部分。暂时不要修改笔记。
```

研究者返回 Zotero 查看原始 PDF，确认后再补充给 Codex。

### 05. 将笔记写入 Obsidian

**目录结构：**
```
Research Vault
├── 01 文献笔记
├── 02 主题笔记
├── 03 理论笔记
├── 04 文献索引
└── 05 模板案例
```

**保存笔记：**
```
请将确认后的精读笔记保存到：
01 文献笔记/数字经济背景下企业商业模式创新研究.md
```

**验证保存：**
```
请重新读取刚才保存的 Markdown 文件，确认中文编码、标题层级和 YAML 区域是否正常。
```

### 06. 维护 Literature Index

在 Obsidian 中创建 `04 文献索引/Literature Index.md`，然后：

```
请将当前文献加入 Literature Index。
记录以下信息：
- 年份
- 论文题目
- Obsidian 双向链接
- 研究主题
- 理论基础
- 研究方法
- 一句话定位

如果索引中已经存在该文献，不要重复添加。
```

**索引格式：**

| 年份 | 文献 | 研究主题 | 理论基础 | 一句话定位 |
|------|------|----------|----------|------------|
| 待填写 | [[数字经济背景下企业商业模式创新研究]] | 商业模式创新 | 动态能力理论 | 解释数字化推动企业商业模式创新的作用机制 |

**检查重复：**
```
请检查 Literature Index 中是否已经存在重复文献，并确认当前笔记的 Obsidian 链接可以正确匹配文件名。
```

## 日常使用流程

每处理一篇论文，按以下顺序操作：

1. 在 Zotero 中整理论文、标签和批注
2. 让 Codex 搜索并读取指定 Zotero 文献
3. 让 Codex 按照固定框架生成精读笔记
4. 将 Markdown 笔记保存到 Obsidian
5. 根据现有标签库确定标准标签和候选标签
6. 更新 Literature Index，并检查是否重复

## 核心理念

> 这套工作流不是让 AI 替代研究者阅读论文，而是将文献获取、内容整理、笔记保存和知识管理连接成一条稳定、可重复的研究流程。

当每篇论文都按相同标准进入 Obsidian 后，文献库从 PDF 存储空间变成支持文献检索、理论比较、综述写作和研究问题识别的个人学术知识系统。
