# 科研数据"活数据"管理：让AI能读懂、能复算、能继续追问

> 来源：微信公众号文章 · 2026-08-11 · [原文链接](https://mp.weixin.qq.com/s/QTGgjHeodvcPtDwYOjtnEg)

## 核心观点

科研数据的真正价值不在于"存下来"，而在于整理成人和AI都能读懂、能复算、能继续追问的"活数据"资料库。文章提出5条原则和一套可落地的实操流程。

## 五条原则

### 原则1：保存好原始观测
- 原始观测是项目里最安静的一层：**只读、带时间戳、留哈希、多备份**
- 不能被 Agent 顺手清洗，更不能为了让结果好看而覆盖
- 一个 CSV 能被模型读进上下文 ≠ 它已经"机器可用"

### 原则2：一次研究 ≠ 文件夹里的一堆文件
- 典型"死数据"：只有 `final.csv`、`final_v2.csv`、`notes.txt`，缺单位、缺样品表、缺来源、缺处理链
- "活数据"应包含：原始数据、样品信息、字段说明、分析脚本、开放问题和入口说明
- 参考 **RO-Crates** 标准：元数据、源码、input、output 全打包在一起
- 核心原则：**不要让 AI 只能靠文件名猜关系**

### 原则3：给 AI 一个入口，不要让它翻垃圾堆
- 给 Agent 生成 `AGENTS.md`，说明：
  - 哪些目录只读
  - 哪些脚本可以跑
  - 测试命令是什么
  - 哪些问题还没回答
  - 哪些结论不能越界

### 原则4：旧数据也能在新模型时代升值
- 案例：NSF 蛋白质数据库（PDB）跨越半个世纪，后来成为 AlphaFold 训练的关键资源
- 数据今天的价值 ≠ 它一生的价值
- 前提：留下的不只是结果，而是能让 AI 重新进入研究现场的指南

### 原则5：新模型来了，先复现，再追问
- 保留"重用问题集"，分两类：
  1. 旧模型必须答对的已知问题（复现验证）
  2. 过去没能力处理的开放问题（新模型追问）
- 每次重放都要留记录：模型版本、工具版本、读取数据、运行代码、结果沿用/被推翻、审查意见

## 实操流程：七步建立活数据资料库

1. 原始数据单独放好，设为只读，生成 SHA-256 哈希清单
2. 制作样品表（sample_id、batch、group、instrument、condition、缺失值规则）
3. 制作数据字典（每列含义、单位、allowed values）
4. 把论文里最重要的图改成脚本可重跑
5. 留一个已知答案测试，确认重跑不跑偏
6. 写两份入口文档：`README.md`（给人看）+ `AGENTS.md`（给 AI 找入口）
7. 建两个小目录：`decisions/`（为什么这么做）+ `questions/`（还有什么没答完）

## 推荐目录结构

```
项目根/
├── data/raw/              # 原始数据（只读）
├── metadata/               # 样品表等元数据
├── schemas/                # 数据字典
├── reports/                # 审计报告
├── src/                    # 可重跑脚本
├── tests/                  # 完整性测试
├── decisions/              # 决策记录
├── questions/              # 待答问题
├── replays/                # 复现记录
├── README.md               # 人类入口
└── AGENTS.md               # AI 入口
```

## 信息优先级表

| 信息 | 是否必需 | 作用 |
|------|----------|------|
| 原始数据.csv | 必需 | 建立原始数据基线 |
| 研究课题 | 建议提供 | 说明项目大方向 |
| 研究问题 | 建议提供 | 决定后续分析目标 |
| 一行数据代表什么 | 强烈建议 | 判断样品/时间点/观测单位 |
| 每列含义和单位 | 可稍后补充 | 建立数据字典 |
| 样品ID、批次、分组 | 可稍后补充 | 建立样品表 |
| 仪器与实验条件 | 可稍后补充 | 恢复实验语境 |
| 缺失值规则 | 强烈建议 | 区分"未测"/"低于检出限"/"无效" |
| 纳入、排除和清洗规则 | 可稍后补充 | 保证分析可复现 |
| 关键图或预期结果 | 后续需要 | 建立复现脚本和科学测试 |

## 附：AI 提示词模板

文章附赠了一个完整的提示词模板，用于在只有 `原始数据.csv` 的情况下，让 AI 自动构建完整的活数据资料库。提示词覆盖：

- 目录创建与原始数据保护（SHA-256 哈希）
- 数据审计（类型、缺失值、分布、重复行、疑似日期/ID 字段）
- 可重跑脚本生成（`profile_data.py`）
- 数据字典模板（`data_dictionary.csv`）
- 样品表模板（`samples.csv`）
- 自动测试（`known_answers.json` + `test_data_integrity.py`）
- 双入口文档（`README.md` + `AGENTS.md`）
- 决策记录与问题追踪
