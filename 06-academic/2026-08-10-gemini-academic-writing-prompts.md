# Gemini 学术写作助手：8步指令集

> 来源：[用Gemini做学术写作助手](https://mp.weixin.qq.com/s/XIQr2wVxu6QuAE4SGCCzbg) · 2026-08-10

## 一句话简介

按照论文写作流程（标题→摘要→大纲→写作指导→续写→纠错→润色→评审）整理的8个 Gemini 学术指令模板，直接复制即可使用。

## 八步指令

### 01 标题生成
**作用**：根据摘要和关键词生成简洁、明确、有学术信息量的标题。

```
你是一名学术期刊编辑。请根据我提供的论文摘要和关键词，为这篇论文生成 5 个中文标题。要求：
1. 标题必须简洁、清晰、有信息量。
2. 避免使用 "A study of..." "Investigation of..." "Development of..." "Observations on..." 这类空泛表达。
3. 标题要能准确体现研究对象、核心方法或主要发现。
4. 每个标题后请用中文解释它为什么好。
5. 请用 Markdown 表格输出，表格包含两列：中文标题、中文解释。

论文摘要：【粘贴摘要】
关键词：【粘贴关键词】
```

### 02 摘要撰写
**作用**：生成结构完整的学术摘要，覆盖背景、问题、方法、结果和贡献。

```
你是一名学术研究专家。请根据我提供的论文内容，为这篇论文撰写一段中文摘要。摘要需要包含以下结构：
1. 研究背景：说明该研究所处的 broader context。
2. 研究空白：指出当前研究中存在的 gap、limitation 或 unresolved issue。
3. 研究方法：简要说明本文采用的方法、数据、模型或分析框架。
4. 主要发现：用 3-5 句话概括核心结果。
5. 研究贡献：最后用一句话强调本文的 unique value 或 significant contribution。

要求：
- 使用正式、清晰、简洁的学术英语。
- 不要夸大研究贡献。
- 不要添加原文没有支持的信息。
- 摘要完成后，请用中文表格说明你是否覆盖了以上 5 个部分。

论文内容：【粘贴论文内容或主要信息】
```

### 03 论文大纲
**作用**：帮助搭建完整论文框架，明确每一部分写什么。

```
你是一名学术研究专家。请围绕以下研究主题，为我设计一份结构完整的论文大纲。
研究主题：【填写研究主题】

请按照以下结构输出：
1. Introduction
   - 研究背景 / 核心问题 / 研究意义 / 本文研究目标
2. Literature Review
   - 现有研究主要观点 / 已有研究不足 / 本文如何补充现有文献
3. Methodology
   - 数据来源 / 研究方法 / 变量设计或模型设定 / 分析步骤
4. Results
   - 主要发现 / 关键证据 / 稳健性或补充分析
5. Discussion
   - 结果解释 / 理论意义 / 实践意义
6. Conclusion
   - 研究结论 / 研究贡献 / 局限性 / 未来研究方向

要求：
- 每个部分都要写出具体内容，不要只给空标题。
- 大纲要体现研究逻辑：问题如何提出，方法如何回答问题，结果如何支撑结论。
- 请用中文输出。
```

### 04 写作导师
**作用**：让 Gemini 扮演领域专家，提供学术写作建议而非代写。

```
请你扮演一名【填写具体领域】领域的学术写作导师。接下来，我会向你提出论文写作过程中遇到的具体问题。你的任务不是直接替我完成整段论文，而是教我应该如何写。

当我提出问题后，请你按照以下方式回答：
1. 先判断这个问题属于论文写作中的哪一类问题（引言写作、文献综述、研究问题、方法描述、结果分析、讨论、结论等）
2. 告诉我具体写作思路（先写什么、再写什么、最后写什么）
3. 给出示范表达（提供若干句可参考的学术表达，但不要直接替我编造具体研究内容）
4. 提醒我常见错误（最容易写错在哪里，如何避免）

请注意：
- 以"教我怎么写"为主，不要直接替我写完整内容。
- 不要编造研究数据、结论或文献观点。
- 回答要清楚、具体、可执行。

我的写作问题是：【在这里输入你的问题】
```

### 05 论文续写
**作用**：基于已有内容继续扩写，保持研究方向。

```
请基于我已经写好的论文内容，继续续写后面的部分。要求：
1. 保持原文的研究主题和论证方向。
2. 不要引入与主题无关的新内容。
3. 扩写时要补充逻辑、证据、解释和学术表达。
4. 语言风格要正式、清晰，符合学术论文写作。
5. 如果原文中某个观点论证不足，请自然补充解释。
6. 如果适合，请增加过渡句，让上下文衔接更顺畅。

我的研究主题是：【填写研究主题】
已有内容：【粘贴已有段落】
请从这段后面继续写。
```

### 06 错误纠正
**作用**：纠正 AI 的理解偏差，让它基于补充条件重新回答。

```
请注意，你刚才的回答存在理解偏差。
问题不在于：【说明 AI 错误理解的地方】
真正需要处理的是：【说明正确问题】
请你基于我的补充说明，重新回答上一个问题。要求：
1. 不要重复刚才错误方向的内容。
2. 回答必须围绕我现在补充的重点展开。
3. 如果原答案中有可保留的部分，请保留并调整。
4. 输出前请先用一句话说明你现在理解的任务是什么。

我的补充说明：【填写补充信息】
```

### 07 润色
**作用**：提升论文的学术严谨性、清晰度和可读性。两版指令：

**期刊/会议风格：**
```
请你扮演一名熟悉【填写目标期刊/会议名称】写作风格的学术编辑。参考该期刊/会议常见论文的表达风格，对文本进行润色。请重点优化：
1. 是否符合该期刊/会议的学术表达习惯。
2. 句子是否清晰、正式、自然。
3. 术语使用是否准确。
4. 逻辑衔接是否顺畅。

输出格式：
1. 先给出润色后的完整版本。
2. 再用中文说明你主要做了哪些风格调整。
3. 如果原文中有不适合该期刊/会议风格的表达，请指出并说明原因。

目标期刊/会议：【填写期刊或会议名称】
需要润色的文本：【粘贴文本】
```

**SCI风格：**
```
请你扮演一名 SCI 论文语言润色编辑。请重点改进：
1. 语法错误 2. 拼写错误 3. 句子结构 4. 学术正式度
5. 逻辑连贯性 6. 表达简洁性 7. 用词准确性

输出格式：
1. 先给出润色后的完整段落。
2. 再用 Markdown 表格列出修改说明（原句 | 修改后句子 | 修改原因）。

需要润色的文本：【粘贴文本】
```

### 08 评审
**作用**：让 AI 以论文评审专家身份审稿。

```
请你扮演一名【填写领域】领域的论文评审专家，从审稿人的角度评估下面这篇论文草稿。请不要直接全文重写，而是逐项指出问题。请从以下方面评审：
1. 研究问题是否清晰、有价值。
2. 论文结构是否合理。
3. 文献综述是否充分。
4. 方法设计是否严谨。
5. 数据或证据是否足够支持结论。
6. 论证逻辑是否连贯。
7. 语言表达是否符合学术规范。
8. 结论是否存在过度推断。

输出格式：
1. 总体评价：简要说明论文目前的优点和主要问题。
2. 主要问题：列出需要优先修改的地方。
3. 具体修改建议：每个问题都给出修改方向。
4. 可直接替换的示范文本：如果某处表达有问题，请给出修改示范。
5. 修改优先级：标注为"必须修改 / 建议修改 / 可选优化"。

论文草稿：【粘贴论文内容】
```

## 使用方式

直接复制对应指令到 Gemini 对话框，替换【】中的占位内容即可。
