## 一句话

不走扩散采样，而是让模型输出**可执行程序**，程序再渲染成视频：每一帧都是时间 t 的纯函数，同一份代码永远渲染出同一支片子。27B 参数、512K 上下文、基于 Qwen3.8-27B 微调。

## 为什么走代码这条路

生成模型的三个短板（官方对比）：
- **缺乏物理依据**：学到的是世界"看起来"怎样，不是"如何运作"
- **难以修改**：大小、时间、轨迹都藏在采样过程里，想改一个细节只能重写 prompt 重新采样，没要求改的画面也会跟着变
- **内容不精确**：文字、公式、图表最容易错

代码的四个长处：元素都是有名字的对象所以好改；文字逐字排版、数值可逐项对照；运动碰撞光线由方程算；一处改动只重渲染受影响的部分。

**最关键的一条是可复现**——官方的翻牌屏对照实验：同一份工程改三轮（暗色机场屏 → 粉彩酒店大堂 → 加飞机和旅客），没被点名的文字、时序、翻牌动作全部原样保留；换成生成模型，这三轮就是三次重新采样，第二版里那行字可能已经换了字体。

## 做什么、不做什么

**只做完全由代码实现的短视频**：动态图形、科普讲解、风格化 2D/3D 场景、程序化音频。**写实拍摄画面不做**。

仓库放了九支带声音的成片（滑坡地形剖面、傅立叶光绘、字形实验、等距书店、黄金螺旋、机器人与小夜灯等），共同点是没有一支实拍风格——**能被写成规则的东西才交给代码**，这是选片标准不是巧合。

最稳的两档是科普讲解（公式和概念不能错）和动态图形（片头、字幕、品牌动效，改字号颜色节奏都是改一个数字）。

## 部署与配置（坑都在这）

- LightLLM / vLLM / SGLang 三套现成命令，均为四卡张量并行、512K 上限
- **两个解析器要一起配**：`--reasoning-parser qwen3` 管思考、`--tool-call-parser qwen3_coder` 管工具调用，少配一个 agent 跑不起来
- 官方推荐 harness 是 Claude Code，但**必须手动改五个配置**，否则 Claude Code 会把未知模型当成 200K 上下文：上下文窗口 524288、自动压缩阈值 80%、最大输出 65536、`--max-turns 2000`、timeout 10h
- 依赖：Node 18+、Python3、ffmpeg、Playwright chromium、中文字体
- 把 `skills/code-video` 复制到任务目录的 `.claude/skills/` 并重启 agent

512K 不是为了塞长文档，是为了撑住一次几小时的制作循环：写代码 → 渲染 → 看画面 → 再改。官方实测可连续跑超 10 小时、超 2000 轮。

## 工作流

四步闭环（写在 code-video skill 里）：
1. 写规格，把模糊需求落成可检查的 SPEC
2. 把每一帧写成时间的函数并渲染
3. **把联系表（contact sheet）当图像读回去自己检查** ← 生成模型做不到的闭环
4. 验收交付 final.mp4、SPEC.md、VERIFY.md、联系表、源码和复现命令

八份领域指南：科普讲解、风格化画面、模拟与生成、角色动画、3D 场景、动态图形、声音与旁白、音乐卡点。

**两段式 prompt**：一句话需求直接丢进去出不来好片子。先用仓库模板生成 `request.md`，交给 Claude Opus 5.5 这类强模型扩成 `dense_prompt.md`，再交给 Code2Video 按 skill 干活。官方承认模型自带的 prompt 增强效果比较基础，用更强的模型扩写成片美学明显更好。

## 代价与局限（官方自己列的）

- 渲染本身不贵，贵的是 **agent 时间**：一次制作仍需数小时
- 只做得了能写成代码的视频，写实画面不行
- 成本高且依赖 harness，结果直接受上下文长度、压缩阈值、输出上限影响
- **没有评测基准**，目前只有定性示例，官方承认这是开放问题
- 与最强闭源模型仍有明显差距，画面完成度和长程稳定性都差一截

## 谁该用

值得看：做科普/教程/数据视频的（公式图表不能错）、做片头字幕品牌动效的（一次调好套一百支都一致）、研究 agent 长程任务的（2000 轮、10 小时的完整制作轨迹全开源，是很好的长程样本）。

先别碰：要写实画面、真人真实场景，或者想"一句话出片、五分钟交付"的。

## 点评

- 和库里 HyperFrames、huashu-art-motion、Video as Code 是同一路线（代码即视频），差别是这次开源的是**模型本身**而不只是渲染引擎或 skill
- 最有价值的不是画质，是那套"渲染出来再读回去自检"的闭环和全开源的长程制作轨迹——对研究 Agent 怎么跑几千轮任务很有参考
