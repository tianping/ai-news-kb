# 我把剪映卸了：Codex 装一个插件，10 分钟出片，剪辑师要失业了？

> 来源：A.I.0.3 · Codex上手记

> 收录日期：2026-08-22

## 核心内容

文章讲述作者体验 Codex + ChatCut 插件做视频剪辑的过程，称以前用剪映半天起步的流程，现在一句话就能完成。

## ChatCut 插件介绍

**是什么：** 给 Codex 安装的 ChatCut 插件，通过自然语言对话生成带画面、配音、字幕的完整视频。

**实测流程（4步）：**
1. 让 Codex 自己装插件 → 发"阅读 chatcut.io/chatgpt，帮我安装 ChatCut 插件"
2. 让它打开编辑器 → "请用内置浏览器打开一个 ChatCut 项目"
3. 用大白话说需求 → "帮我做一个《瓦尔登湖》的介绍视频，30秒左右，适合视频号，风格温暖，低沉男声配音"
4. 等 3 分钟，拿成片

**与传统剪辑对比：**

| 痛点 | 传统方式 | ChatCut 方式 |
|------|---------|-------------|
| 素材 | 另找 AI 工具生成 | 一句话搞定 |
| 配音 | 另找配音工具 | 自带 5 种音色任选 |
| 字幕 | 剪映手动加 | 自动生成 |
| 顺序 | 手动拖时间线 | AI 自动排 |
| 改片 | 重新剪辑 | 聊天式修改 |
| 耗时 | 半天到一天 | 不到 10 分钟 |

## 国内用户注意事项

1. 需要有 Codex 账号
2. 浏览器推荐 Chrome，Edge 偶尔抽风
3. 素材版权要注意，部分来自免费图库（如 Pexels），商用需自行确认许可
4. 服务在海外，国内使用可能需要网络工具

## 适合人群

- 做口播的：拍完直接丢给它，字幕节奏转场全包
- 做图书/好物带货的：一句话出一条介绍视频
- 拍 Vlog 的：素材交给它，画面先跑起来
- 完全不会剪辑的小白：不用碰时间线、不用学转场

## 核心观点

视频制作的门槛正在被重新拉平。AI 不是替你想创意，而是把执行成本压到最低——你负责想，它负责做。剪辑师不会失业，但执行成本被拉到地板价后，重复劳动的价值大幅下降。
