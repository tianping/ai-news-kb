## 自动剪辑之路（三个月迭代）

1. **HyperFrames 粗剪阶段**：两个月前用 HyperFrames 辅助做视频，口播粗剪 + 背景动画模板。结果被限流，后台反馈"同质化模板"。
2. **IP 动画阶段**：从自己 IP 插画思路衍生，让插画动起来。流量回暖，粉丝刷到"小女孩和猫"就能认出是小肥肠——强赋能 IP 的 buff。
3. **导演 Skill 整合阶段**：把 IP 动画、口播、AI 动画整合，用一个导演 skill 总控调度，不再像 PPT。目标：电影质感（道阻且长）。

## 技术架构

**导演 Skill 总控调度**已有工具：

- 自制：个人 IP 动画 skill、粗剪 skill
- 开源插件：HyperFrames、Remotion（没有就让 Codex 安装）

流程：输入口播稿 + 素材 → 导演 skill 组织调度各环节 → 输出成片。

创建导演 Skill 的提示词核心是**串接流程**；前提是本地已有上述两个自制 skill 和两个开源插件。剪辑模板可以截取网上好看的让 Codex 模仿，调试是个漫长过程（作者后续会铺开讲）。

## 博主感悟：从 AI 工具人到落地派

- 带小红书项目群友陆续出单，坚定做 AI 落地的决心；下一期计划小程序商业闭环，再下一期 AI 带货。
- 去年纯讲 AI 工具/追热点复刻工作流的打法：累、突围难、变现难，工作流转手就被同行改成自己的项目。
- 今年转向实操变现（公众号漫画 → 小红书虚拟资料训练营），都是自己先跑通再带人跑通。"工具占 10%，我个人经验占 90%"——粉丝认的是 IP 而非 skill。
- 观察：很多 AI 博主停更了；差异化出路是"落地性强"的人设标签。
