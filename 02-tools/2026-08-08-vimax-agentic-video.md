## 什么是 ViMax

ViMax 是香港大学数据科学实验室（HKUDS）开源的端到端多智能体视频生成框架。它不是单纯调用一个视频模型生成几秒素材，而是把视频生产拆成接近真实创作流程的多阶段系统：导演、编剧、制片人、视频生成器一体化。

- **GitHub**：https://github.com/HKUDS/ViMax
- **开源协议**：MIT License
- **语言**：Python 3.12，uv 管理环境
- **GitHub 星标**：1.4k+

## 解决什么痛点

当前 AI 视频工具的核心痛点：
1. 只能生成短片段，缺乏叙事深度
2. 角色和场景跨帧一致性差（换脸、变装、场景突变）
3. 剧本和分镜需要专业知识
4. 长视频需要跨场景连续性
5. 参考图管理困难

## 四大核心创作模式

### 1. Idea2Video（创意→视频）
用户只需用自然语言描述一个想法（如"一只猫和狗是好朋友，遇到新猫咪后的故事"），补充简单要求（如"面向儿童、不超过3个场景"），系统自动完成：
- 创意拆解与剧本撰写
- 分镜与镜头规划
- 角色与场景设计
- 视觉合成与音频同步

### 2. Novel2Video（小说→视频）
面向长篇文学内容：
- 叙事压缩：提取核心剧情，保留关键角色与情节转折
- 角色追踪：全程维护角色外观、性格、行为一致性
- 逐场景视觉适配：根据小说描写自动生成视觉场景
- 剧集拆分：长篇故事自动拆分为独立剧集

### 3. Script2Video（剧本→视频）
面向已有完整剧本的用户：
- 剧本解析：提取角色信息、场景信息、动作指令
- 镜头设计：根据氛围设计拍摄角度、镜头运动、转场效果
- 视觉还原：精准还原剧本中的场景布置与角色动作
- 灵活调整：修改剧本细节可实时更新

### 4. AutoCameo（客串视频）
- 上传自己或宠物照片，融入任意创意脚本
- 形象一致性：基于参考照片保持外观统一
- 自然融入：智能调整光影、比例、风格适配
- 多场景适配：跨故事客串

## 技术架构：8层多智能体流水线

| 层级 | 功能 |
|------|------|
| 输入层 | 接收创意/剧本/小说、参考图片、风格指令 |
| 中央编排 | 智能体调度、阶段过渡、资源分配、重试/降级 |
| 剧本理解 | 角色/环境信息提取、场景边界划分、风格意图解析 |
| 场景与镜头规划 | 分镜设计、镜头列表、关键帧与节奏控制 |
| 视觉资产管理 | 参考图选择、风格引导、Prompt优化 |
| 资产索引 | 帧/参考图分类存储、嵌入向量生成、复用检索 |
| 一致性保障 | 角色/环境追踪、参考图匹配、时序连贯性校验 |
| 视觉合成与组装 | 图像生成、最佳帧选择、帧转视频、剪辑组装 |

**核心设计亮点**：把"人类创作者会反复检查的一致性问题"前置到流水线里，而非生成完再手动补救。

## 核心技术能力

### 角色与场景一致性保障（三重机制）
1. **智能参考图选择**：自动筛选前序场景关键帧作为参考
2. **MLLM/VLM一致性校验**：并行生成多张候选图，由视觉语言模型评估选择最优帧
3. **时序连贯性追踪**：记录角色外观特征（发型、服装、体型）和场景元素，后续帧强制保留

### 智能长剧本生成（RAG-based）
- 基于检索增强生成技术分析长文本
- 核心情节提取、场景拆分、对话保留、格式标准化

### 分镜设计与多机位模拟
- 根据场景氛围选择镜头类型（远景/近景/特写）
- 设计镜头运动轨迹（跟踪/摇镜）
- 模拟多机位拍摄效果
- 控制镜头节奏（动作场景快切，抒情场景慢过渡）

### 并行生成与Prompt优化
- 同机位连续镜头并行处理
- 根据风格自动优化图像生成Prompt
- 自适应帧转视频

### 音视频同步
- 角色语音生成（根据性格和情绪）
- 音效匹配（环境音、动作音效）
- 背景音乐适配
- 音视频精准对齐

## 安装与使用

### 环境要求
- Linux 或 Windows（64位）
- Python 3.12+，uv 环境管理工具
- 需要第三方 API（聊天模型、图像生成、视频生成）

### 安装步骤
```bash
git clone https://github.com/HKUDS/ViMax.git
cd ViMax
uv sync
```

### 配置
编辑 `configs/idea2video.yaml` 或 `configs/script2video.yaml`，填写：
- 聊天模型 API（如 OpenRouter、Google Gemini）
- 图像生成 API
- 视频生成 API

### 运行
```bash
# 创意生成视频
uv run main_idea2video.py

# 剧本生成视频
uv run main_script2video.py
```

### 输出产物
- `final_video.mp4`：最终完整视频
- `frames/`：所有视频帧图像（可二次编辑）
- `script.txt`：AI优化后的剧本
- `logs/`：创作日志
