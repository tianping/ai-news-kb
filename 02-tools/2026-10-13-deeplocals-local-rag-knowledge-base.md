## 概述

作者团队自研的本地 RAG 知识库产品 **DeepLocals** 的介绍与实测（属作者自家产品推广，数据均为作者自测）。要解决的痛点是：电脑里几千个散落的文件，想按"问题的意思"（而不是关键词）找一句话、核对一个数据非常难。

## 痛点对比

- **通用智能体**（Codex、Claude Code、豆包、WorkBuddy）：作者问配 Opus 5.5 的 Claude Code 能否不靠关键词、只靠大意从几千个文件里找答案，它回答"不能"——2 分钟连一小部分都读不完。
- **现有 RAG 知识库**（腾讯 IMA、Google NotebookLM）：NotebookLM 即使 Pro，一个知识库也只能放 **300 个文件**；PDF 中的公式和表格导入后排版基本乱掉。
- **Karpathy 的 LLM Wiki 思路**（让大模型把资料整理成一份 Wiki 再问答）：几十份文档可以，资料一多、格式一杂就撑不住；作者评价为"玩具"，量大还得用 RAG 知识库。

## DeepLocals 五大特色

1. **海量本地文件**：一张卡片 = 一个知识库，可装几千个文件；作者电脑 6839 个文件分 16 个知识库；支持**跨知识库语义检索**。从一千多个文件做带思考+规划+多轮检索的问答，完整回复约 **48 秒**（GIF 未加速）。
2. **55 种文件类型**（NotebookLM 为 43 种），下一版加视频处理达 66 种；扫描件的公式、图片、排版基本保留。导入方式：文件 / 文件夹 / Obsidian 笔记 / 智能学习四种。
3. **图文回复 + 问答地图**：每句话后带引用，点击即看原文证据以降低幻觉；问答地图展示最近若干次问答与引用资料的关系，节点可跳转。
4. **RAG 原生智能体 + Skills**：跨文件格式检索，可直接导出 Word 等多种格式；内置十多个办公 Skill。
5. **本地大模型**：默认配 Qwen3.8:27B，支持三种主流本地模型配置模式；数据不出本机、免费、不限次。

## 备注

- 作者自家产品软文，性能与对比数据（300 文件上限、格式数、48 秒）未经独立核实；未给出开源地址或定价信息。
- 选型参考：资料量在几十份 → LLM Wiki / NotebookLM 足够；上千份、含扫描件公式表格、且要求本地隐私 → 可考虑此类本地 RAG 方案（同类开源替代可另查，如 AnythingLLM、RAGFlow 等）。
