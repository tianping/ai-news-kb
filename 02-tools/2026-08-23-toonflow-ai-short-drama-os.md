## 概述

Toonflow 是一个开源 AI 短剧生产项目，GitHub 约 1.44 万 Star、2600+ Fork，Apache-2.0 许可证（商业分发需额外授权）。它把小说转短剧做成可管理、可回溯、可迭代的流水线，而非"一句话生成大片"的黑盒工具。

## 核心架构

| 层级 | 技术栈 | 作用 |
|------|--------|------|
| 桌面与服务层 | Electron、Express、Socket.IO | 跨平台桌面端、后端 API、实时消息流 |
| 数据层 | SQLite、better-sqlite3、Knex | 项目、小说、事件、脚本、资产、分镜、视频轨道持久化 |
| Agent 层 | ScriptAgent + ProductionAgent | 剧本统筹 + 生产编排 |
| 生成层 | Vercel AI SDK、多家模型适配器 | 接入 OpenAI/Anthropic/Google/DeepSeek/智谱/通义/MiniMax/xAI |
| 本地能力 | Transformers.js、ONNX | 本地向量检索、Agent 记忆 |
| 媒体处理 | Sharp、本地 OSS 目录 | 图片处理、素材管理 |

## 三层 Agent 协作

1. **决策层**：Decision Agent — 理解目标，决定调用哪个子 Agent
2. **执行层**：
   - 衍生资产 Agent（分析剧本需要的角色/场景/道具）
   - 图片资产 Agent（生成并补充资产）
   - 导演规划 Agent（制定拍摄计划）
   - 分镜生成 Agent（生成分镜图/视觉描述）
   - 分镜面板 Agent（写入工作区）
   - 分镜表 Agent（构建结构化分镜表）
3. **监督层**：Review Agent — 检查结果并提出修订

## 关键设计亮点

### 章节事件图谱
导入原著 → 提取章节事件 → ScriptAgent 生成故事骨架/改编策略/结构化剧本。事件是比原文更适合短剧改编的中间表示，减少长上下文丢失。

### 角色/场景/道具资产化
先把角色外貌、场景结构、道具形态转化为可复用资产，分镜引用资产 ID 而非重新写提示词，降低跨镜头角色漂移。

### 无限画布工作区
剧本、角色、分镜、素材、视频节点组织在同一空间，可回溯上游问题（是事件理解错？资产描述不够？提示词缺镜头语言？）

### 持久化 Agent 记忆
本地 ONNX 向量检索，区分短期消息/长期摘要/语义召回。项目资料留在本地，适合隐私敏感创作者。

### 可编程供应商系统
用户可在设置中心编写 TypeScript 逻辑配置模型供应商，经沙箱执行后统一加载为模型列表。

## 适合人群

- 短视频团队、小说改编创作者
- AI 编剧与分镜研究者
