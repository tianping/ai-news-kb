# 如何利用 Hermes + Blender 跑通第一个 3D 任务

> 来源：[如何利用 Hermes + Blender 跑通第一个 3D 任务](https://mp.weixin.qq.com/s/KimtoQJfx3kr6YqW8qUFRw) · 2026-08-15 · 公众号：智瞳一哥

## 核心概要

Hermes Agent 将 Blender MCP 纳入其 MCP Catalog，用户只需一行命令 `hermes mcp install blender` 即可安装。安装后，Agent 可以通过自然语言直接在 Blender 中创建对象、调整材质、布置灯光和相机、渲染预览图。文章提供了一个从安装验证到首次任务跑通的完整实操指南，并给出了一段可直接使用的提示词模板。

## 关键信息

- **工具名称**：Hermes Agent + Blender MCP
- **安装命令**：`hermes mcp install blender`（一行安装，同时处理 MCP 和配套 Skill，关闭部分付费附加工具）
- **连接验证**：`hermes mcp list` → `hermes mcp test blender` → 在会话中 `/reload-mcp` → 让 Agent 列出可用工具（不创建/修改文件）
- **本质**：MCP 不是插件，而是把 Blender 的部分操作变成 Agent 可调用的工具——Agent 真正创建场景对象、材质、灯光和相机，而非仅生成一张图片
- **与 AI 图片的区别**：Blender 工程可继续改尺寸、换材质、调镜头、做动画、重新渲染；AI 图片只能看

## 首次任务建议：产品展台（非复杂产品动画）

社区案例：Teknium X 帖引用创作者用 Codex + GPT-5.6 Sol + Blender MCP，5 个提示、40 分钟做出悬浮 iPhone 效果。但该案例在 Codex 完成，非 Hermes 实测。

文章建议起步任务做产品展台，包含五件事：
1. 创建圆角底座
2. 加入简单材质
3. 放置产品占位物体
4. 设置灯光和相机
5. 渲染低分辨率预览图

## 可直接使用的提示词模板

```
请使用 Blender MCP，在一个新的空白项目里完成低风险测试。
目标：制作一个简洁的产品展示台。
要求：
1. 创建一个圆角长方体作为底座；
2. 底座使用深灰色哑光材质；
3. 在底座上方创建一个竖直的圆角长方体，作为产品占位物；
4. 添加一盏主灯和一盏柔和补光；
5. 设置相机，让底座和产品完整出现在画面中央；
6. 只渲染一张低分辨率预览图；
7. 不覆盖已有文件，不安装额外付费工具，不执行外部上传；
8. 完成后汇报：创建了哪些对象、修改了哪些关键参数、预览图保存在哪里。
先告诉我你的执行计划，等我确认后再开始修改场景。
```

## 验收六项检查

1. **对象是否真的存在** — 打开场景对象列表确认，而非只生成外部图片
2. **参数是否方便继续修改** — 尺寸、位置、材质保留可编辑状态，命名清晰
3. **相机是否拍到完整主体** — 确认镜头对准正确位置
4. **灯光是否服务于主体** — 主灯塑形，补光避免死黑，产品轮廓清楚
5. **文件保存到正确位置** — 要求 Agent 报告路径，亲自打开确认
6. **是否做超出要求的动作** — 检查是否安装多余组件、覆盖旧文件、上传内容

## 提示词六块结构（通用模板）

| 板块 | 说明 |
|------|------|
| 任务目标 | 最终要得到什么 |
| 操作对象 | 允许创建或修改哪些内容 |
| 视觉要求 | 材质、灯光、相机大方向 |
| 输出要求 | 工程文件、预览图、保存位置 |
| 权限边界 | 不能覆盖、不能上传、不能安装什么 |
| 验收回报 | 做了什么、结果在哪、哪些没完成 |

> 此结构不只适用于 Blender，凡 Agent 操作文件、浏览器、表格、视频软件或代码项目都可沿用。

## 适用人群

- 想做产品展示图的运营和内容创作者
- 有 3D 想法但不熟悉 Blender 界面的人
- 想把 AI 接进设计软件的产品经理和应用开发者
- 已会 Blender，希望减少重复搭场景操作的人
- 想研究 Agent 如何操作专业软件的人

**暂不适合**：精细角色建模、复杂绑定、电影级灯光、可直接商用的完整动画。

## 对 AI 应用开发者的启示

Agent 接入专业软件后，产品界面需让用户看到：
- Agent 准备调用哪些工具
- 哪些动作需要人工确认
- 场景里具体改了什么
- 工程文件和预览结果保存在哪里

> 好 Agent 不是悄悄替你做完一切，而是在开始前说明计划、关键动作前停下来、完成后交代结果。
