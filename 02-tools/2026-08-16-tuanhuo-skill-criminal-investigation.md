## 概览

**团伙 Skill**：一套把"挖关系"从单点扩成整条研判流水线的离线情报工作台。
- 从数据进来 → 团伙框架、涉案罪名、法律解析、可回溯报告出来，一步到位
- 包含 SKILL.md、推断规则、刑法库、审计脚本完整工程，上万个校验脚本
- 适配国信智擎离线本地部署 Agent、Workbuddy 等平台

## 核心定位

> 把依法取得或明确授权的案件线索（单聊、群聊、通话、资金、设备、账号、企业、位置、文件、笔录、结构化清单），自动发现行为、语义提及对象、关系、行动单元与团伙假设，输出可审计的高级离线 HTML 关系网络。

**四大输出物**：
1. `case-graph.json` — 结构化数据
2. `audit.json` — 审计底稿
3. `case-network.html` — 离线情报工作台（可交互、可回溯）
4. `manifest.json` — 清单

## 四种启动模式

| 模式 | 适用场景 |
|------|----------|
| **comprehensive** | 材料范围大、不知道团伙在哪，先整体扫一遍 |
| **target-expansion** | 已知某个人/账号/企业，往周边扩线 |
| **hypothesis-test** | 手里有组织结构猜测，拿证据检验 |
| **incremental** | 新一批材料进来，并入已有案件图谱 |

Agent 会先进行"确参反馈"，反问几个高价值问题（分析目标、来源范围、时间范围、法域、重点对象、身份合并建议、低置信度展示、脱敏要求），答完才开工。

## 九步工作流

| 步骤 | 核心内容 | 关键闸门 |
|------|----------|----------|
| **01 材料体检** | 来源清单、覆盖矩阵；取得依据、原始性、哈希、时区、时间跨度、解析成功率、重复、删除恢复状态 | 缺合法来源说明直接降级 |
| **02 身份解析** | 人物/账号/设备/企业分开建模；同名/同头像/共同设备只能形成候选，需硬证据才合并 | 无硬证据不许静默并人 |
| **03 全来源实体发现** | 逐条扫单聊、群聊、通话、资金、文件、笔录、联系人、设备、企业 | 第三人提及也要建实体 |
| **04 七维关系发现** | 指挥、通信、任务、资金、资源、事件、掩护 —— 七维独立建边可叠加 | 同两人可同时挂资金边和指挥边 |
| **05 团伙假设** | 按涉嫌行为/协作事件建组织假设；聊天容器本身不构成团伙 | 共同群聊只算通信范围 |
| **06 竞争性假设** | 每个关键判断至少比较一种合理解释（正常经营、普通社交、临时合作、账号共用等） | 强制竞争性假设+反证清单 |
| **07 法律要件** | 先立行为事实，再匹配法域/生效法律，五要素逐项标注 | 内置刑法库（见下） |
| **08 研判优先级** | 0-100 排序，不代表有罪概率，分项理由透明 | 安排核查资源用 |
| **09 交付** | 任意人物/关系/角色/团伙/要件 ↔ 证据 ID ↔ 来源/文件/记录定位/保全信息 | 全程可回溯 |

**约 4.9 万个自动检查脚本**把关每个环节。

## 七维关系：同一批人，七条线一起看

| 维度 | 看什么 |
|------|--------|
| **指挥** | 决策、授权、否决、分派、汇报闭环 |
| **通信** | 稳定联络、跨群桥接、隐蔽通信、联络替代 |
| **任务** | 招募、准备、执行、接应、复盘、善后 |
| **资金** | 出资、收款、归集、结算、分配、代持、受益 |
| **资源** | 账号、设备、企业、地点、车辆、文件、渠道、权限 |
| **事件** | 共同目标、时间窗口、阶段衔接、结果反馈 |
| **掩护** | 身份遮蔽、话术、销毁、规避、替代通道、反侦查 |

> 资金一条线、指挥一条线、掩护一条线，三条线叠起来，组织关系才现形。只看一条线，要么漏要么错。

**五个主张层级**：
1. 材料直接显示的观察事实
2. 对象间的关系线索
3. 能解释证据组合的工作假设
4. 外部核实的事实
5. 法律要件分析

## 内置刑法知识库

- **《中华人民共和国刑法》2020-12-26 版全文**，505 个条文起始项，带 SHA256 哈希校验
- 覆盖：涉黄、涉赌、涉毒、帮信、掩隐、诈骗、传销等
- 每个疑似涉案类型建**法律构成要件矩阵**：主体、主观方面、客观行为、对象或结果、共同犯罪关系 → 逐项标 supported/partial/missing/contradicted
- 法条注明法域、版本、生效日期；无法核验标记"待法制审核"
- 新版本法律 DOCX 可导入知识库，保存原文和哈希，**不覆盖旧版本**
- 法律映射是法制审核底稿，**不是定罪结论**

## 上手教程：四步走

### 第一步：备线索、取证材料
整理依法取得/授权的材料：单聊、群聊、通话、资金流水、笔录、文件、联系人。**关键是把来源说清楚**——哪来的、什么时间段、有没有合法依据。

### 第二步：选平台、装 Skill、选模式
- 平台：国信智擎离线本地部署 Agent、Workbuddy 等
- 上传 Skill 压缩包
- 选四种模式之一 + 回答最多 5 个高价值问题

### 第三步：等待跑图出报告（约 30 分钟）
Skill 跑完生成 `case-graph.json` → 三条收尾命令：
1. 严格审计（结构、引用、对账、研判边界）
2. 数据注入离线 HTML 模板
3. 浏览器自动跑交互测试（控制台报错、画布渲染、关系端点）
三步全绿，`case-network.html` 才算能交付。

### 第四步：读报告、定核查方向
1. 看团伙导航和重点人员排序
2. 看每个团伙的法律要件矩阵（哪些罪名要件有证据、哪些空着）
3. 按研判优先级 0-100 从高到低安排核查资源

> **核心原则**：机器给的是核查方向，结论永远由人来定。每条线索都能点回证据 ID → 看到来源、文件、记录定位。

## 边界与申明

- 只分析依法取得或明确授权的数据
- "全面排查" = 授权范围内的全面检查
- 输出是**侦查假设和核查方向**，不代替侦查机关认定、法制审核或司法裁判
- 演示数据不指向任何真实案件
- 模型推断永远不等于犯罪事实，结论均以"材料显示""当前支持""工作假设""待核实"标注
- 不得非法获取信息、不得超范围调查、不得冒充公职人员
- 研判结论须经法制审核后方可作为办案参考
