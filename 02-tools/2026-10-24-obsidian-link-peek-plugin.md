## 概述

Link Peek 是 Obsidian 社区插件：鼠标悬浮在**外部网页链接**上时，弹出 OpenGraph 卡片（标题、简介、缩略图），不用切到浏览器就能看出链接是什么内容。不改笔记源码，也不需要额外语法。

与 Obsidian 原生「页面预览（Page Preview）」互补：
- 原生页面预览 → 只管内部双链 `[[笔记]]`
- Link Peek → 只管外部 `http(s)://` 链接

文中建议与 Jump to link、Sidenotes 搭配，组成「链接阅读 + 批注」工作流。

## 安装

设置 → 第三方插件（Community plugins）→ 关闭安全模式 → 浏览 → 搜索 "Link Peek" → 安装并启用。

- 桌面端全平台支持（Windows / Mac / Linux）
- 移动端体验差（卡片易错位），建议电脑端用

## 常用配置

| 配置项 | 默认 | 调整建议 |
|---|---|---|
| 悬浮延迟 | 500 ms | 易误触 → 800–1000 ms；想快 → 300 ms |
| 缓存时长 | 7 天 | 常更新网页 → 1–3 天；离线整理 → 14–30 天 |
| 卡片尺寸 | — | 大屏约 600 px 宽；小屏约 400 px |
| 触发方式 | 悬浮即弹出 | 链接密集时改成按住 Ctrl/Cmd + 悬浮 |
| Canvas 支持 | 开启 | 画布内 URL 节点和文本块链接都能预览 |

隐私：请求直接从本机发往目标网站，没有中间服务器。

## 支持的场景

1. Live Preview（实时预览）：边写边查
2. 源代码模式：纯源码 `[文字](url)` 也能触发（不少同类插件在此模式下失效）
3. 阅读模式：快速浏览所有引用网页的摘要
4. Canvas 画布：适合做文献图谱、素材看板

## 使用技巧

- 卡片只显示摘要，看全文仍需点链接在浏览器打开
- 网页失效或禁止抓取时卡片提示无法获取，不会卡死 Obsidian
- 批量场景：文献综述一次贴几十个论文链接，悬浮快速筛选；整理收藏的大量网页参考

## 常见问题

- **没有缩略图**：网站屏蔽了 OpenGraph，只能读到标题——网站限制，非插件问题
- **卡片挡住文字**：调小卡片最大宽度，或改用 Ctrl 悬浮触发
- **主题冲突、样式错乱**：用 Style Settings 插件或自定义 CSS 修复
- **链接没反应**：确认是外部 `http(s)://` 链接，而不是 `[[内部双链]]`
