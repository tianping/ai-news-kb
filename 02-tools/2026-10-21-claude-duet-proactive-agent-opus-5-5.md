## 概述

Anthropic 发布 **Claude Duet**，一个由 **Opus 5.5** 驱动的「主动式 Agent」。它在云端虚拟机里 7×24 运行：自己盯着工作流，判断事情的轻重缓急，主动揽活、推进，只在需要拍板时才打断用户。首批向美国的 Claude Pro / Max 用户开放候补，获邀后才能用，支持 iOS、Android 和网页；研究预览期间不额外收费。这款产品对标 OpenAI 的 dot。

## 关键内容

### 产品形态

- **晨报**：列出进行中的事项、卡点和需要用户决定的事，例如「5 件事在推进，2 件需要你」
- **云端运行**：自带云端虚拟机和浏览器，用户关掉电脑和手机后任务照样跑；网站没有现成连接器时，可以用浏览器直接操作
- **继承 Claude 账户**：长期记忆、技能和已授权的第三方应用直接迁移过来，不用重新设置
- **连接器**：可用 Claude 应用市场里 6000 多个连接器和插件跨系统干活。例如在 Stripe 查未付发票并写催款信、用 Gusto 填工资、通过 Docusign 准备协议并送签
- **权限边界**：
  - 需要用户批准：发消息、付款、签文件、删除内容
  - 批准了也不能做：买卖证券、账户间转账、访问他人账户
- **限制**：
  - 后台检查一般每隔几小时一次，晨报和任务会消耗现有套餐额度
  - Slack 功能有限，暂不支持 Microsoft 365
  - Google 环境只能建 3 个连接，有多个 Gmail 账户的人不够用（预览用户 Wiley Strahan 反馈）

### 官方演示：咖啡品牌 Marlo 的老板 Maya

- 芝加哥新店 26 天后开业，开店清单 41 项，当天必须她点头的只有卫生许可：表格已经填好，640 美元费用在 Link 里等她批准
- 嫌 PPT 太挤，一页拆成两页；融资资料缺 3 份，补上 2 份，剩下的董事会纪要等她签字
- 把收银、Shopify、客户管理、客服、工资和银行数据汇总成每日经营看板「Marlo Pulse」，每天清晨 5:30 刷新
- 主动发现运费调整后订阅流失率从 2.6% 升到 3.4%，提议查原因并试行满 40 美元包邮
- 招聘：选定候选人后，自动从 HR 文件夹取出薪酬方案附进录用邮件，改好语气后等用户点「发送」

### 早期用户案例

- 房产经纪人 Jess Provencher：没让它查日程，它自己发现一场看房约错了日子
- 烤肉连锁店 Shahs of Kabob（约 110 名员工）的老板 Amin Ebrahimi：用在会计、客服、营销上，逐店梳理发票，「不用再开 100 个标签页」
- 品牌策略师 Mya Dalton：准备会前简报时发现客户电话和航班起飞时间冲突，主动提出改时间
- Stripe 的 Jen：假设经营一家一人糖果公司，让 Duet 结合 Link 找供应商、下单采购，「它真的办到了」
- AI 创作者 Peter Yang：把「主动性」列为头号看点，认为 Artifacts 可能成为 Duet 的独特优势；还给孩子做了一套「AI 探索俱乐部」互动任务

### Anthropic 内部使用

- Mike Krieger（Instagram 联合创始人，现在在 Anthropic Labs）称 Opus 5.5 是「第一个有足够判断力、能以合适方式主动做事的模型」。他让 Duet 替自己看周末的 Slack，只在急事时叫他（如 #evals-launch 频道的 @）；Duet 还提醒他 Neal Stephenson 出了新书，并从本地书店代为下单
- Claude Code 负责人 Boris Cherny：散步时把待办口述给 Duet
- 模型与产品行为设计负责人 Chelsea Larsson：交出待办清单去陪孩子，晚上看 Duet 汇总的报告
- Duet 团队负责人 Karan Ahuja：用 Duet 开发 Duet，从约用户访谈、做原型到提交代码都有它参与
