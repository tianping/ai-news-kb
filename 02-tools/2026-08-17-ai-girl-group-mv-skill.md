# 女团 MV Skill：AI 视频工作流

**来源**：微信公众号文章  
**日期**：2026-08-17  
**分类**：工具与产品 / AI 视频工作流

---

## 核心内容

### 这是什么？
一个打包好的 AI 视频制作工作流（Skill），专门用于制作 AI 女团 MV。它把原本需要专业知识、耗时数天的复杂流程（角色一致性、分镜脚本、负面提示词、逐镜头生成），收敛成"丢几张角色设定图 + 说一句话"的交互。

**核心卖点**："AI 一次生成（最终效果在视频最后）"——不用手动调每一个镜头。

---

### 输入与处理流程

1. **输入**：5 位成员的角色设定图（参考图）
2. **自动分析**：
   - 参考视频分析（显示"参考视频分析完成 x5"）
   - 角色档案提取：自动读取脸、发型、服装、配饰
   - 例：成员 1 = 长直黑发、白色吊带背心 + 银灰色不规则褶皱短裙 + 黑色网格过膝袜

---

### 内部结构：六大模块提示词公式

```
视频结构 = 角色 + 场景 + 动作 + 分镜 + 结尾 + 负面提示词
```

| 模块 | 作用 |
|------|------|
| **角色** | 从设定图提取的成员档案，锁定脸、发型、服装一致性 |
| **场景** | 舞台、灯光、氛围等视觉基底 |
| **动作** | 描述"整体运动感"而非具体舞步 |
| **分镜** | 把 MV 拆成多个短镜头，按节奏硬切拼接 |
| **结尾** | 收尾镜头处理 |
| **负面提示词** | 排除模糊、抖动、崩脸、淡入淡出等 |

> 关键点：六个模块的提示词 Skill 已预填好，用户只需在最外层给一个方向。

---

### 生成底层路线

- **分镜方式**：Storyboard 模式
- **图像/视频技术栈**：
  - Midjourney 出参考图
  - ComfyUI + ControlNet 组合做姿态和构图控制
- **两阶段结构**：
  1. **全局预设提示词（Master Prompt）**：定死角色、美学、风格等"全局锚点"
  2. **逐镜头故事板**：按分镜生成

**交互设计**：选中所有素材 → 长按 Tab 键一次性生成；支持"全部重做"或局部"修改"重新生成对应镜头。

---

### 现实边界（短板）

| 短板 | 说明 |
|------|------|
| **一致性仍是老大难** | 5 个成员在几十镜头里不崩脸，是 AI 视频硬骨头；视频承认"难免出现小 bug"，靠"修改/重做"回补 |
| **"一次生成" ≠ "一次成片"** | 产出多半是需要人工筛选、微调的毛坯 |
| **门槛只是被转移，不是消失** | 依赖 ComfyUI、模型、显存等硬门槛一个没少；真正卡人的往往是算力和环境 |
| **审美上限受限于模板** | 结构化带来稳定，但也导致同质化——套同一个 Skill，出来的 MV 容易"都是一个味儿" |

---

## 总结

女团 MV Skill 的本质：**把 AI 视频制作从"手动搓每一个镜头"推进到"用一句话调度一整套工作流"**。

它最大的价值不在于"生成"这个动作本身，而在于把**角色、场景、动作、分镜、结尾、负面提示词**这套方法论，沉淀成**可复用、可分享的 Skill**——相当于给"会做 MV 的老师傅"写了一份标准作业手册，换个新人也能量产。

对虚拟偶像、短视频创作者、AI 视频工业化流程研究者，这是个值得参考的样本。
