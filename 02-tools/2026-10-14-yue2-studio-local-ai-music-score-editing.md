## 概述

YuE2-Studio 是包装开源多模态团队 **M-A-P 的 YuE2 模型**的本地桌面工作站。针对 Suno/Udio 式"开盲盒"——整首歌一体生成、副歌某句跑调只能整首重抽——它改为两段式：**先生成乐谱，再做演唱**。AI 音乐的核心痛点不是音质，而是不可控。

## 核心机制：先谱后唱

1. 输入风格描述（如 `city pop, electric piano, funky bass, 108 BPM`）+ 分段歌词
2. 模型先生成 **ABC 记谱法**文本，实时渲染成五线谱（主旋律音高、时值、和弦走向）
3. 声学渲染模块再按旋律与伴奏骨架做人声演唱与全频带混音
4. 乐谱可**就地编辑**：挪音符、改调性和速度，固定曲谱骨架后重新渲染音色

把"抽卡"拉回传统的"编曲 → 录音"范式。

## 工程架构：零 Python 依赖

- 前端 **Tauri**（Rust + React），后端 **yue2.cpp**（纯 C++/CUDA 移植，类似 llama.cpp）；单个 Windows 安装包或解压即用便携版
- N 卡：自带 CUDA 12 / CUDA 13 预编译后端，GTX 900 系列到 RTX 40/50 系及专业卡，无需预装开发套件
- 显存：GGUF 多档量化，**6GB（Q5_K_M）**起步；8–12GB 可跑 Q8_0 或近无损 BF16。RTX 4090 渲染 3 分半全曲约 **46 秒**
- A 卡 / 核显：实验性 Vulkan 路径，仍推荐 N 卡

## 工作站模块

1. **扒谱翻唱**：内置 SheetSage2 听音模型，拖入人声音频 → 转乐谱 → YuE2 换风格音色重新翻唱
2. **音轨分离**：HT-Demucs，一键拆成人声、鼓、贝斯、吉他、钢琴、其他 6 轨，便于导入 Logic Pro / Ableton Live
3. **音频转 MIDI**：MuScriptor 模型，最多 34 种乐器分组，带交互式钢琴卷帘
4. **本地 LoRA/LoKr 训练**：三步向导，自动切片、对齐歌词时间戳，在本地显卡训练固化歌手音色或曲风
5. **彩蛋**：复刻 Winamp 2 界面，支持第三方皮肤、.EQF 均衡器、全屏 MilkDrop 频谱可视化

## 接入 Agent（MCP）

启动后常驻 `http://127.0.0.1:8791/mcp` 端点，暴露 **162 个**细粒度工具，可挂到 Claude Code、Cursor 等 Agent：一句自然语言 → 写分段歌词、定 BPM 与编排提示词、调本地引擎排谱、微调节奏、渲染并导出无损分轨，形成闭环。

## 实操补充：Mac M4 16G 部署与使用（2026-10-21）

- **来源**：微信公众号「AI落地应用实干家」《AI音乐开源YuE2 Studio 本地部署指南/免费生成音乐》
- **原文**：https://mp.weixin.qq.com/s/ZNXchz7dPY-sHnImYHiO2g

### 安装三步

1. 从 GitHub releases 下载：Mac 版是 `YuE2-Studio-3.6.0-macos-arm64.dmg`（60MB，拖进「应用程序」）；Windows 版是 exe，缺 WebView2 会自动补装。可见 3.6.0 已支持 Apple Silicon，不只是原文说的 N 卡 / Windows
2. Mac 包没有经过苹果公证，双击会提示「无法验证开发者」。右键选「打开」，或运行：
   ```bash
   xattr -dr com.apple.quarantine "/Applications/YuE2 Studio.app"
   ```
3. 下载模型（最容易卡住的一步）：首次打开没有模型，引擎起不来。软件会先检测机器配置，再给出四套组合：

| 组合 | 主干 | 总下载 | 适合 |
|---|---|---|---|
| 轻量 | Q5_K_M | 4.0 GB | 6G 显存的小卡 |
| 均衡 | Q6_K | 4.3 GB | 8G 左右 |
| 高质量（推荐） | Q8_0 | 5.1 GB | 近无损 |
| 完整原生 | BF16 | 9.9 GB | 12G 显存以上 |

   - 每套包含 5 个文件：主干、VAE、SheetSage2（扒谱）、MERT-v2、decoder companion；4 连接分块下载，可断点续传
   - M4 16G 推荐 Q8_0，约 6 分钟下完
   - 下完后左下角从「引擎已停止」变成「配置就绪 · 高质量 · Q8_0 主干」就算齐了
   - 改中文：设置 → 外观 → 语言 → 简体中文，立即生效

### 界面

左栏十来个入口，常用的只有「创作」（写风格、填歌词、生成）和「音乐库」（带谱、封面、标签）。其余是搜索、LoRA 适配器（权重可调）、工作室工具（分轨/母带/转调）、均衡器 / 可视化 / Winamp 皮肤。

### 创作：四个框

| 框 | 写法 |
|---|---|
| 风格 | 写成配器清单，别写「好听、温暖」这类虚词。例如「city pop、电钢琴、slap 贝斯、104 BPM、女声」 |
| 歌词 | 按段落写，主歌、副歌分开，每段不超过 8 行 |
| 时长 | 上限 10 分钟，一般 2.5–3.5 分钟够用 |
| 高级（可选） | steps、seed、guidance |

- **固定 seed**：同样的词能复现同一首；想保留旋律、换个唱法，就换 seed 再跑

### 案例：中文慢歌（M4 上约 5 分钟出结果）

- 风格栏按「语言、曲风、人声、配器、情绪、BPM」的顺序写：
  `Mandarin Chinese pop ballad, warm female vocal, electric piano and soft strings, 82 BPM, intimate and nostalgic, clean production`
- 歌词：`[Verse 1]` 四行 + `[Chorus]` 四行，每行七八个字；时长 96 秒；seed 20261020
- 前四五秒在把模型读进显存、现编 Metal 内核，之后才开始真正计算
- 听三件事：人声清不清楚、副歌有没有在四十多秒进来、结尾是不是硬切
- 不满意的改法：固定 seed 换配器或情绪词（旋律大致保留、声音会变）；要动旋律就改谱

### 改谱

旋律先用 ABC 记谱法写出来并排成五线谱，再按谱演唱。能做的修改：
- 改速度
- 整体升降调，范围 −24 到 +24 个半音
- 直接在谱上挪小节，再用 MIDI 网格校一遍

改完按新谱重唱，旋律不变，声音可以换。

### 出歌之后

- **导出**：默认 24 位 FLAC；也可以选 MP3（LAME）。标题、歌词、封面会写进文件标签
- **分轨**：人声可以单独渲染，导出 MP3 或 32 位 WAV
- **歌词视频**：内置，支持 16:9、9:16、1:1，带卡拉 OK 字幕，直接出 MP4
- **延长**：从最后一帧往后接，每次 15 秒到 2 分钟，不用整首重写

### 常见问题

1. **人声太抢**：风格词里收一收 vocal 相关的词，或加一句 `not busy`；还不行就单独渲染人声，自己调音量
2. **副歌一直不来**：段落没写好或时长太短，把副歌往后挪或时长加 30 秒
3. **显存不够中途报错**：M4 是统一内存，16G 里显存一栏占 13.6G。报错就在模型页降一档（高质量 → 均衡）

### 值不值得装

- 想写歌但不会乐理、编曲，又想自己掌控结果：值得。代价是五六个 G 的硬盘、每首约五分钟，再加一个下午学怎么改谱
- 只要一段背景音、不打算改：用在线服务更省事
- 「它不是把写歌变简单了，是把写歌的控制权交回你手里」

### 让 Agent 代装并连上 MCP

可以直接把这段提示词交给 Claude Code 这类 Agent：

> 帮我装 YuE2 Studio，仓库是 timoncool/YuE2-Studio。先看 README 和 releases，装最新版；然后看我的显卡显存，按它的对照表挑合适的模型规格下载齐；装完连它的 MCP 服务。

连上 MCP 后，出歌、改谱、导出都能在对话框里完成，不用切窗口。选模型的经验：显存 8G 以下用量化版，12G 以上可以用完整权重。

### 推荐写歌顺序：先只出谱

1. 先定情绪，再定配器，最后写歌词
2. 风格写成配器清单（如 city pop、电钢琴、funk 贝斯、108 BPM）；歌词主歌、副歌分开，每段不超过 8 行
3. **先只出谱不唱**，确认旋律立得住；不行就改风格重来
4. 谱能用了再让它唱，导出选无损 FLAC（libFLAC）
5. 某段太长或太平，用「重新渲染」只补那 15 秒到 2 分钟
6. 想换唱法又要保留旋律：固定旋律，换 seed 再跑

一首 3 分钟的歌在 4090 上四十多秒就能出，真正耗时的是前面调风格那几步。

### 翻唱模式的注意点

- 流程：SheetSage2 听录音扒出旋律谱，再按指定风格重唱
- 歌词必须贴着旋律走：用原曲歌词最稳。新写的词每行音节数要和原曲对上，重音落在相同的音上，否则会拖拍、走音、串段
- 扒谱本身出错，会一路带到成品里

### 短板

- **显卡门槛**：NVIDIA 6G 显存起步；AMD、Intel 走 Vulkan，仍是实验状态；Mac 靠统一内存运行，安装要先过系统拦截
- **单曲最长 10 分钟**，不适合长叙事歌曲或串烧
- **随机性大**：同样的词，两次生成可能差很远，一首能用的通常要试三四次
- **商用版权不确定**：模型开源，但训练数据里曲子的版权归属没人能担保，商用前要自己评估
