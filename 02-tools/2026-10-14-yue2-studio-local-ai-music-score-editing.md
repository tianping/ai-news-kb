## 概述

YuE2-Studio 是包装开源多模态团队 **M-A-P 的 YuE2 模型**的本地桌面工作站。针对 Suno/Udio 式"开盲盒"——整首歌一体生成、副歌某句跑调只能整首重抽——它改为两段式：**先生成乐谱，再做演唱**。AI 音乐的核心痛点不是音质，而是不可控。

## 核心机制：先谱后唱

1. 输入风格描述（如 `city pop, electric piano, funky bass, 108 BPM`）+ 分段歌词
2. 模型先生成 **ABC 记谱法**文本，实时渲染成五线谱（主旋律音高、时值、和弦走向）
3. 声学渲染模块再按旋律与伴奏骨架做人声演唱与全频带混音
4. 乐谱可**就地编辑**：挪音符、改调性和速度，固定曲谱骨架后重新渲染音色

把"抽卡"拉回传统的"编曲 → 录音"范式。

## 工程架构：零 Python 依赖

- 前端 **Tauri**（Rust + React），后端 **yue2.cpp**（纯 C++/CUDA 移植，类似 llama.cpp）；单个 Windows 安装包或解压即用便携版
- N 卡：自带 CUDA 12 / CUDA 13 预编译后端，GTX 900 系列到 RTX 40/50 系及专业卡，无需预装开发套件
- 显存：GGUF 多档量化，**6GB（Q5_K_M）**起步；8–12GB 可跑 Q8_0 或近无损 BF16。RTX 4090 渲染 3 分半全曲约 **46 秒**
- A 卡 / 核显：实验性 Vulkan 路径，仍推荐 N 卡

## 工作站模块

1. **扒谱翻唱**：内置 SheetSage2 听音模型，拖入人声音频 → 转乐谱 → YuE2 换风格音色重新翻唱
2. **音轨分离**：HT-Demucs，一键拆成人声、鼓、贝斯、吉他、钢琴、其他 6 轨，便于导入 Logic Pro / Ableton Live
3. **音频转 MIDI**：MuScriptor 模型，最多 34 种乐器分组，带交互式钢琴卷帘
4. **本地 LoRA/LoKr 训练**：三步向导，自动切片、对齐歌词时间戳，在本地显卡训练固化歌手音色或曲风
5. **彩蛋**：复刻 Winamp 2 界面，支持第三方皮肤、.EQF 均衡器、全屏 MilkDrop 频谱可视化

## 接入 Agent（MCP）

启动后常驻 `http://127.0.0.1:8791/mcp` 端点，暴露 **162 个**细粒度工具，可挂到 Claude Code、Cursor 等 Agent：一句自然语言 → 写分段歌词、定 BPM 与编排提示词、调本地引擎排谱、微调节奏、渲染并导出无损分轨，形成闭环。
