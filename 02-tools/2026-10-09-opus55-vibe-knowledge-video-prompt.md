## 概述

抖音正在推 #Vibe知识大赏，玩法是让 AI 直接用代码生成知识科普短片。作者用一段提示词 + Claude Opus 5.5，两小时做出一条播放 10 万+ 的科普视频，三条测试视频合计涨粉 600 多，并收到付费咨询。文章给出完整可复用提示词，以及三条同提示词、同配乐、同画风视频数据相差十几倍后的复盘结论。

两种常见形态：

1. **纯音乐 + 动效**（作者选的）——画面全由代码绘制，不用找素材、不用配音，最简单；
2. **旁白 + 图片 + 动效**——信息量更大，但要配音和素材（让 Claude 自己搜素材时务必限定可免费商用，否则易侵权）。

风格不要靠文字描述，直接垫几张参考图，模型照着做比描述半天准。作者三条都是「宣纸底 + 水墨」。

## 四步流程

**第一步：选题。** 跟热点走起量快（如诺贝尔奖刚公布、得主贡献普通人看不懂，适合动画讲）。爆款路子多半一致：借一个硬核的东西（某算法、某冷门奇特小知识），最后落到人生道理上。

**第二步：生成。** 提示词丢进 Claude Code，把 `{主题}` 替换掉。分镜、动画、渲染、音效、配乐全部由模型自己完成，最后直接产出 MP4。作者强调模型最好用 Opus 5.5——同样的提示词给 GPT 系模型，效果「惨不忍睹」。

**第三步：修改完善。** 调视觉风格时**先让它出 10 秒左右的片段**，别一上来就生成整片（省 token、省时间）。风格调对后，让模型把这套风格**提炼成通用模板**，之后换主题直接套。

**第四步：发布。** 带平台活动话题 #Vibe知识大赏 并 @抖音科技运营，好作品有机会被推广。

## 提示词全文

```
# 角色
你是一位人文纪录片导演，同时会用代码做动画。你擅长把抽象的知识讲给普通人听：不堆术语，用画面和故事让人看懂，看完还有一点触动。

# 任务
用代码制作一支 {16:9} 的纪录片风格短片，主题是「{主题}」。
- 背景音乐：{背景音乐}（默认使用桌面上的《千年之后》氛围版）。片长跟随音乐，从第 0 秒开始放，结尾随音乐自然收束。用《千年之后》时约 2 分 38 秒。
- 无口播，画面和字幕承担全部叙事。
- 全片的情绪曲线跟着音乐走：音乐的第一个重拍就是全片的第一个高潮（《千年之后》在第 17 秒）。

# 叙事
## 第一步：先找「锚词」（写任何文案之前完成）
锚词是全片的钉子：2～4 个字，是这个原理落在普通人生活里的那个处境、困惑或反直觉的瞬间，而不是术语本身。
- 好锚词的三个标准：
  ① 观众一看就有代入感，觉得「这说的就是我」；
  ② 同一个词能概括整个原理；
  ③ 结尾时能被重新定义：开头它是困境，结尾它变成理解、释然或力量。
- 示例：红皇后效应的锚词是「原地」（拼命跑，却还在原地）。按同样的思路：沉没成本可以是「舍不得」，幸存者偏差可以是「看不见的人」。
- 用法：第 17 秒的高潮把它"砸"出。

## 原则
先写观众的处境，再讲知识。知识是用来解释「你」的。开头不讲历史、不出术语；历史、人物、实验放在高潮之后。

## 钩子（0～16.4 秒）
1. 第一句：用第二人称写出观众正在经历的那个悖论或困惑。句式：「你已经……，为什么还……？」
2. 3～4 个快速画面，每个约 3 秒、配一句字幕：让同一个现象在不同尺度上各出现一次（个人 → 自然界 → 群体或社会），让观众意识到"原来到处都是"。
3. 一句收束：「所以，……」把几个画面归到同一个悖论上。
4. 13～16.4 秒：一句经典引语、一个关键数字或一个直击要害的发问，其中要含锚词，为高潮蓄力。

## 高潮（第 17 秒，必须踩准音乐）
《千年之后》在 16.5～16.9 秒有一口"换气"（接近静音），17.0 秒重拍砸下。画面这样对位：
- 16.4～16.9：画面整体收暗，所有元素淡出
- 16.9～17.0：静止约 3 帧
- 17.0 爆发：纸面骤然亮起或墨晕炸开（方式与全片画风一致），巨大的锚词同时出现（约占画宽 1/3），一圈墨痕或光环从中心向外扩散
- 17.6：锚词下方浮出一行小字：术语名（中英）
- 17.6～约 20：保持，只做极轻微的呼吸感
补充：
- 17.0 配一个低沉的冲击音效。
- 这个时间点误差不超过 2 帧。
- 换别的音乐时，先实测它的第一个"换气 + 重拍"在哪一秒，再把高潮放在那里。
- 中段正式给原理命名或揭晓关键结论时，可以再用一次小一号的爆点；全片最多两次。

# 画风
- 底色和质感：羊皮纸或米白宣纸；全片叠加胶片颗粒、纸张纹理和暗角。
- 配色由你根据画风决定，整体低饱和、温暖、克制。
- 画面里出现的数字一律用等高数字（lining figures），不要用高低错落的旧式数字。

# 转场
画面之间不要硬切，要有丝滑的过渡。优先用「同一个元素贯穿前后两个画面」来转场。例如：
- 一个圆从大变小，变成下一个画面里的太阳或烛火；
- 一条线延伸出去，变成下一个画面的地平线或道路；
- 镜头推进到某个细节，这个细节铺满画面，展开成下一个场景。
转场要短而干净，前后两个画面不要长时间叠在一起。淡入淡出、闪白、黑场只作为辅助。

# 动效与节奏
节奏舒缓，有呼吸感：镜头缓慢推进或平移，元素渐显渐隐。画面的变化和字幕、音效的出现保持同一个节拍。不要弹跳、旋转、花字、快切。

# 字幕
- 字幕就是旁白。每一屏下方只放一句中文，下面一行英文斜体翻译。
- 句子要短（中文不超过 18 字）、有诗意，可以用破折号制造停顿。
- 每句停留 3～5 秒，全片约 25～30 句。
- 字幕在任何背景上都要看得清：暗背景用浅色字，亮背景用深色字，必要时加柔和阴影。

# 声音
- 背景音乐必须加：{背景音乐}，从第 0 秒开始，结尾随音乐自然淡出。音量压到不刺耳，让少量音效也能听清。
- 音效只加少量：
  - 一层很轻的背景氛围音（风、纸页、环境底噪）；
  - 5～8 处重要音效：第 17 秒高潮、关键转场、关键结论出现、片尾。
  - 音效要轻、短、干净，不抢音乐。

# 交付
1. 先给我分镜表：段落 | 时间码 | 画面 | 转场方式 | 中文字幕 | 英文字幕 | 音效。并写明锚词，以及它在片中出现的所有位置。
2. 正式渲染前先抽几帧预览，自查有没有文字重叠、文字超出画面或纸面、看不清的地方，改好再渲染。单独检查 16.3、16.8、17.0、17.1、17.5、18.0 秒这几帧，确认高潮踩在重拍上。
3. 渲染成片：MP4，1920×1080，30fps，含背景音乐和音效。只交付这一个视频文件。
4. 列出片中用到的年份、人名、数字和引文，方便我发布前核对。
```

## 为什么有的火有的不火：四条复盘结论

三条视频（《奥德赛时期》《局部最优解》《最后相遇定理》）用同一套提示词、同一首歌、同一种画风，数据相差十几倍。

**结论一：开头要把人留住。**
- 第一秒就要有炫画面 + 一个让眼睛落脚的视觉锚点。《局部最优解》第一秒是一整片山，小山头上站着人，其中一个穿红衣服，视线自然落上去；《奥德赛时期》第一秒只有一根红线慢慢画，像张图表，太平，没留住人。
- 文案第一句要跟观众有关，别上来就讲术语讲历史，说观众正在经历的事。

**结论二：视频要有节奏。** 点赞少的视频通病是音乐情绪和文案节奏各走各的，音乐砸下来了画面文案还在慢走。好作品的做法：
- 字幕切换卡在音乐小节线上，不随便切；
- 重拍前两三秒，字幕故意只说一半（《局部最优解》第 14 秒：「想登上更高的山，你得先——」）；
- 重拍前半秒，画面整体收暗，等音乐换气；
- 重拍那一下，画面、文案、音效一起爆：纸面亮起，「下山」两个大字砸出来补完上一句 + 低沉冲击音效。

音乐高潮、画面高潮、文案高潮重叠在同一帧上。换歌就让模型先分析音频找重拍再对位。

**结论三：抛一个问题给观众。** 《局部最优解》397 条评论，另两条只有 8 条和 11 条。好问题跟观众自己有关、每个人都有自己答案——「安稳算不算人生的最优解」，正反两方都想说两句；讲迷茫、走散的那两条看完有感触但没什么可答的，就没人开口。

**结论四：转场要丝滑。** 好视频画面之间基本不硬切，一个画面自然「长」成下一个。《局部最优解》所有转场都在山水里推近、平移、拉远，看起来像一个连续长镜头，眼睛不用重新找重点。

## 变现思路

发布后即有人付费咨询，但作者认为直接收费教学难做：防封 Claude、交付都不好解决。他更看好把它当工具给**本身有知识储备的人**用——心理博主、读书博主、知识博主、心理咨询师：用一个视频把道理讲透，吸引同频的人，再建陪伴群变现。当下的窗口是有流量、适合起号。
