# 中科院计算所赵屹团队 BioMedAgent：自进化多智能体让 67 种生信工具自动串成分析流程

- **日期**：2026-09-29
- **来源**：生信观测局（微信公众号），报道自 Nature Biomedical Engineering（IF 26.3）2026-03-30 在线发表
- **URL**：https://mp.weixin.qq.com/s/T5lpC383QlS9IRijAblcdA
- **论文**：DOI 10.1038/s41551-026-01634-6
- **分类**：AI 工具 / 智能体 × 生物医学

## 一句话概括

中科院计算所赵屹团队（联合陈润生院士团队、澳门科技大学张康团队）在 Nature Biomedical Engineering 发表 BioMedAgent：自然语言进、完整分析报告出，三阶段多智能体流水线（Planning/Coding/Execution）+ 三大支撑系统（本地工具 LTU、记忆检索 MR、交互探索 IE），预集成 67 种生信工具，在自建 327 任务基准 BioMed-AQA 上取得 77% 总体成功率。

## 框架设计

**三阶段流水线**：Planner 规划 → Programmer 编码 → Executor 执行

**三大支撑系统**
- LTU 本地工具层：预集成 67 种专业生信工具（BWA 比对、Bowtie2、GATK 变异检测、Samtools、vcf2maf 注释、Intervar 临床解读等本地工具 + Web API），Docker 容器化解决环境依赖；选工具两轮检索（先语义相似度，再上下游依赖关系）；工具缺失时由智能体生成自定义工具代码（CTC）补位
- MR 记忆检索：把成功经验拆成三类——Tool（适用场景与用法）、Workflow（最优分析流程）、Code（可复用代码片段）；新任务按语义相似度检索 Top3 最相似记忆复用；更新策略 CMA（连续记忆积累，保留全部）vs IMF（迭代记忆遗忘，只保留步骤最少的最高效解），论文结论 IMF 收敛更快、更稳、内存占用更小
- IE 交互探索：执行失败时把错误回溯到编码或规划阶段重新生成重试（最多 3 轮），成功经验随后写入记忆库；约 48.6% 任务在编码阶段需要至少 1 轮额外交互，30.5% 在规划阶段需要

## 评测结果（BioMed-AQA：327 任务）

- 任务分布：组学分析 O 96、精准医学 P 18、机器学习 M 59、统计分析 S 58、数据可视化 V 96；子集 BioMed-AQA-MCQ 含 172 道多选题
- 总体成功率 77%（O 94%、M 90%、P 78%、V 65%、S 59%）
- 消融链条：无 IE 28% → 加 IE 52% → 加 MR 后 1 轮 70% / 2 轮 75% / 3 轮 77%
- 对照：ChatGPT (GPT-4o) 46%、GPT Assistants 39%、GPT function call（含 IE）33%（无 IE 时 26%）；可分析范围 BioMedAgent 100%，另两者 68% 与 65%
- 换基座：DeepSeek v3 仍 77%（M 类 98%）、Qwen3 75%，说明提升不完全依赖特定基座模型
- MCQ 子集 76%

## 外部泛化与同类框架对比

- BixBench（54 真实场景、296 问题）：不依赖领域专用工具时，开放题约 49%、含拒答项多选题约 49%、无拒答项多选题 63%，均优于官方基线（后者无拒答项基线约 55%）
- 同类框架中 BioMedAgent 是唯一在规划/编码/执行、自然语言指令、本地工具调用、自定义工具代码、多智能体、自进化、评测规模等维度全部具备的，规模远超 BIA（15 题）、BioMaster（20 题）
- 工具收益单独量化：使用本地工具任务 Win score 显著高于不使用（p<0.001）；成功任务中 46.25% 仅用本地工具、28.85% 仅用自定义代码、24.90% 两者并用

## 三个真实科研场景

1. **NSCLC 跨组学分析**：三条自然语言指令完成 67 例 bulk RNA-seq 差异基因分析 + 22 个 scRNA-seq 矩阵聚类与标记基因识别 + 跨组学整合，共识别 1831 个差异基因（与 GEO2R 一致性 78%）；发现 ABCC3、SERINC2、SEZ6L2 三个基因主要在上皮细胞高表达，与肺癌耐药和预后相关
2. **复现机器学习研究**：一条指令在 ctDNA 液体活检数据上构建随机生存森林（RSF）模型并评估，复现 c-index 与原文完全一致（KS 0.61、LB+ 0.73、All 0.74），验证液体活检模型优于传统 Khorana 评分
3. **病理图像细胞分割**：接入超分辨率工具 MiHATP 后自动完成分辨率增强、细胞分割与 Dice 评估，四类细胞 Dice 均有提升（炎症细胞 +0.87%、上皮细胞 +0.49%、纺锤形细胞 +2.18%、其他 +1.74%，整体 +0.86%），剩余提升空间填补率约 29.9%

## 边界（论文自述）

- 统计分析（59%）与数据可视化（65%）仍是明显短板，会调工具不等于会做统计推断、会出好图
- 提升主要来自工具使用与记忆机制，而非基座模型规模
- 评测依赖自建 BioMed-AQA，第三方独立复现仍需时间
- 工具缺失时退化为生成自定义代码，稳定性低于直接调用成熟工具
