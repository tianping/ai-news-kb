# 实测 Opus 5.5 生成科普动画视频（附提示词）（莫影AI）

- **日期**：2026-09-30
- **来源**：莫影AI（公众号），https://mp.weixin.qq.com/s/X1_WYeMM3sjGxkRsofN2Rw
- **分类**：02-tools / Opus 5.5 视频工作流

## 概述

莫影AI 用 Claude Opus 5.5（High 思考档）的 Cowork 模式实测「纯代码做恐龙科普动画」：手机只打了两句话、点了三个选项（画幅/时长/声音），Opus 自主完成写脚本、配音、画画、配乐音效、出片、自我验收全流程，生成一部 2 分多钟 1080p 动画（4479 帧），零图片素材，全代码生成。文章同时附了可复用的提示词模板。

## 关键内容

### 实测过程

- 派活提示词第一句（原话）：「纯代码实现，以一个小三角龙的视角，来讲述恐龙进化史，生成一个动画视频，要生动且引人入胜。」
- Opus 先反问 3 个问题，点选即可：
  - 画幅：横屏 16:9
  - 时长：约 2 分钟
  - 声音：AI 配音 + 字幕 + 配乐
- 看完第一版后修改指令（第二句）：「恐龙名字叫小角。选择适合的开源 TTS 进行配音，配音要选中文友好的模型。」
- 就这两句话，剩下的全是它自己干的

### Opus 自己干的 6 件事

1. **写脚本**：先写旁白和分镜，12 个场景、38 句旁白（故事全 AI 设计）
2. **配音**：在线配音服务连不上，自己换成离线开源模型；每句配完用语音识别"听"一遍，揪出读错的字
3. **画画**：小角、始盗龙、马门溪龙、近鸟龙、霸王龙，火山/森林/博物馆，全代码一笔一笔画
4. **配乐音效**：BGM、巨龙脚步声、小行星撞击轰鸣、鸟叫，全代码合成，没用素材库
5. **出片**：浏览器逐帧截图，4479 帧，合成 1080p 高清视频
6. **自己验收**：渲染完自己抽帧检查，发现字幕挡小角、霸王龙只露一小块、换场景时两个画面角色叠一起，改完重渲

### 故事内容（AI 自己设计）

深夜博物馆，小三角龙化石"醒"了，叫小角，6600 万岁，带你坐时光隧道回到 2.52 亿年前，看到今天窗外小麻雀。12 场景：二叠纪大灭绝 → 第一批恐龙 → 恐龙家族树 → 侏罗纪巨龙 → 长羽毛恐龙 → 角龙家族 → 小行星撞地球 → 鸟类活下来。细节亮点：右上角地质年代时间轴（讲到哪代小圆点跟到哪）、小角说话嘴型跟配音一合、马门溪龙画测量线（脖子占全身约一半）。

### 技术细节

- 配音模型：Opus 自动选了小米团队开源的 **ZipVoice**（中文友好）；作者说效果一般无伤大雅，可自己指定 TTS（豆包、千问都不错）
- 出片方式：浏览器一帧一帧"拍"（Playwright 类工具）+ ffmpeg 合成
- 作者原话：用 Cowork 模式做的，Claude Code 也行；普通网页聊天框做不了，因为得在电脑环境画图/配音/渲染

### 可复用模板（原文，【】内换掉）

> 用纯代码做一个【约 2 分钟】的【横屏 16:9】动画视频：以【一只小三角龙】的视角，讲【恐龙进化史】，给【小学生】看，要生动有趣。要有字幕、配乐和音效。

换主题即可：【一滴水的旅行】【一颗种子长成大树】【太阳系八大行星】……
