# Codex + Blender 做 IP 角色建模像提线木偶，换付费 Tripo 才像（予贝AI）

- **日期**：2026-10-23
- **来源**：予贝AI
- **分类**：02-tools 工具与产品（3D / Blender）
- **URL**：https://mp.weixin.qq.com/s/fHLYgIzxJjhNz8kIX5pkkQ

## 概述

作者想把自己的卡通头像 IP（棕色卷发、圆框眼镜、橙色外套）做成可旋转的 3D 模型。先用 Codex 通过 MCP for Blender 直接建模：特征都在，但「看着像提线木偶」，不像原角色。改用付费的 Tripo 多视角生成后，效果好得出乎意料。结论：**结构清楚的风格化小场景可以用 Codex + Blender；需要高度还原的人物 IP，有预算就直接用 Tripo**，之后再回到免费的 Blender 调灯光、角度和出图。

## 流程

### 1. 先准备三视图参考

只给一张头像，头像里没出现的部分（侧面头发厚度、外套背面、背包和肩带）都要 AI 自己编，参考越少越容易跑偏。用支持参考图的 AI 绘图工具生成三视图：

> 根据这张头像，制作同一个卡通角色的建模参考图。保留人物的脸型、发型、眼镜、主要配色和整体风格。在一张图里并排展示全身正面、侧面和背面。三个视图使用相同的角色比例、服装与配饰，人物高度和站立位置对齐。采用简单自然的站姿，双臂略微离开身体，方便看清衣服与身体轮廓。背景干净，不要文字和遮挡。头像没有展示的服装部分，先给出设计建议，确认后再补齐全身参考图。

- 检查三个角度是否一致：眼镜、发型、领口、配饰要对得上
- 给 Tripo 时要拆成**正面、左侧、右侧、背面四张独立图**分别上传，不要传拼图

### 2. 安装 Blender 与 MCP

- 从 blender.org 下载安装，先启动一次确认正常；新建一个项目文件夹在 Codex 里打开，参考图、工程、渲染图都放在这里
- 让 Codex 自己装 MCP：

> 帮我在这台电脑上安装并配置 MCP for Blender，让 Codex 能够连接 Blender。先检查 uv、Blender 插件和 Codex 里的 blender MCP 是否已经配置；已有的不要重复安装。如果尚未配置，请按照 MCP for Blender 的官方安装说明完成安装，选择 Codex 作为客户端，保留我已有的其他 MCP 配置。完成后告诉我安装了什么、还需要在 Blender 界面里做什么。先不要修改当前 Blender 场景。

- 配置完要**完全退出并重启 Codex**，新的 MCP 连接才会生效

### 3. 验证连接

- Blender：编辑 → 偏好设置 → 插件，搜「MCP for Blender」并启用；在 3D 视图按 N 打开侧栏，启动服务，面板显示 `Connected on port 9876`
- Codex 里先做只读测试：

> 检查 Blender MCP 连接，只读取当前场景，不要创建、删除或修改对象。告诉我当前场景里有哪些物体，以及选中了什么。

- 能读到默认立方体、相机、灯光和当前选中物体，才算真正连通
- 报 `Could not connect to Blender` 时：检查 Blender 和插件服务是否开着、Codex 是否完全重启过

### 4. Codex 建第一版

> 根据提供的头像和角色参考图，通过 Blender MCP 制作一个静态卡通人物模型。保留棕色蓬松卷发、黑色圆框眼镜、橙色外套、浅色连帽衫、深色裤子、浅色鞋子和双肩包这些主要特征……各部分合理命名……输出正面、侧面、背面的预览图。保存可继续编辑的 .blend 工程，并导出 .glb 模型。

- 第一轮只做静态角色，不加骨骼和动作，集中检查造型
- 结果：交付了能打开的模型和三视图，需求清单上的东西都有，但整体像提线木偶
- 让 Codex 继续修改，反而更难看，还耗了很长时间

### 5. 换 Tripo

- Tripo Studio：https://studio.tripo3d.com/
- 在多视角入口分别上传四张独立参考图（服装、比例、站姿要一致）
- 效果：卷发有层次，眼镜贴合脸部，外套和连帽衫有自然褶皱，背面的背包、帽子、头发都对得上，辨识度高得多
- 不付费的话只能单图生成，导出只能用 v2.5 模型，效果稍差
- 生成后转到侧面、背面检查发型、双手和配饰，确认后再导出 GLB

### 6. 回到 Blender 做小调整

- 灯光、整体比例、朝向、镜头这类小改动，在免费的 Blender 工程里改，不必每换一个画面都重新生成
- 修改前先另存一版，保留原始 GLB

## 结论

- 人物 IP 难在「像不像」：脸型、头发、眼镜比例一偏，特征都在，看着还是不像
- Codex + Blender 适合结构清楚的风格化小场景（作者之前做的茅草屋，屋顶、门洞、木梁、柴薪、编篮都像样）
- 需要高度还原的角色：Tripo 付费多视角生成做底子 → Blender 免费调整出图
