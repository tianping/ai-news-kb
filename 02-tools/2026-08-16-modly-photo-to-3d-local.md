# 有人开源了一个拍照生成 3D 模型的软件，全程跑在自己显卡上

> 来源：[有人开源了一个拍照生成 3D 模型的软件，全程跑在自己显卡上](https://mp.weixin.qq.com/s/81y7ZjqIYK26auJbWScaYQ) · 2026-08-16

---

## 概览

**modly** 是一个开源桌面软件，把一张图片变成 3D 网格模型，所有模型推理全程在本地显卡上跑，不上传图片、不需账号、无 API key。

- 仓库：https://github.com/lightningpixel/modly
- 支持：Windows / Linux / Apple Silicon Mac

---

## 核心特性

| 特性 | 说明 |
|------|------|
| **完全离线** | 模型下载到本地后，整个生成过程离线运行，数据不出设备 |
| **多模型支持** | 可切换不同生成模型：Hunyuan3D 2 Mini、TripoSG、Trellis2 等，采用扩展机制 |
| **后处理内置** | 生成后可直接在软件内平滑、减面，导出 GLB 格式 |
| **批量处理** | 提供可视化流程编排界面 + 命令行工具，支持批量处理 |
| **免账号** | 无需注册、无需 API key，下载安装包即用 |

---

## 解决什么问题

| 传统方案 | 痛点 | modly 方案 |
|----------|------|------------|
| 三维扫描仪 | 贵，小件难扫 | 一张照片生成，成本为零 |
| 在线服务 | 传图、按次收费、数据留服务器 | 本地跑，数据不出设备、免费 |
| CAD 手工建模 | 耗时、需专业技能 | 自动生成，再微调导出 |

## 适用场景

- 实物快速建模（电商、设计、逆向工程）
- 3D 打印前的模型准备
- 游戏/元宇宙资产快速制作
- 任何不想上传图片到云端的 3D 生成需求

---

## 快速上手

1. 去 [Releases](https://github.com/lightningpixel/modly/releases) 下载对应平台安装包
2. 安装打开软件
3. 在软件内下载所需生成模型（Hunyuan3D 2 Mini / TripoSG / Trellis2 等）
4. 导入图片 → 生成 → 平滑/减面 → 导出 GLB

---

## 意义

> 把「拍照 → 3D 模型」这条路径从「云端付费服务」拉回「本地免费离线」，配合开源模型生态（Hunyuan3D/Tripo/Trellis），让个人开发者、设计师、Maker 都能零门槛拥有图生 3D 能力。
