# 两天手搓一条AI剧情短片（新手跟练版）

> 来源：[两天手搓一条AI剧情短片（新手跟练版-附完整制作流程）](https://mp.weixin.qq.com/s/bS80thseGnkET2M3qmJchg) · 2026-08-12

## 概述

作者从0到1花两天手搓了一条现代甜宠爱情短剧第一集，总成本不到300元。完整记录从灵感→剧本→分镜→角色设计→视频生成→剪辑的全流程，附踩坑经验。

## 完整制作流程

### 1. 剧本创作（工具：DeepSeek）
- 先从整部剧的定位和走向与AI交流（现代爱情·甜宠双强·破镜重圆·自我成长）
- 逐步打磨：人物小传→分集大纲→单集剧本
- DeepSeek vs 豆包：对剧作需求捕捉更精准，主动抛选项、反向提问，帮补全细节
- **关键**：AI出的剧本必须自己逐字逐句改，直接用原稿会流于模板化

### 2. 提示词分镜（工具：LibTV自带脚本功能）
- 把完整剧本丢进LibTV，自动拆分镜、标景别、写画面描述
- AI出分镜只当底稿，再手动改成AI视频模型更易懂的提示词语句
- 按「镜头组」来做，一组控制在15秒左右，性价比最高、一致性可控

### 3. 长视频生成实测
- **Seedance 2.5**：标准模式单段最长30秒，长视频模式最长3分钟，人物场景连贯性更好
- **LibTV超长视频模式**：多节点工作流，一次生成最长5分钟，不用手动拼接
- **缺点**：贵！积分消耗远高于短镜头，等定稿后再用长视频模式出最终版

### 4. 角色&场景图生成
- **主角图**：豆包/Midjourney出初稿→banana改图精修，素材越清晰视频还原度越高
- **融合真人照片**：LibTV上传真人照+AI角色图，要求50%相似度，保留特征又避开真人限制
- **不要在LibTV直接生图**：自带磨皮模糊感，质感差；豆包真人生图质感提升明显
- **场景四视图**：尽可能生成场景四视图保证空间一致；720度全景图截角度再重新生成正式场景图
- ⚠️ 不要直接用全景截图生视频，画面发灰、细节差

### 5. 视频生成5条实操经验

1. **提示词加镜头时长**：虽不会精准到秒，但整体节奏更可控
2. **人物对话细节要足**：神情、动作、语气、状态全写进去；标点符号影响AI表现（感叹号情绪强、逗号有停顿、句号平缓、波浪号可爱）；手机录一遍台词掐时间对应视频时长
3. **同场景换视角**：先截图生成去人物纯空镜场景图备用，后续切角度时当参考，色调布局光影更统一
4. **上下衔接镜头写死站位**：AI无上下文记忆，提示词必须重写人物站位、朝向、相对位置，否则穿帮
5. **关键镜头不加BGM**：有台词和关键音效的视频加「不要背景音乐，不要文字字幕，保留音效」；空镜过渡镜头可不限，AI自带音乐偶尔适配度意外高

## 剪辑收尾

1. **粗剪**：全部导入剪映按剧情顺序粗拼，完整拉片找问题
2. **重制技巧**：单个镜头单独重生成，成本低可控性强；只有强连贯片段才整段重制
3. **精剪**：配BGM和音效，卡节奏，有停顿有留白，让片子有呼吸感

## 关键踩坑

| 踩坑 | 解法 |
|------|------|
| LibTV直接生图质感差 | 外部工具出图再上传 |
| AI空间感知弱（车内、座位等） | 补带人物站位的场景参考图 |
| 视频中有文字内容 | 先生成带文字的图片再生视频 |
| 同场景前后像两个地方 | 截空镜图当统一参考 |
| 上下镜头人物瞬移 | 提示词重写站位朝向 |

## 总结

- 总成本不到300元，耗时两天（以前需小团队一周）
- 工具飞速迭代，创作门槛越来越低
- 当所有人都能用AI生成画面时，真正稀缺的是好故事、好审美、不随波逐流的表达
