# Codex + ChatCut：AI视频剪辑外贸获客实战（10天55条视频）

> 来源：微信公众号文章 · 2026-08-11 · [原文链接](https://mp.weixin.qq.com/s/mXOr_CVehkKU2Ligrx1gIQ)

## 概述

作者将剪辑软件里反复拖时间线的工作交给 Codex 和 ChatCut，10天内发布55条外贸视频，收到23个精准咨询，筛出8个高意向客户，5个进入正式对接。

核心不是"AI自动剪完就能成交"，而是把脚本、剪辑、字幕、平台适配、客户背调和跟进拼成一条可重复运行的获客流程。

## 工具关系

- **ChatCut**：第三方AI视频剪辑工具，把素材区、预览窗口、转录面板和多轨时间线接入AI可操作的剪辑工作台
- **Codex**：理解需求、拆解任务、调用工具、检查结果
- Codex 负责决策，ChatCut 负责执行视频处理
- 与 Remotion（React模板）和 HyperFrames（HTML动效）不同，ChatCut 优势是接手已拍好的真人素材

## 五步工作流

### 第一步：保存原始版本，再让AI动手
每次剪辑先保存原始快照，每完成一个阶段再保存：
- `00-原始素材-未剪辑`
- `01-口播粗剪`
- `02-平台时长版`
- `03-字幕完成`
- `04-发布前版本`

AI可能删错内容或识别错术语，保留版本可随时退回。

### 第二步：先让Codex写脚本，再上传素材
不直接丢素材说"帮我剪好看"，而是先确定客户是谁、关心什么、结尾引导什么。

脚本模板：
- TikTok：15-30秒，前三秒出现工厂或产品钩子
- LinkedIn：45-60秒，突出项目案例、产能和交付能力
- YouTube Shorts：30秒，围绕产品核心搜索词展开

每套含：旁白、画面顺序、镜头时长、字幕文案、结尾行动引导。

### 第三步：一条指令完成第一轮粗剪
关键要求：**先给拟删除清单，等我确认。**

指令要点：
1. 删除停顿、口误、闲聊、无效空镜和重复镜头
2. 保留车间全景、生产工序、质检、成品包装四类画面
3. 按"工厂实力→生产过程→质量检查→成品交付"排序
4. 片段间用克制淡入淡出
5. 成片时长控制29-30秒
6. 保留原始项目和可编辑时间线

### 第四步：字幕、配音和BGM一起处理
设置边界：
- 美式商务男声，语速约110词/分钟
- 英文字幕放底部安全区，统一无衬线字体
- 产品名/型号/参数/行业术语必须与术语表一致
- 轻量纯音乐，音量约为旁白的30%
- 无法确认的人名/数字/专业词标记，不擅自改写

### 第五步：一条素材导出三种平台版本
- 9:16 竖版：TikTok/Reels，主体居中，字幕上移
- 1:1 方版：LinkedIn/Facebook，核心产品与工厂标识不被裁切
- 16:9 横版：YouTube/官网，保留原始构图

统一1080P MP4导出，导出后分别预览检查裁切问题。

## 客户背调：Codex继续介入

客户私信后，把公司名交给Codex整理B端客户初筛报告：
1. 公司主营和目标市场
2. 可能的采购角色
3. 与我方产品的匹配点
4. 需要进一步确认的问题
5. 一封简短、克制、不夸大能力的首次跟进邮件

只使用公开可验证信息，不编造客户规模/订单/合作品牌。

## 关键经验

- **B端内容筛选从脚本阶段开始**：少讲个人体验和外观颜值，多讲产能、定制能力、交期、认证、项目落地
- **结尾行动引导决定客户质量**："喜欢就下单"吸引消费者；"批发、OEM或项目合作请私信索要参数"才接近B端
- **每条视频都要有明确的客户对象和下一步动作**
- **AI剪完一定要看成片**：检查数字、型号、字幕、品牌标识、语义限定条件和画面裁切

## ChatCut vs 传统剪辑 vs 代码生视频

| 场景 | 传统剪辑 | ChatCut | Remotion/HyperFrames |
|------|----------|---------|---------------------|
| 真人口播粗剪 | 手动找片段 | 自然语言处理时间线 | 不适合 |
| 字幕和术语核对 | 手动修改多 | 可先生成再复核 | 需自建逻辑 |
| 多平台尺寸 | 逐个调整 | 批量适配 | 程序化模板 |
| 固定模板批量 | 重复操作 | 可协助 | 更适合批量渲染 |
| 复杂创意/调色 | 更成熟 | 仍需人工调整 | 需额外开发 |

## 注意边界

1. ChatCut是第三方接入，不等于Codex原生视频剪辑功能
2. 安装：`Read chatcut.io/chatgpt to install the ChatCut plugin`
3. AI代理执行/配音/音乐/渲染可能消耗积分，执行前看估算
4. 涉密素材（未发布产品/客户项目/独家工艺/人员肖像）先确认版权隐私
5. AI剪完必须人工看成片
