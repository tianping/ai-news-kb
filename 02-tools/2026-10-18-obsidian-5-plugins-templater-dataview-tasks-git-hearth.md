- **Dataview**（401 万下载）：把整个库当数据库查询
- **Tasks**（334 万下载）：跨笔记汇总任务，支持到期、循环、筛选

## 逐个说明

### Templater
- 模板在生成那一刻自动填好内容：当天日期、当周周一、根据文件名算出第几篇等
- 可以写 JS 脚本读库内容、生成目录、调接口
- 作者用例：新建项目笔记时自动在底部生成"待办"区，并把项目路径写进 YAML
- 安装：社区插件市场搜 Templater，设置里指定模板文件夹

### Dataview
- 用类似 SQL 的语句列出符合条件的笔记，如"标签是 #reading、状态未读的书""这周改过的项目笔记"
- 新手先记三个词：`FROM`（从哪找）、`WHERE`（筛什么）、`SORT`（怎么排），能覆盖八成场景
- 前提是笔记带标签和元数据（YAML 属性）。先养成加属性的习惯，再上 Dataview

### Tasks
- 解决原生复选框散落各处、没有全局视角的问题
- 写法示例：`- [ ] 写周报 📅 2026-09-20`，自动汇总、按截止日排序、逾期标红；配完成日期可统计每周完成量
- 循环任务：`every 2 weeks`，每完成一次自动生成下一次

### Git（Obsidian Git）
- 定时把库提交到 Git 仓库（GitHub、Gitee 均可），可回退到之前的版本，也能多台电脑同步
- 初次配置要装 Git、建仓库、设自动提交间隔，新手约需 20 分钟
- 它管的是版本，不是实时云同步。要手机电脑秒同步，需配远程仓库加自动推送，或另用 Syncthing、Remotely Save

### Hearth
- 作者 ondreu，2026 年 6 月底发布，2.5 万下载、139 个 GitHub Star
- 纯拖拽、零代码：30 多种卡片组件，所见即所得；毛玻璃、圆角、主题色在设置面板里点选，不怕软件升级后 CSS 布局乱掉
- 自动识别已装插件：库里有 Dataview、Omnisearch 时直接提供对应卡片
- 多套仪表盘（工作/学习/个人），可绑快捷键切换；手机端自动切成简约模式

## 组合建议

1. 从零开始：先装 Templater 和 Dataview，把"写"和"查"跑顺
2. 再加 Tasks 管待办
3. 有稳定内容后上 Git 做备份
4. 最后用 Hearth 收拾首页
- 已有稳定 Dataview + CSS 首页的老用户不必为了好看换 Hearth；想做首页又怕写代码的人最适合它
