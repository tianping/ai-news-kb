## 核心观点

- 碎片化时代，读者只给 **3 秒**。开头没抓住注意力，后面内容再好也是白搭
- 咪蒙 911 篇文章拆解后发现：她 **从来不铺垫**，第一句话就"炸"
- 不写"最近发生了一件事""今天想跟大家分享"之类的引入语
- **开头不是"引入"，开头是"钩子"**

## Skill 功能

- 输入一句"这篇文章想表达什么"
- 用 8 种模式各生成一版开头
- 用户选最炸的那个

### 示例（话题：催婚）

| 模式 | 生成开头 |
|------|---------|
| 自己写的（反面） | "最近过年回家，又被催婚了，想跟大家聊聊。" ← 像请柬 |
| 反常识式 | 「催婚的本质不是关心你，是怕自己没面子。」 |
| 场景式 | 「年夜饭第三道菜还没上，我妈已经开始介绍相亲对象了。」 |
| 拷问式 | 「凭什么我28岁不结婚就是"有问题"？」 |
| 悬念式 | 「我妈今年过年没催婚。我反而慌了。」 |
