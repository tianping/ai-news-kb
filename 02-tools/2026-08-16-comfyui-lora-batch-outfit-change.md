## 概览

一套 ComfyUI 商用级万能工作流，搭配 LoRA 模型实现"一键批量换装"：在保持面部与姿态完全不变的前提下，精准替换服装纹理、色彩、版型、褶皱细节。适用于电商服装展示、人物写真、广告视觉设计等商业场景。

---

## 核心原理：三步走

| 步骤 | 说明 |
|------|------|
| **① 特征提取** | 读取衣物图 → 提取纹理、颜色、版型、褶皱特征 |
| **② 遮罩定位** | 人物照标记替换区域（白遮罩=重绘，黑遮罩=保持） |
| **③ 精准迁移** | LoRA 将衣物特征"绘制"到遮罩区域，姿态与面部零失真 |

**核心优势**：动作零失真——无论肢体姿态多复杂，生成后关节角度与肢体比例完全复刻原图。

## 三大主流方案对比

| 方案 | 核心模型 | 输入要求 | 适用场景 | 特点 |

| **Flux Klein** | Flux Klein LoRA | 人物照 + 上衣 + 下装（或全身套图） | 电商选品、快速打样 | 三图输入，主打"快"与"准" |

| **Qwen** | Qwen Edit + Consistence LoRA | 模特图 + 参考衣物图 | 高一致性要求 | 极少像素偏移 |

**选型建议**：
- 新手/追求效率 → **Flux Klein**
- 追求商用级画质 → **ACE++**
- 追求最高一致性 → **Qwen**

## ACE++ 核心工作流搭建实操

### 环境准备
- 硬件：NVIDIA 显卡，**8GB+ 显存**（XL 工作流需 12GB+）
- 软件：ComfyUI + 基础模型（推荐 Nunchaku，性价比高、避免显存溢出）+ ACE LoRA 模型

### 关键步骤：图像预处理（最关键）
1. **衣物图背景移除**：必须移除背景杂物，确保特征提取纯净
2. **双图拼接与遮罩制作**：
   - 左侧：衣物图（仅作特征参考，黑遮罩=不重绘）
   - 右侧：人物图（重点重绘区域，白遮罩=替换新衣）
3. **遮罩优化**：反向、模糊边缘节点处理，避免生硬"贴图感"

### 特征迁移执行
- ACE 插件 LoRA 学习左侧衣物特征 → 绘制到右侧白色遮罩区域
- 采样器同时接收：ControlNet 姿态信号（锁定关节）+ Redux 700+ 特征 Token（精准描述高领、褶皱、螺纹细节）

### 生成与优化
1. 初稿生成
2. 局部重绘：仅选衣物区域优化，不影响面部和头发
3. 精准贴回：裁切恢复节点将重绘部分贴回原图（类似"局部美颜"）
4. 图像放大：细节不足可开 8K intricate details，AI 补全面料纹理

## 常见问题与解决方案

| 问题 | 解决方案 |
|------|----------|
| 服装边缘生硬 | 检查遮罩边缘模糊处理，用"模糊边缘"节点让过渡自然 |
| 人物姿态变化 | 检查 ControlNet UniPose 2.0 是否正确接入，充当"动作保镖" |
| 纹理细节不足 | 后处理放大增强——Flux 自带放大或开启 8K intricate details |
| 复杂姿势效果差 | 手脚交叠、严重遮挡时残留错误，优先简单姿势，复杂场景人工修正 |
| 显存不够 | 启用 `--lowvram`（性能降约 40%）、缩小尺寸、或用在线平台（Running Hub） |
