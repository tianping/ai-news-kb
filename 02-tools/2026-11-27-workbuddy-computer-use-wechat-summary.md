## 概述

WorkBuddy 继浏览器操控之后上线 **Computer Use**（智能体「电脑应用操控」，目前**众测中**）：AI 看屏幕、移鼠标、点按钮、打字，直接操作桌面软件。作者用它操作微信整理群消息，再接「微信流」的场景 Skill 和微信 CLI 把内容沉淀成本地知识。作者称此前用 Codex 的 Computer Use 操作微信会让微信闪退，WorkBuddy 更稳（腾讯自家生态）。

实践会同步到开源蓝皮书：https://github.com/AlephAITech/WorkBuddyGuide

## 开启方法

1. WorkBuddy 设置 → 智能体 → 找到「电脑应用操控」→ 安装
2. 给 WorkBuddy Computer Use 开**辅助功能**和**屏幕录制**权限（macOS）
3. 对话框右侧可实时看到操作过程，微信里能看到它的光标

## 场景一：微信群消息自动整理（主场景）

- **痛点**：每天几千条未读，有价值内容被刷走；以前用「微信流」要手动选聊天记录、手动转发
- **做法**：让 WorkBuddy 打开指定群（例：DeepSeek 交流群）→ 把最近消息转发到微信流 → 调用「公众号文章提取 Skill」处理群里分享的文章 → 结果存到本地指定文件夹
- **定时化**：让它建定时任务，每天早上整理指定群聊，起床直接看汇总；群友分享的技术文章、开发经验走不同场景 Skill 沉淀
- 也可以直接把聊天记录转发给 WorkBuddy 让它分析
- **实测**：链路能跑通，但通过 Computer Use 操作微信**速度慢**

### 代发消息

让它给指定好友发消息：搜索好友→打开聊天窗口→输入→发送，全程不用动手。作者认为适合销售/运营的重复沟通（产品咨询、发资料、同步订单、社群通知），可结合业务资料和话术生成回复、**确认后再发**。但作者也说太慢，且全自动发消息本身是麻烦事，**不建议这么用**。

## 场景二：电脑体检与清理（Mac）

- 几分钟出一份体检报告：磁盘空间、长期未用的大文件、系统性能、开机启动项、电池健康、优化建议，以及内存压力/负载偏高的可能原因
- 把可清理的缓存和临时文件列成**待确认清单**（浏览器缓存、应用缓存、安装包、开发日志、崩溃报告），确认范围后移到**废纸篓**（不是直接删除）
- 自己打开系统设置 →「登录项与扩展」，检查登录启动项、后台活动、应用更新器，并标注每个程序的用途
- ⚠️ 作者提醒：涉及删文件一定仔细核对，重要文件提前备份

## 场景三：WPS 表格数据清洗与分析

告诉它文件位置和处理要求（例：桌面上的销售明细表），它自己找到文件、用 WPS 打开、清洗处理并**另存为新表**。与网页版 AI 相比，省掉了上传和下载这两步。

## 场景四：整理 PDF 准备打印

一个文件夹里混着扫描件、旧版本、微信存下来的图片 → 让它合并成一份适合打印的 PDF，横版页面也自动转成竖版。

## 要点 / 我的判断

- 浏览器操控（11-03）→ 桌面软件操控（本篇），WorkBuddy 正在补齐 Computer Use，卖点是和微信、企业微信、腾讯会议、腾讯文档这类腾讯产品打通
- 安全设计跟上一篇一样：**写操作先列清单确认**（删文件、发消息）
- 局限：慢、众测阶段；微信自动化有账号风控风险（原文没提，自己判断）；原文是作者体验分享，没有量化测试
