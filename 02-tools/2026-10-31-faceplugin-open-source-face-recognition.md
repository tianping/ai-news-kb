# Faceplugin：号称全球首个完全免费开源的人脸识别 SDK

- **日期**：2026-10-31
- **来源**：微信公众号「蒸汽记忆」

## 概述

人脸识别方案大多要么收费、要么偷偷上云。Faceplugin 把整套人脸识别 SDK 开源，号称全球第一个彻底免费、开源的人脸识别库，Windows 和 Linux 都能跑，GitHub 已获约 3.1k star。

## 主要特性

- **纯本地运行**：数据不出设备，不联网、不上云
- **CPU 即可运行**：无独显也能用，适合低配机器做本地项目
- **Python 接口简单**：人脸检测、关键点定位、特征比对齐全，可判断两张脸是否为同一人
- **跨平台**：支持 Windows / Linux

## 与国内主流方案对比

| 方案 | 类型 | 授权情况 |
|---|---|---|
| InsightFace | 开源首选 | 代码 MIT，但预训练模型限制非商用，商用需单独授权 |
| 虹软 / 百度 | 离线商业 SDK | 商业授权 |
| Faceplugin 开源版 | 开源 | 官方确认可免费商用，无需额外 license |

## 局限

- 精度和活体检测能力弱于 Faceplugin 自家商业版
- 也低于 InsightFace 成熟模型及虹软/百度正式 SDK
- 生产环境若对精度或活体有要求，建议评估商业版

## 备注

适合隐私敏感、离线、低成本的人脸比对场景（门禁原型、本地相册聚类等）；正式落地前需自行测试精度。
