## 概述

Opus 5.5 是纯文本模型，却因一批高水准视频刷屏（AI 视角写给末日论者的 MV、el.cine 配 Seedance 2.5 的电影级片段、Kevin Ngo 用 Python 写钢琴曲 + Blender 渲染的 3D 治愈动画）。本文讲清它"怎么做出视频"，并用 7 个场景演示用法，附可直接复用的长提示词。

## 原理：代码驱动渲染 vs 扩散模型

| | 扩散视频模型（Seedance / Sora） | Opus 5.5 代码生成视频 |
|---|---|---|
| 生成方式 | 猜下一帧像素 | SVG / Canvas 2D / WebGL / Three.js 逐层绘制，时间轴 + 缓动曲线控制动画 |
| 声音 | 模型自带或另配 | 配乐、音效、旁白都由代码生成，按时间点精确卡点 |
| 输出 | 直接出视频 | 无头浏览器逐帧截图 → FFmpeg 合成 MP4 |
| 修改 | 开盲盒，改细节要整条重生成 | 改代码即可，"改哪动哪" |
| 擅长 | 武打/科幻/实拍感大片 | 精准可控的动效、图形、排版 |

作者认为爆火的关键是 Opus 5.5 在**审美直觉**和**工程纠错**上的跨越：几千行动画时间轴代码里，图层层级不乱、碰撞不穿模、音画卡点准确。

**操作入口**：Claude 中切到 Opus 5.5，推理强度选 UltraCode，模型会自动唤起多个子 Agent 并行编排代码。

## 7 个应用场景

1. **产品宣传视频** — `研究[iphone Duo]。制作一个 30 秒的动态视频，要有原创背景音乐、音效和中文旁白，音画同步。` 模型自己查产品、提卖点、出分镜；配乐音效代码合成，旁白用微软免费 TTS。
2. **儿童绘本** — `生成一个儿童绘本风格的视频，时长 30s，内容故事是关于小兔子的国庆假期。` Canvas 噪点模拟水彩纸纹 + 手绘抖线；扩写成 7 页绘本，翻页"沙沙"声和八音盒琶音都是算法生成。
3. **项目介绍** — `根据项目代码来制作一个宣传视频。` 给一个 GitHub 仓库，从源码和文档提炼卖点、分镜、BGM、卡点。
4. **15 秒高密度动效** — `15 秒长的动态图形演示视频，用于展示动画设计师的技能与能力。`（X@zero）非线性弹性曲线、交错延迟、遵循动量的形变。
5. **UI 一镜到底变形动画**（X@Stephan Livera）— 展示长上下文工程能力，完整提示词见下节。
6. **科普视频** — `一支展现人类进步历程、并展望未来 30 年的视频。`（X@imjustnewatai）交付 3 分钟叙事动画 + 原创配乐。
7. **电影故事**（X@Abdul Shakoor）— Opus 5.5 当"总导演"：GPT Image 2.5 出角色设定表和起始帧，Seedance 2.5 出镜头视频，保证人物一致与真实感。

## 提示词精选

### UI 一镜到底变形动画（全文）

```
<inputs>
请先询问我以下信息：我想让这个形状变成哪 8 到 12 种 UI 状态（例如按钮、加载器、播放器、滑块、开关、标签页、图表、命令面板、提示条）；画面采用纯黑白，还是加入一种强调色；以及一首约 120 BPM、可免版税使用的音乐（例如 Mixkit 上可商用的音乐）。
</inputs>
<direction>
做出 Dribbble 水准的 UI 动效。全程是同一个形状，不切镜：每种状态都由同一个元素变形而来，尺寸、圆角和颜色随之变化，内容切换时带有短暂的模糊效果。用光标驱动每一次变化，呈现真实的点击和拖动。使用浅暖灰色画布、黑白 UI 元素，以及一种简洁的 UI 字体（Geist）。全程使用弹簧动效，最多只有极轻微的回弹。镜头逐步放大，让每种状态都铺满画面。最后一帧要与第一帧完全一致，这样视频才能循环播放。
禁止使用：弹跳式缓动、粒子爆发、辉光、UI 元素上的渐变、粗细不一致的图标线条、节奏空档，以及任何看起来像模板的效果。
</direction>
<structure>
120 BPM，共 7 小节，每一拍都要有动作。
按钮 → 加载器 → 勾选完成 → 灵动岛 → 音乐播放器（播放/暂停图标变形）→ 拖动进度条 → 进度条变成音量滑块，拖过最大值时会被拉伸 → 开关随节拍切换 → 滑块圆钮变成液态标签指示器 → 标签页展开成自动绘制的图表，悬停时出现提示框 → 图表收拢成 ⌘K 命令面板 → 输入文字进行筛选 → 按回车键 → 弹出提示条 → 回到按钮。
</structure>
<build>
制作一个独立 HTML 文件，画面为 1440×1440 正方形。所有样式都根据 seek(t) 中的时间计算：不使用 CSS 转场、不使用计时器，也不在帧与帧之间保留状态。
弹簧动画使用闭式阶跃响应公式。一个值若多次改变目标值，就将每次变化对应的弹簧响应相加，使其始终是时间的纯函数。
标签指示器的两侧边缘分别由不同的弹簧驱动，让前缘先于后缘拉伸前行。开关的滑块圆钮也使用同样的处理方式。
拖动采用直接操控：光标按住时，根据光标位置计算数值；松开后，元素从松手时的位置开始弹簧回弹。
使用 numpy 分析音乐并确定节拍网格，从强拍开始。根据测得的音效峰值，安排每个 UI 音效出现的时间。
使用 Playwright 渲染：每帧取 4 个子帧，再用 ffmpeg 的 tmix 混合，制作 60fps 的运动模糊效果。
完整渲染前，先按每一拍渲染一帧。修正所有节奏不准、布局拥挤或难以阅读的部分。
</build>
<gotchas>
镜头缩放的元素上不要使用 will-change，否则文字会变模糊。变形容器里的文字切换时，需要单独安排进入和退出的时间，否则文字会互相重叠。最后一帧必须与第一帧完全一致，包括光标的位置和速度，否则循环播放时会卡顿。
</gotchas>
<start>
先询问我需要的信息，然后在编写任何代码之前，先按节拍网格向我展示 UI 状态列表。
```

**可借鉴的技术要点**：`seek(t)` 纯函数渲染（无 CSS 转场/计时器/帧间状态）→ 可逐帧确定性截图；弹簧用闭式解并叠加多次目标变化；numpy 测节拍网格做音画对齐；Playwright 4 子帧 + ffmpeg `tmix` 出运动模糊；先每拍渲一帧做 QA 再全量渲染。

### 电影故事（多模型协作）提示词结构

原文给了三段超长提示词，结构如下（原文全文见 URL）：

- **GPT Image 2.5 角色设定表**：锁定人物身份（脸部骨相、雀斑、发色挑染、金项链十字架、绳编手链、印花 T 恤、毛边牛仔短裤）；参考图仅借 2000 年代卡片机家庭录像色调；16:9 米白纸三排版式——第一排 6 角度转面全身、第二排 5 种表情 + 4 格细节微距；真实皮肤纹理、五指、无美颜/CGI。
- **GPT Image 2.5 起始帧**：以设定表为身份参考，从停着的轿车内透过车门抓拍海崖公路边的她；盛夏正午直射光、28mm 广角桶形畸变、抬高黑位低对比、胶片颗粒；4:3，无文字。
- **Seedance 2.5 镜头一**（10 秒单机位）：`<<<image_2>>>` 逐像素起始帧 + `<<<image_1>>>` 身份锁定；"相机锁定（最重要）"——零剪切零运镜、仅手持呼吸微颤；按秒分段写动作与台词（"I've been testing out the new Opus 5.5 model..." / "...and the shit you can do with it is absolutely insane."），细到每个词对应的表情；自动对焦搜索、曝光变化、机内麦克风音频、无音乐；详细负面要求。
- **Seedance 2.5 镜头二**（10 秒六镜头卡点剪辑）：航拍跟拍 → 侧面跟拍 → 低机位掠过 → 仪表盘内拍 → 后座视角 → 副驾驶近景说"Told you... it has no limits."；96 BPM 冲浪摇滚、每次切镜落在鼓点；分镜头音效设计；人物/车辆一致性与真实感约束。

## 作者经验分享

- Claude 系列视觉能力强但**风格容易趋同**——最有效的破局是"视觉参考大法"：上传一张参考图。
- 二维动画、文字特效、平面图形 → 直接代码绘制 + 按时间控制变化。
- 需要人物/实拍素材 → 用即梦等生成工具出素材，再用代码多层编排包装。
- 复杂 3D 角色和场景 → Python 脚本操纵 Blender，建模—动画—渲染全流程跑通。
