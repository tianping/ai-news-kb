## 一句话

新手最常见的翻车是一上来就试视频——单看每段都不错，剪到一起人物换脸、衣服和场景对不上。正确顺序是**写剧本 → 拆分镜 → 做资产图 → 逐镜生成 → 剪辑配音**，把一致性问题挡在生成之前。

## 五步

### 1. 剧本 + 分镜

输入题材、人物设定、剧情梗概、目标时长，让 AI 按场次写出地点、出场人物、关键动作和对白。逐场确认"人物要做什么、遇到什么、最后有什么变化"，再拆镜头。

**检查标准（很实用）**：
- 分镜表里每一行能不能直接变成一张画面？只写"气氛紧张"不行，要补上观众看得见的动作或表情
- 一行同时交代好几个动作，就再拆一镜
- 每镜只安排**一个主要动作**
- 核对相邻镜头的服装、道具、视线、动作、光线是否连贯

### 2. 人物、场景、道具资产图（关键一步）

- **人物**：正面、侧面、背面 + 面部特写，锁定发型、服装、配饰
- **场景**：先做能看清空间关系的主视角，补近景时对照门窗和光线
- **道具**：关键道具单独留图，颜色、形状、握持位置要清楚
- 在分镜表里标清**每一镜引用哪几张资产图**，后面要重做时直接沿用同一组素材

### 3. 逐镜生成视频

用确认过的分镜图当起始画面；提示词交代起始姿势、一个主要动作、结束姿势。**先试有转身、手部动作或道具交接的镜头**（最容易崩的先试）。

生成后看开头、中间、结尾三处，重点查换脸、手部变形、**最后一帧能否接到下一镜**。反复出错就把动作拆短。环境远景和道具特写可以先用静帧试剪。

### 4. 剪辑、配音、配乐

按编号导入，先排画面核对视线、动作方向、道具位置 → 再加对白、环境音、动作音效 → 最后配乐和字幕。对白出现时压低音乐。

导出前在手机上完整看一遍：对白清不清楚、字幕来不来得及读、相邻镜头接不接得上。

**第一次练习先做四到六镜，把五步完整走通**。

## 可复用的提示词

### 编剧 + 分镜师（四步推进，每步停下来等确认）

```
角色。你是一名 AI 漫剧编剧与分镜师。你能把零散灵感整理成目标明确、冲突递进、
适合逐镜制作的短剧。

任务。把我的题材想法变成可制作的漫剧脚本。按以下四步推进，需要我确认时先停下来。

输入。【填写题材、故事灵感、目标受众、预计集数与单集时长】。
如果我还没定题材，先给三个方向供我选择。

01 提出三个故事方案。给出 A／B／C 三版。每版写一句话卖点、主角目标、核心冲突、
对手或障碍、情绪看点、目标受众和预计集数。说明三版在题材切口、冲突或结局上的区别，
以及各自的制作难点。等我选定后再继续。

02 建立主要人物小传。逐人写姓名、年龄、身份、出场状态、人物关系与核心动机。
补充发型、五官、体型、标志性配饰、日常服与关键场合服装。再列 3–5 个性格词、
一项缺点、一个说话习惯和一个习惯动作。区分固定造型与随剧情变化的造型。

03 写分场剧本。按场次写地点、时间、出场人物、人物目标、可见动作、对白与场尾变化。
对白尽量简短，能够用动作交代的信息优先交给画面。核对每场是否推动剧情，再等我确认。

04 转为逐镜分镜。按镜号输出场次、时长、景别、运镜、画面描述、光线氛围、
对白或旁白、音效、参考素材和图生视频提示词。每镜只安排一个主要动作。
核对总时长，以及相邻镜头的服装、道具、视线、动作和光线是否连贯。
```

### 图生视频模板

```
【人物】在【场景】中，从【起始姿势】开始，完成【一个主要动作】，最后停在【结束姿势】。
采用【景别】，镜头【固定／缓慢推进／跟随】。
保持面部、服装、道具与背景光线一致。
```

## 点评

- 方法论没有新东西，但**顺序讲对了**：一致性是在"资产图"这一步解决的，不是靠生成时反复抽卡。这和库里 ComfyUI 漫画分镜、绘本实践、YUI 短片几篇的结论完全一致
- 三条最值得记的操作细节：**每镜只放一个主要动作**、**分镜表标明引用哪几张资产图**、**先试最容易崩的转身与手部镜头**
- 两段提示词可以直接拿去用，尤其"需要确认时先停下来"这个约束，能避免 AI 一口气写完一堆没法用的东西
- 工具无关：没绑定任何具体生成平台，换哪家模型都适用
