## 一句话

有界面的开源短剧 / 漫剧工作台：无限画布上编排剧本、角色、分镜、素材和视频节点，3D 白模预演搭景排机位，再按镜头生成视频；支持本地部署、自选模型、MCP 与插件扩展。

## 主要功能（README / 原文）

- **AI 编剧**：多 Agent 协作把小说或创意拆成场景、台词、节奏，输出标准剧本格式
- **智能分镜**：自动生成分镜脚本，含景别、构图、光线方向、镜头运动
- **角色一致性**：建立角色外貌数据库，跨场景跨镜头保持人物外貌、服装、道具一致
- **批量出图**：集成 Nano Banana、GPTImage2、可灵、即梦、海螺等主流图像模型
- **视频合成输出**：自动配音、字幕、剪辑，支持 9:16 与 16:9
- **无限画布工作台**：剧本、角色、分镜、素材、视频以节点形式自由编排，支持并行生产
- **三层 Agent 协作**：决策层 / 执行层 / 监督层，覆盖任务拆解、内容生成、质量审阅与修订反馈
- **持久化 Agent 记忆**：基于**本地 ONNX 向量检索**的跨会话记忆，支持语义召回
- **可编程供应商系统**：在设置中心直接写 TypeScript 供应商逻辑并即时生效，不用改源码或重启
- **章节事件图谱驱动改编**：自动提取原著章节事件并结构化存储，剧本改编按事件图谱调用上下文

## 点评

- 功能清单里真正有差异化的是三条：**三层 Agent（多了监督/审阅层）**、**本地 ONNX 向量检索做跨会话记忆**、**在设置里写 TypeScript 就能加供应商**。最后这条对接国内各家模型很实用，不用等官方适配
- 角色一致性的做法（建外貌数据库跨镜头复用）和库里那篇五步流程、绘本实践是同一条路：**先锁资产再生成**
- MIT 许可对商用最友好，是它相对 Reveric 和 OpenMontage 的明显优势
- 功能列得越全，越要警惕深度。建议和 Reveric 一样：先下客户端拿不重要的素材走通四到六镜，再决定投入
