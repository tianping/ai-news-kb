## 项目定位

把 **261 种手绘风格**整理成 Skill，每种配一个编号。换画风不用再憋"治愈一点、手绘一点、文艺一点"这类模糊描述词——看图选一个号码，告诉 AI 想画什么即可。

上线没几天已拿到 **1000+ Star**。

## 风格分类（编号段）

| 类别 | 编号范围 | 特点 / 适用场景 |
|------|---------|----------------|
| A 国际社论漫画 | 001–035 | 报刊杂志式幽默插画，线条有个性；观点、职场、科技配图 |
| B 国际绘本 | 036–054 | 故事感强，人物场景柔和；生活、亲子、情绪类 |
| C 现代平面 | 055–082 | 重色彩、造型、设计，画面简洁；封面、海报 |
| D 日本当代插画 | 083–123 | 日系味浓，人物日常场景多；生活、旅行、咖啡店 |
| E 当代中国插画 | 124–154 | 东方人物、本土元素；传统文化、节日、城市生活 |
| 后续 | 155–261 | 通用网感、媒介、地域手绘及新补充的当代插画 |

用法：往下翻画廊，喜欢的直接记编号（如 041），之后封面、正文配图、短视频插画反复复用。

## 核心逻辑：编号管画风，主题管内容

- 同一个编号可一直换主题；同一主题可换编号试不同画风。
- 效果不理想时不用重写 Prompt，直接切到旁边几个编号试。
- 长期做配图的账号（公众号/小红书）固定 2–3 个编号，换选题只换主题，画风不折腾。

### Prompt 示例

```
041号风格
主题：秋天的第一杯奶茶

041号风格
主题：程序员坐在电脑前写代码

236号风格
主题：工程师站在PLC控制柜前调试设备
```

Skill 会找到对应风格，按主题生成**中英文双语 Prompt**，复制给画图模型即可（作者用 Codex）。

## 参考图防跑偏

直接丢参考图给 AI 常见问题：画风学到了，但人物、动作、背景也被带过来。handraw-style 的处理：

1. 先用**风格名称、作者、画面特征**做文字描述；
2. 实在压不住才用参考图；
3. 传图时限制 AI **只参考线条、笔触、材质、配色**，人物/场景/构图重新生成。

避免"只想学画风、结果把人物场景也抄过来"。

## 安装与使用

```
# 对 Codex（或其他 Agent）说：
帮我安装 https://github.com/yang0/handraw-style.git
```

然后打开仓库内画廊 `handdraw-style-prompter/gallery/index.html`，看图选编号，发：

```
041号风格
主题：一名程序员正在电脑前调试PLC
```

Agent 整理出双语 Prompt 后即可生图。**不想装 Skill 也可以直接把仓库当画风图库用**：找画风、记编号，同样省事。

## 与已有工具的关系

- 本地 `story-to-handdrawn-video` skill：故事→手绘 Remotion 视频，固定彩色铅笔日记风 + 20 风格库；handraw-style 覆盖面大得多（261 种），偏配图/插画生成。
- 本地 `wechat-comic-pro`：公众号漫画压标；handraw-style 可作为其画风来源。
