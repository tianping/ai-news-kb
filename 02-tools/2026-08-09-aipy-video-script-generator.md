## 简介

使用 AiPy（AI 编程助手）通过自然语言对话，从零搭建一个「AI 短视频脚本生成器」Web 项目。用户输入视频主题、平台、时长、风格等参数后，调用 OpenAI 兼容 API 自动生成包含分镜表、节奏建议、爆款标题的完整短视频脚本。

## 核心功能

- **输入参数**: 视频主题/产品名称（必填）、目标平台（抖音/快手/视频号/B站）、视频时长（15s/30s/60s）、视频风格（搞笑/种草/知识科普/情感/剧情反转）、目标受众、参考文案/关键词
- **AI 生成输出**: 视频标题、总时长和分镜数量、分镜表格（编号/时长/画面描述/台词文案/音效BGM建议）、整体节奏建议、爆款标题/封面文字建议（3-5条）
- **操作功能**: 一键复制完整脚本、导出 Word 文档、重新生成
- **UI**: 年轻化风格、适配移动端、深浅色模式切换
- **运行**: `npm start` 即可启动

## 迭代优化提示词

1. **三种脚本风格**: 一次生成三种不同角度的脚本供用户选择
2. **深浅色模式切换**: 右上方放置切换按钮，适配不同使用环境
3. **自定义视频时长**: 改为用户自定义输入，限制不超过 2 分钟
4. **随机端口**: 多用户同时使用互不冲突

## 踩坑与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| AI 返回 JSON 格式解析失败 | AI 偶尔输出不标准 JSON（多余逗号、属性名无引号） | server.js 加 5 层容错：直接解析 → 提取大括号内容 → 修复多余逗号 → 修复单引号 → 补全缺失字段 |
| 前端报 `Cannot access 'safeData' before initialization` | 补丁式修改变量声明顺序错乱 | 重写前端，数据清洗统一放到 `safeScriptData()` 函数 |
| 导出 Word 报错 `ERR_INVALID_CHAR` | Content-Disposition 头直接放中文文件名 | 用 `encodeURIComponent()` 编码，`filename*=UTF-8''` 标准格式 |
