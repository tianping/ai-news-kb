## 八个技能一条龙

| 技能 | 职责 | 产出 |
|------|------|------|
| **short-drama**（入口） | 初始化、路由、状态管理 | 项目工程 |
| **develop** | 小说/长篇材料改编、分集地图 | 分集大纲 |
| **write** | 分集剧本 | 剧本（场景、动作、对白、钩子） |
| **assets** | 人物造型、场景视图、道具状态 | 角色三视图、场景方位板、道具参考板 |
| **image-prompts** | 参考图提示词 | 图片提示词文件 |
| **storyboard** | 分镜关键帧 | 分镜表（标注镜头职责） |
| **video-prompts** | 逐镜翻译成视频提示词 | 视频提示词（母版+补拍版） |
| **review** | 独立审查 | 审查记录 |

**调用方式**：Claude Code 用 `/short-drama`，Codex 用 `$short-drama`，也可自然语言说明，两种写法可互换。

## 核心设计理念

### 刻意不直接生成
- **不含生图/生视频/音频调用**——只产出文本提示词
- 提示词先落进文件，由人确认后再进入生成环节
- 防止未经确认的提示词误触发生成、造成预算浪费
- 对预算敏感的工作室非常实用

### 真实产线蒸馏
- 作者工作室 2025 年至今累计上千个 AI 短剧/漫剧项目
- 前后端近 8 万行代码的自建工具，在模型能力迭代面前维护不动
- 干脆抛开图形工具，把历史项目工程和提示词蒸馏成技能集
- 让制作人直接用 agent CLI + 文件维护工程，确认后再送生成
- 现在自建工具里只剩"排队抽卡"

## 完整交接链演示

仓库 demo 展示一集短剧的完整四步交接：

```
剧本 → 资产设定 → 分镜 → 视频提示词
```

题材：都市打脸短剧（外卖员送餐被羞辱→亮出集团董事身份）

- **剧本**：制作稿格式，场景/动作/对白/钩子齐全，附交稿前逐条自检清单
- **资产设定**：角色三视图、场景方位板、道具参考板
- **分镜**：落实原文并标注镜头职责
- **视频提示词**：母版与补拍版约定

## 连续性契约

全流程用同一套**创作者决策、来源引用与连续性契约**衔接：
- 角色造型前后一致
- 场景设定不矛盾
- 道具状态可追踪
- 分镜与剧本对应
