# 硕博常用 Codex 科研指令集（公开部分 10 条）

- **来源**: [微信公众号文章](https://mp.weixin.qq.com/s/SS0b9fbkzFhTSFw1TeYwyg)
- **日期**: 2026-09-03
- **定位**: 把 AI 当研究助手而非代笔——Codex 负责整理/分析/润色，逻辑框架与观点自己定

## 核心方法论：三步流程

> 直接让 AI "写一段文献综述" → 得到的都是"近年来……值得注意的是……综上所述"模板文，AI 痕迹明显。**问题不在模型，在用法。**

1. **先让 Codex 整理文献，而不是直接写综述**：投喂论文，提炼每篇的核心观点/方法/发现/不足，表格输出
2. **自己梳理研究思路**：明确文献间的联系、已有研究不足、自己的切入点
3. **再给 Codex 定好的框架**：让它组织语言、优化表达，而不是替你决定观点

## 一、文献综述

### 1. 文献综述框架生成
```
请根据以下论文生成一份文献综述框架，要求：
1. 按研究主题、研究方法或研究结论进行分类；
2. 提炼各研究的核心观点与主要发现；
3. 总结目前的研究热点及发展趋势；
4. 分析仍然存在的研究空白（Research Gap）。
论文内容：【粘贴论文摘要或正文】
```

### 2. 多篇论文研究方法对比
```
请比较以下论文的研究方法，并以表格输出，包括：
- 研究设计 / 数据来源 / 数据分析方法 / 创新点 / 局限性
论文内容：【粘贴论文】
```

### 3. 文献批判性分析
```
请从以下几个方面分析论文：
1. 研究问题是否具有价值；
2. 方法设计是否合理；
3. 数据分析是否充分；
4. 研究结论是否具有说服力；
5. 对本领域有哪些贡献。
论文内容：【粘贴论文】
```

## 二、论文写作

### 4. 学术润色
```
请在保持原意不变的前提下润色以下内容：
要求：保持学术表达规范；提高语言准确性与逻辑性；
避免口语化表达；保持自然流畅。
原文：【粘贴内容】
```

### 5. 论文降重
```
请对以下内容进行降重改写。
要求：保留原有观点；调整句式结构；使用不同表达方式；
保证逻辑连贯、符合学术写作。
原文：【粘贴内容】
```

### 6. 中文摘要生成
```
请根据论文内容生成一篇200—300字中文摘要，包括：
1. 研究背景 2. 研究目的 3. 研究方法 4. 主要研究结果 5. 研究结论
论文内容：【粘贴正文】
```

### 7. 引言撰写
```
请根据以下研究主题完成论文引言，包含：
1. 研究背景 2. 研究意义 3. 国内外研究现状 4. 当前研究不足 5. 本文研究目标
研究主题：【填写主题】
```

## 三、研究设计

### 8. 挖掘 Research Gap
```
请分析以下研究领域，并找出3—5个值得进一步研究的问题。
包括：已有研究成果；存在的问题或争议；尚未充分探索的方向；值得关注的新机会。
研究领域：【填写内容】
```

### 9. 生成研究假设
```
请根据以下研究背景提出3—5个可验证的研究假设。
要求：明确自变量和因变量；给出理论依据；
如有需要，考虑中介变量或调节变量。
研究背景：【填写内容】
```

### 10. 推荐研究方法
```
请针对以下研究问题推荐研究方案，包括：
定性或定量方法选择；研究设计；数据采集方式；数据分析方法；可能涉及的伦理问题。
研究问题：【填写内容】
```
