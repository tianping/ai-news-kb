## 核心变化：乐谱回到生成链路

过去两年 AI 音乐流程 = 输入提示词 → 等几十秒 → 听成品；不满意就调形容词继续"抽卡"。不符合音乐人反复推敲旋律/和声/编曲的工作习惯。

**YuE2 把乐谱放回生成链路**：先出可检查、可修改的乐谱（ABC 记谱），确认后再生成 48 kHz 立体声音频。

### 完整规划模式（两阶段）

1. **写计划**：拿到歌词 + 风格 → 先规划旋律与和弦，以 **ABC 乐谱**保存
2. **做声音**：确认后的乐谱进入生成链路（语义 token → 声学表示 → 解码）→ 48 kHz 立体声

创作者可先导出计划，在生成音频前**修改和声、旋律、速度或段落顺序**，再让模型依据修改后的乐谱完成演绎。官方也提供只规划旋律、以及不用乐谱直接生成的模式。

## 技术边界："编辑"到底指什么（易误解点）

YuE2 的"可编辑"**不是** DAW 里精确切开某段录音只改一个音符、其余波形不变。官方明确：

- 修改乐谱后，系统生成的是**一份新的完整录音**
- **不保证**编辑范围之外的原始波形保持不变
- 官方示例检查两份乐谱的音符、时值、拍号、速度是否一致，允许和弦变化；新录音是否演对仍要对比试听

形象说法：你把改好的新乐谱交给乐队——"副歌和声改了，重新演奏一遍"。修改有了乐谱锚点、版本之间有了可参照的结构，但距离逐轨逐段精细制作仍有空间。

## 人和 Agent 的共同接口

YuE2 仓库附带 **yue2-music Agent Skill**，为支持技能包的助手提供生成、转写、翻唱、改谱、版本对比的工作流（实际生成仍需另行安装模型运行环境）。

官方案例《The Last Train》：9 个步骤、14 个版本——从中文流行歌逐步修改和声、编曲、主题与歌词，最终形成带萨克斯独奏的英文爵士版本。

分工：

| 角色 | 做什么 |
|------|--------|
| 人 | 决定审美方向，提具体修改意见 |
| Agent | 把要求转成乐谱/歌词/风格参数调整，检查需保留的结构 |
| 底层模型 | 依据最新输入生成新的完整录音 |
| 项目记录 | 保存乐谱、配置、音频、模型版本，可回看可对比 |

**AI 音乐的最小单位，从一首孤立"成品音频"变成含计划、草稿、修改、对比的"完整项目"。**

## 零样本翻唱路径

核心路径：

1. 用 **SheetSage2** 把原歌录音转写成旋律乐谱
2. 创作者检查、修正乐谱
3. 替换歌词或目标风格，让 YuE2 重新演绎

官方建议翻唱采用**只提供旋律、不带和弦符号**的输入，给伴奏适应新风格留空间。"零样本"指用通用生成模型，无需针对翻唱任务专门微调。

⚠️ 技术路径跑得通 ≠ 自动获得歌曲/录音/声音身份使用授权；公开传播与商业化时权利需分别核实。

## 跑分要理性（别急着写"打败 Suno"）

- 2026-09-12 WildSongBench 对比：192 条提示词、17 种系统设置；YuE2 **best-of-8** 设置取得其中最高 SongBench 平均值
- 读数字要看三件事：
  - **候选预算**：best-of-8 从 8 次生成中筛选；普通 YuE2 从 2 个候选中选；都不等同用户一次调用不加筛选的体验
  - **筛选规则**：普通设置按音素错误率选候选；best-of-8 依次参考音乐性、提示控制与音素错误率
  - **评测范围**：不同模型在不同指标互有胜负；头部均值小差距不能证明统计显著，更不能代表所有人的听感偏好

更客观的评价：YuE2 在特定公开评测设置下展现很强竞争力，但**不足以据此宣布全面超越商业音乐产品**。

## 上手门槛（显存与许可证）

- **硬件**：官方起点 = Linux + Python 3.12 + 支持 BF16 的 **24GB 显存 NVIDIA 显卡**
  - 若看到"8GB 可跑"社区说法，逐项核对量化方式、代码分支、生成长度与速度，不能当官方标准配置
- **许可**：
  - 一方代码、Agent Skill、文档 = **Apache-2.0**
  - 模型权重单独 = **CC BY-NC 4.0（非商业）**
  - 早期下载包保留各自附带许可证
- **工程代码开放 ≠ 权重自动获得商用许可**。商业部署 / 接入付费产品需另确认权重授权；生成物及输入素材权利分开判断。

## AINQO 判断：评估 AI 音乐工具问四个问题

1. **是否有可编辑的中间层？** 旋律、和弦、结构能否被检查和修改？
2. **能否明确表达修改范围？** 能否在乐谱层只改和声、保留主旋律，并验证生成结果？
3. **版本是否可追踪？** 乐谱、参数、模型版本是否保留，试听结果是否有据可查？
4. **版权与许可是否清晰？** 代码、权重、输入素材、生成物，是否分别核实了使用条件？

AINQO TAKE：未来最值得长期使用的 AI 音乐工具，未必是第一遍最惊艳的；更期待它听得懂修改意见、留下可检查的草稿、陪人一遍遍改稿。YuE2 把乐谱重新摆到台前，提供了值得追踪的方向。

## 要点速记

- 乐谱（ABC 记谱）回到生成链路，先规划再出声，可检查可修改
- 改谱 = 生成新完整录音，不保证范围外波形不变（非 DAW 式精确编辑）
- 附 yue2-music Agent Skill；《The Last Train》9 步 14 版本演示
- 翻唱走 SheetSage2 转写 → 改谱 → 重新演绎，零样本
- 跑分 best-of-8 有筛选预算，别当用户一次调用体验
- 24GB 显存起点；代码 Apache-2.0 但权重 CC BY-NC 4.0（非商业）
