# story-video-director：一键从故事生成视频的 AI 导演 Skill

> 来源：[这个 skill 可以一键选角儿出片儿了](https://mp.weixin.qq.com/s/he35T9wJ_Xcdw_eHyMsuoQ) · 2026-08-15 · 公众号：心有安处

## 核心概要

GitHub 开源项目 `story-video-director`，输入故事内容，自动完成：角色创建、剧情资产包（配图）生成、视频提示词生成、调用视频生成 API、自动剪辑成长视频。作者测试用的是 MiniMax H3（秘塔 API，约 0.1 元/秒），质量打 70 分。

## 核心流程

```
故事输入
    ↓
自动创建角色（选角）
    ↓
生成剧情资产包（配图/图片）
    ↓
生成视频提示词
    ↓
调用视频生成 API（默认 MiniMax H3，可替换）
    ↓
自动剪辑拼接成长视频
```

## 关键信息

- **项目地址**：https://github.com/zlbigger/story-video-director
- **视频生成模型**：默认 MiniMax H3（秘塔 API），~0.1 元/秒，可换其他模型
- **测试案例**：《桃园三结义》1 分多钟视频
- **质量自评**：~70 分
- **成本**：视频生成按 API 计费，技能本身开源免费

## 使用方式

1. 克隆仓库，配置 API 密钥
2. 输入故事文本
3. Skill 自动完成全流程，输出最终视频

## 适用场景

- 快速把故事/剧本转成视频初稿
- 短视频内容批量生产
- 不知道怎么拆镜头、写提示词的创作者

## 局限

- 视频质量受限于底层视频生成模型（MiniMax H3 约 70 分）
- 需要视频生成 API 密钥（有成本）
- 单次生成时间较长（需等待视频生成 + 剪辑）
