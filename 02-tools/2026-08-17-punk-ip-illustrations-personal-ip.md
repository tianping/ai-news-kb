# 个人 IP 配图这件事，终于有一条能反复用的路了

> 来源：[视觉研究设 · 微信公众号](https://mp.weixin.qq.com/s/QdWaKjGCvqy08ef45iRTFw) · 2026-08-17

## 核心问题

公众号文章写完后，配图面临三大痛点：图库找图风格不统一、自己画时间不够、AI 生成每张人物形象都变（发型、衣服、身体比例漂移）。配图有了，个人辨识度却丢了。

## Punk IP Illustrations 开源 Skill

作者 Adrian Punk 在 X 上开源了一套 Skill，名叫 **Punk IP Illustrations**，核心思路是：**先把"画的是谁"固定下来，再让这个角色进入每一篇文章。**

### 工作流程

1. **上传照片，创建个人 IP** — 把照片转成角色资产包，包含：
   - 主角色全身像（正面、侧面、背面视图）
   - 一张干净人物参考图
   - 一份 `character-spec.md`（记录固定身份特征）
2. **用户确认角色** — 发型、鞋子、配件不对可以逐项修改，旧版本不覆盖。明确说"确认/定稿"后才变成 confirmed 状态，未确认的角色不能用于配图
3. **文章配图** — 读取全文 → 分析信息密度 → 用当前角色逐张生成配图。不用重新上传照片，直接给文章/Markdown/网页链接即可

### 角色规范文件示例

character-spec.md 会记录容易漂移的身份特征。例如"龙叔"的规范：
- 黑色短刺发
- 黑 T、胸前蓝紫色三角笑脸
- 灰色短裤
- 脖子上的耳机
- 左手智能手表
- 黑白运动鞋

**场景怎么变，这些固定特征不能随便丢。**

## 配图策略

### 数量决策

| 文章长度 | 配图数量 |
|----------|----------|
| 短观点 | 1 张 |
| 中等篇幅 | 1-3 张 |
| 长文 | 3-5 张甚至更多 |

不按章节平均塞图，不为了数量硬画。

### 优先画的内容

1. 全文总判断
2. 关键转折
3. 容易误解的机制
4. 只靠文字不易理解的过程
5. 能变成行动的结论

### 两种正文图模式

**核心动作模式**：
- 适合观点、冲突、判断、现实问题
- 保留一个角色 + 一个核心物件/一组紧凑物件 + 一个动作 + 一个结果
- 例如：表达"旧观念被打破"→角色直接剪断那个旧模板
- 不堆说明文字，动作本身要能讲明白

**流程拆解模式**：
- 适合教程、方法、工作流、输入到输出的过程
- 压缩成 3-5 个节点
- 同一角色在不同节点重复出现，但每个分身做不同的事
- 画面有阅读顺序、有留白，不变成拥挤的 PPT

## 插入位置回填

生成图片后，记录每张图对应的观点和建议插入位置。如果给的是本地 Markdown 文件，可自动把图片插回正文：
- 用完整段落作为定位锚点
- 放在相关段落后面
- 避开句子中间、列表内部、引用块

## 隐私与资产管理

- 运行资产保存在本地 `.punk-ip-assets` 目录
- 角色设定、参考图、人物规范、文章插图分开放
- 角色分 draft 和 confirmed 两种状态
- 原始人物照片默认不复制进角色包，不上传公开仓库
- 生成资产和文章插图留在本地

## 局限性

- 角色参考图做得差 → 后面的图跟着飘
- 文章本身没有观点 → AI 不可能替你凭空找值得画的地方
- 工具能把流程跑顺，但作者仍要负责判断内容

## 适用场景

- 教程、方法类文章
- 想让账号形象更稳定的个人 IP 创作者
- 设计、AI 工具、产品体验、创作流程类内容

## 评价

这套 Skill 的定位不是绘图工具，而是**内容生产工具**。绘图工具关心"这一张图好不好看"，内容生产工具还关心"下个月、下一篇文章、另一个主题里，读者还能不能认出同一个人"。个人 IP 不经得起抽签式的形象漂移，角色必须先成为资产。
