# Codex + Excalidraw 一句话出片：手绘白板风格视频流水线

- **收藏日期**: 2026-09-30
- **来源**: 微信公众号「萌巧蓄水池」
- **分类**: AI 工具 / 内容创作工作流
- **原文链接**: https://mp.weixin.qq.com/s/Ci9__JzYdbnVCYRebtQhFA

## 概述

作者用 Claude Code 里的 `/whiteboard-video` Skill + Excalidraw + Codex 生图 + Obsidian 文件结构，把"写稿→找资料→画图→动画→配音→剪辑→字幕→封面→发布文案"整条视频生产链变成一行命令自动完成。产出包括 1080P 成片、横/竖版封面、五个候选标题 + 各平台发布稿、完整资料来源。作者借此反思 AI 降低的是创作门槛而非创作价值，真正剩下的是选题判断与查证能力。

## 关键内容

### 1. 工具分工（三层）

| 工具 | 角色 |
|------|------|
| **Excalidraw** | 白板画风（自带抖动手绘线条），开源无需每期重造 |
| **Codex（AI 生图）** | 生成人物、汽车、电脑等"难画"元素，处理成透明贴纸嵌入白板 |
| **Obsidian** | 每期独立目录存旁白/场景/贴纸/字幕/封面/资料来源/发布稿；装 Excalidraw 插件可直接改场景图 |

不用 Obsidian 也完全可以，普通文件夹一样能跑。

### 2. 七步流程（Skill 内编码）

1. **选题与查证**：AI 先查资料，优先官方来源，关键数字交叉核对；作者判断"值不值得讲"
2. **写旁白**：短句、口语、一句一个信息点；每段都必须有东西可画
3. **准备 Logo 和贴纸**：公司/产品用官方 Logo；人物道具 AI 生成贴纸，统一视觉风格
4. **生成场景**：1920×1080 画布，文字/框/箭头/贴纸逐一进画面，给字幕区和水印区留安全区
5. **生成封面**：同一内容同时出横版+竖版；主标题讲清对象，副标题制造好奇心
6. **渲染成片**：配音、字幕、动画、音乐、片尾自动合成；检查尺寸/帧率/音轨/字幕
7. **生成发布稿**：五个候选标题、各平台文案、置顶评论、资料来源一次性整理

### 3. 节奏与形式判断

- 视频控制在 2~2.5 分钟，拆 6~8 场景；每场景再按旁白拆小段，每隔几秒画面出现新东西
- "白板停在那里十几秒什么都不发生，观众就走神"——画面必须持续变化
- "正在画"（未完成感）是天然注意力机制，比画完更重要

### 4. 知识内容为什么适合白板

- 最大敌人是"抽象"而非"复杂"；三栏卡片讲三要素、两列讲区别、时间线讲因果、箭头讲因果、简单账本讲数字
- 白板逼你"把复杂问题拆成普通人能看懂的结构"，本身就是一种思考方式

### 5. 不露脸的得与失

- 得：无需出镜/灯光/场地/剪废话
- 失：观众记不住脸，只能靠画风/配色/封面/声音/标题/片尾角标形成记忆
- 对策：同一系列视频统一手绘风格、配色、封面结构、水印、片尾、叙事节奏

### 6. 适合/不适合白板的选题

- 不适合：突发新闻、现场调查、需要真实照片/视频作证据的事、追求短期热度的热点
- 适合："生命周期更长"的问题——"XX 到底是什么？""为什么 XX？""XX 怎么算？""普通人怎么理解 XX？"

### 7. 作者自定"铁律"（八条）

1. 先旁白，后画面
2. 字幕区和水印区不能放元素
3. 公司尽量用官方 Logo
4. 人物、道具、文字分开处理
5. 数字必须有来源
6. 所有数字从同一资料源读取
7. 固定参数（字体/字幕大小/配乐音量/水印位置/片尾/账号名/品牌色）全部进配置文件
8. 一期所有资料放同一文件夹

### 8. 数字查证机制

每个数字记录进当期 README：来源、核对时间、支持哪句、官方/媒体、准确/估算。"知识类账号最宝贵的是信任，一个数字错一次是小错，连错几次观众就怀疑你说的一切。"

### 9. 标题方法

固定写五个候选，分别尝试：数字反差、反常识、结论先行、把大数字换算成生活里的东西、直接提问。五个放一起比较，才知道"原来不是没有好标题，而是没给自己比较的机会"。

### 10. 多平台文案原则

一份内容不复制粘贴到四个平台。针对不同平台分别准备标题、简介、正文、评论区置顶；内容可一样，表达必须不同。

### 11. 配置与"改起来容易"

- 每期"一样的东西"（固定参数）全放配置文件；AI 每期只负责"不一样的东西"（旁白/场景/人物/数据/主题）
- 改一个字/换标题不再牵动整个时间轴和封面，可低成本迭代

### 12. 上手建议（作者原话）

- 第一期故意做得丑，只完成"从一个问题到一条完整成片"
- 节奏：P1 做 5~6 场景 → P2 调字体 → P3 定配色 → P4 优化封面 → P5 定片尾 → 之后再加自动化
- 先拿纸写 30 个"为什么……/到底是什么……/怎么做到的……"问题；写不出 10 个说明没找内容方向，工具不是瓶颈
