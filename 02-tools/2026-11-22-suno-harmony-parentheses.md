## 一句话

歌词里**句尾加圆括号**，括号里的字会被当成第二个声音唱出来，也就是和声；**方括号是指令，不会唱出来**。两种括号别搞混。

## 1. 歌词里这样写

```
[Chorus]
今晚的月亮 (月亮)
陪我走回家 (回家)
```

- 圆括号里只放 **1–3 个字**
- 放在**句尾**
- **一行最多一处**

## 2. 方括号和圆括号别搞混

| 符号 | 作用 | 会不会唱出来 | 写法 |
|------|------|------|------|
| `[ ]` 方括号 | 指令（段落、唱法、效果） | 不会 | 最好单独一行 |
| `( )` 圆括号 | 和声 / 伴唱 | 会 | 句尾 1–3 字 |

## 3. 最容易踩的坑：英文指令写进圆括号

- ❌ 改前：`(whispered) 我想你` → AI 会把 "whispered" 当歌词唱出来
- ✅ 改后：

```
[Whispered]
我想你
```

## 4. 想要男女和声

写进「音乐风格」（Style）一栏：

```
Male Vocals, Female Background Vocals
```

意思是男声主唱、女声和声。

副歌想更厚，在歌词里用段落标签：

```
[Chorus: layered harmonies]
```
