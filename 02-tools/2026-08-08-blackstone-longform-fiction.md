# 黑石写作助手·中长篇小说版（OpenClaw Skill）

> 来源：[ClawHub - blackstone-longform-fiction](https://hub.openclaw.ai/jony4/skills/blackstone-longform-fiction) · 2026-08-08

## 这是什么

黑石写作助手是一个 OpenClaw Skill，专为中长篇小说创作设计。基于"故事工程"核心理论，用六项写作技能帮助作者从想法推进到可用正文。作者是 jony4，官网 https://blackstone.wansu.tech。

## 核心定位

- **不是续写工具**：不只是生成一次性片段，而是覆盖从灵感到正文的完整创作流程
- **长篇连续性**：按人物状态、关系、时间线、伏笔、世界规则检查跨章矛盾
- **本地+云端**：本地写作永远免费，云端提供跨会话记忆和跨客户端接续
- **已有作品可接续**：读取作者正文与已确认设定后续写、改稿或检查，不静默改写既定事实

## 六大核心写作技能

| 技能 | 作用 |
|------|------|
| **立意** | 从一句想法发展出可用的故事立意 |
| **人物** | 构建有内在矛盾的人物，不是贴标签 |
| **主题** | 检查故事的主题是否贯穿始终 |
| **故事结构** | 设计情节骨架，控制节奏与转折 |
| **场景设置** | 将情节落为具体场景，含空间、时间、氛围 |
| **写作风格** | 统一叙述视角、语气、用词风格 |

## 四条主线流程

1. **Idea2Video 不，是 Idea2Text**：只有一句想法 → 立意 → 人物 → 结构 → 场景 → 正文
2. **已有作品接续**：读取已有正文和设定，续写/改稿/检查
3. **跨章连续性检查**：人物状态、时间线、伏笔是否连贯
4. **正文修改**：改文风但不改剧情，改剧情但保持风格

## 触发方式

对话中直接说即可触发，不需要特殊命令：
- "黑石，开始写作。我现在只有一个想法。"
- "黑石，帮我把这个想法发展成立意。"
- "黑石，帮我完善主角。"
- "黑石，检查这个故事的主题和结构。"
- "黑石，把这个场景写成正文。"
- "黑石，续写第十二章，保持现有风格。"

## 云端故事记忆

- **跨会话召回**：上次写到哪、人物当前状态
- **跨客户端接续**：换设备/换AI客户端继续写
- **作品级连续性核对**：跨章人物、时间线、伏笔
- 计费：本地写作永久免费，云端记忆调用 0.01 元/次，失败自动退回

## 与普通续写工具的区别

| 维度 | 黑石写作助手 | 普通续写工具 |
|------|------------|------------|
| 覆盖范围 | 立意→人物→主题→结构→场景→风格→正文 | 仅续写正文 |
| 长篇连续性 | 跨章人物/时间线/伏笔检查 | 无 |
| 已有作品 | 读取设定后续写，不静默改写 | 可能忽略已有设定 |
| 工作流 | 六项技能按需调用，逐步推进 | 一次性生成 |
| 沉淀 | 确认的设定自动保存到云端故事图谱 | 无持久记忆 |
