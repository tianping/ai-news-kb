# 把 AI 装进了 SSH 终端，这款强大的远程终端工具开源了！

> 来源：极客之家 · 2026-08-22

## 简介

NyaTerm 是一款用 Tauri + React + Rust 开发的开源远程终端工作台，将 AI 助手原生集成进终端。支持 SSH、本地终端、Telnet、串口、RDP、VNC 六类会话，同时具备 SFTP 文件管理、隧道、OTP、资源监控等完整功能，可从 Xshell / MobaXterm / WindTerm 直接导入会话。

## AI 助手

### Ask 模式：随手问答
- 单次问答，一句话生成命令、解释输出、分析报错
- 自动携带终端上下文，无需手动复制
- 选中文本即可让 AI 解释或操作

### Agent 模式：多步任务
- 观察→决策→执行的循环，当前会话内连续做多步操作
- 每条命令先生成风险等级卡片，用户确认后才执行
- 执行完成后单独给出总结报告

### @ 会话：多机对比
- 在输入框敲 `@` 可将其他终端会话加入上下文
- 适合多台机器配置相同但表现不同的场景对比

### 模型灵活接入
- 内置多种 provider，支持自定义 OpenAI 兼容接口
- 国内 DeepSeek / 通义等模型均可接入
- 推理模型（DeepSeek R1、通义 QwQ）的思考过程可展示在面板

## 风险控制
- 高影响命令需审批，不点同意不执行
- 危险操作会给安全替代方案
- 实时评估键盘输入，危险命令会提醒
- 生成的好命令可一键存为快捷命令

## 终端功能
- 六种会话共用标签页与分屏，布局可拖拽恢复
- 命令历史带模糊联想建议
- 终端内可直接搜索、翻译选中文本
- IP / host:port 自动转可点击链接
- 大输出保护机制，防界面卡死
- 会话录制功能
- 右侧资源监控面板：CPU/内存/磁盘/网络实时曲线，支持 NVIDIA GPU 和昇腾 NPU
- Docker 管理（容器/镜像/卷/网络/Compose）
- 可换皮肤

## 串口与老设备
- 支持 Telnet 和串口会话
- 串口支持 Backspace 模式调节

## 文件与同步
- SSH 会话自带 SFTP 文件浏览器，传文件支持队列、暂停、断点续传
- 远程文件拉到本地编辑，保存后自动回传
- 凭据、私钥本地加密存储
- 主密码、锁屏、OTP（TOTP/HOTP）支持
- 配置可通过 WebDAV / S3 兼容存储 / GitHub Gist 加密同步
- 支持导出加密 .nya 备份文件

## 适用场景
1. **服务器排障**：报错信息原地让 AI 分析，Agent 模式自动查
2. **多机对比**：多个会话 @ 进上下文，找差异
3. **设备调试**：串口/Telnet/SSH 一个工具搞定
4. **多电脑办公**：配置加密同步到公司/家里
