## 解决什么问题

扫描件、影印版、老师发的 PDF 乐谱只能看不能改；想改指法、调声部、重新排版就得手打，一首中等难度钢琴曲熟手也要两三小时。这个工具把 PDF 转成 **MusicXML**，MuseScore、Sibelius、Finale、Dorico 都能直接打开成可编辑音符。

## 流程

1. PDF 每页转标准灰度图，歪的扶正、糊的增强
2. 调用开源 OMR 软件 **Audiveris** 识别音符、符杠、连线
3. 各页拼成完整一份，补齐缺失声部、对齐小节号

一条命令跑完，不用逐页操作。

## 使用

```bash
# 依赖：Python 3.10+、Audiveris（官网免费下载）
pip install -r requirements.txt
python score_converter/main.py -i 谱子.pdf -o 输出目录 --instrument piano
# 谱子小、排得密：加 --dpi 400（不是越高越好，太高会直接失败）
```

## 局限与坑

- 扫描件糊、歪、有手写批注时错音率明显上升，**识别后必须人工过一遍**
- 十来页单曲效果好；整本曲集、排版怪的乐队总谱别指望一次成功
- 定位是辅助：「八成准 + 你改两成」比自己打十成快
- 页数多跑得慢（一页几秒），不是卡死
- 内存不足 Audiveris 会报错退出，先关掉其他大程序
- 先拿一两页试效果再批量
- 某几小节明显错乱多半是原页扫描歪了——重扫那一页比手改快
