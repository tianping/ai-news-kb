# 不会写分镜，也能用 Codex + MiniMax H3 / Seedance 2.5 做出第一条 AI 视频

## 核心观点

普通人做 AI 视频的核心障碍不是导演能力或画工，而是**不知道第一步该做什么**。本文用「穿搭变装视频」和「多人物喜剧短剧」两个完整例子，展示如何用 Codex（或 ChatGPT）当外置大脑，把视频创作拆成可逐个确认的小决策。

关键原则：**第一条视频不用 API，不用先学剪辑，先跑通 10-15 秒单场景的完整流程。**

---

## 九步工作流（单场景，10-15秒）

### 第一步：准备四样东西
- Codex 或支持图片生成的 ChatGPT
- MiniMax H3 或 Seedance 2.5 界面（两者区别：H3 最多 15 秒、支持首帧/尾帧/多模态参考；Seedance 2.5 单次最长 30 秒、支持更多参考类型）
- 一条想学习的视频链接，或一句自己的想法
- 一个项目文件夹（存参考图、提示词、生成结果）

### 第二步：把参考视频交给 Codex 分析结构
发给 Codex：
```
我想学习这条视频的创作结构：<粘贴链接>
目标：做一条原创的 9:16、约 15 秒视频，使用 MiniMax H3 或 Seedance 2.5 生成。
请先不要生成图片和视频提示词。先帮我分析：
1. 最值得学习的核心玩法是什么
2. 开始画面是什么，结束时发生了什么变化
3. 主角、场景、镜头和动作分别需要保持什么
4. 需要准备哪些参考图片
5. 哪三个地方最容易生成失败
不要复制原视频人物、Logo、文字或音乐。看完后给我一个简单方案，等我确认再继续。
```

### 第三步：让 Codex 列「制作单」（非导演术语）
方案确认后继续问 Codex：
```
请把它整理成一张制作单。不要使用导演术语，用普通人能看懂的方式列出：
- 要生成几张图
- 每张图负责什么
- 图里必须出现什么
- 什么东西必须保持不变
- 最后要把哪些素材上传到视频模型
这一轮仍然不要开始生图，先让我确认制作单。
```

### 第四步：先生成一张测试图，一次只改一处
- 用 9:16 比例，原创角色
- 生成后先数人数，再看脸和手脚
- 只有一处不对 → 让模型只改这一处（具体说明改动量，如「缩小20%向上移动」）
- 多处同时出错 → 重新生成比连续修补更省时间

### 第五步：让 Codex 根据确认图片写视频提示词
首帧通过后，把图交给 Codex：
```
这张首帧已经确认。请为 MiniMax H3 写一段可以直接复制的视频提示词。
视频 14 秒，9:16，固定机位，一个连续镜头。
[描述具体动作序列和时间分配]
请写清：首帧职责、完整时间轴、每段具体动作、声音和针对性禁止项。
不要为了显得专业堆砌镜头术语。
```

### 第六步：先生成测试版
- 只用首帧图生视频，不上传尾帧
- 先用较低分辨率跑测试版，确认流程后再出完整质量版

### 第七步：把生成的视频交回 Codex 做诊断
```
这是刚生成的视频。请自己读取视频并抽帧检查。
先告诉我它和目标视频最明显的差别，再检查：
1. 人物脸、发型和身材有没有变化
2. 每次转场实际持续多久
3. 转场有没有遮住主角
4. 手臂、重心和视线有没有突然重置
5. 背景和镜头有没有无故变化
6. 哪三个问题最影响观感
区分你直接看到的问题、合理推测的原因和暂时无法确认的原因。先诊断，不要立刻重做全部素材。
```

### 第八步：一次只修一个主要问题
如果最影响观感的是转场太慢，就只改提示词中的转场部分，保留其他所有元素不变。重新生成后，把两个版本放一起比较。**不要同时更换人物图、动作、镜头、音乐和时长**，否则即使变好也不知道是哪项修改起作用。

如果同一个错误连续出现两次 → 回到上游检查首帧和动作设计。不要往提示词后面追加「更自然、更稳定、更高质量」。

### 第九步：完成标准
第一条视频满足以下即可算流程跑通：
- [ ] 观众能看懂视频里发生了什么变化
- [ ] 主角身份没有明显漂移
- [ ] 参考图片没有互相冲突
- [ ] 每个主要动作都有开始和结束
- [ ] 转场没有长时间遮挡主体
- [ ] 生成失败后，能说出具体时间和具体问题
- [ ] 图片、提示词和最终视频都保存在同一项目文件夹

## 多分镜视频工作流（以 cuimao_reverse 项目为例）

多人物、有对白、需要切换景别的剧情视频，难点是**人物换了镜头后还是不是同一个、前一个镜头的动作能不能接到下一个镜头**。

### 流程扩展
1. **拆故事变化**：把视频交给 Codex 分析故事变化线，写成普通人能确认的制作单
2. **设计参考素材包**：拆成角色设定图、配角阵容、群体站位、环境空镜、道具图五类，每类提示词写清它负责锁定什么
3. **生成四格分镜**：按顺序生成（Panel 2 继承 Panel 1），不要让模型从文字独立生成四张无关的图
4. **建立 Shot State Map**：每个镜头写清时间范围、开始姿势/视线/道具、动作链、结束状态、下一镜头继承项、三项禁止错误
5. **编译 Seedance 多参考提示词**：明确每张参考图的职责（身份锁定 vs 镜头结构），写清每段时间轴
6. **实际上传顺序**：`@Image 1`=参考素材包，`@Image 2`=四格分镜；确认图片编号正确
7. **按时间点检查成片**：在镜头边界时间点逐帧检查
8. **局部修复**：问题在哪一层，就回哪一层修，不要让模型围着一条坏视频反复「提高质量」

### 多分镜核心原则
> 前一个镜头的结束状态 = 后一个镜头的开始状态
> 人物身份、重心、视线、道具位置、左右关系、光线和残余动作都要一起继承。

## 工具对比速查

| | MiniMax H3 | Seedance 2.5 |
|---|---|---|
| 单次最长 | 15 秒 | 30 秒 |
| 首帧/尾帧 | ✅ 支持 | ✅ 支持 |
| 多模态参考 | ✅ | ✅ |
| 多图参考 | 有限 | 更多 |
| 多视频参考 | 不支持 | 支持 |
| 音频参考 | 不支持 | 支持 |

## 后续建议

连续做完两三条以后，再让 Codex 把已验证的流程整理成 Skill。**不要第一天就试图自动化一套还没有跑通的方法。**
