## 0. 全局固定人设（新建对话第一条先发）

```
你是国内双一流【填写你的专业】高校青年研究员，精通本科、硕士毕业论文写作规范。
严格遵循以下规则：
1. 严禁编造文献、调研数据、案例；信息不足直接提示我补充素材，不得自行杜撰内容；
2. 使用标准中文学术书面语，杜绝空话、网络用语、口语；
3. 长期记住全文框架，保障前后章节逻辑统一，观点不自相矛盾；
4. 段落过渡自然，层级清晰，符合国内高校论文评审要求；
5. 需要引用地方预留[序号]，禁止凭空生成参考文献。
后续全部回答严格遵守约束。
```

## 第一部分：前期筹备指令

### 1. 选题优化指令

**Prompt：**
```
我的专业：【】，初步研究想法：【粘贴选题思路】

任务：
1. 判断选题范围偏大/偏小/适中，分析可行性；
2. 输出3组选题：稳妥标准版、聚焦创新版、拓展深化版；
3. 分别说明每个选题：研究优势、写作难点、文献获取难度；
4. 挖掘领域核心研究问题，寻找论文创新切入点。
```

### 2. 开题报告生成指令

**Prompt：**
```
论文题目：《______》
论文类型：本科毕业论文 / 硕士学位论文

生成标准开题报告，包含模块：
一、研究背景与意义（理论意义、现实意义分开撰写）
二、国内外研究现状与简要评述
三、研究内容、论文框架、文字技术路线
四、研究方法、数据来源说明
五、研究重点与难点
六、论文创新点
七、分周期研究进度安排
八、预期研究成果
九、核心参考文献方向

要求内容详实落地，规避空洞套话。
```

### 3. 完整三级论文提纲指令

**Prompt：**
```
论文拟定题目：《 》
论文类型：本科毕业论文／硕士学位论文

输出标准毕业论文三级完整目录。
目录结构：摘要、关键词、绪论、文献综述、理论基础、现状分析、问题/实证分析、对策建议、结论与展望、参考文献、致谢。

要求：
1. 在每一个三级标题后标注本段写作核心要点；
2. 章节逻辑闭环，论点前后呼应，内容无重复；
3. 标题务实，拒绝空泛标题；
4. 提纲完成后，单独列出3处容易内容空洞的风险点，附带修改方案。
```
