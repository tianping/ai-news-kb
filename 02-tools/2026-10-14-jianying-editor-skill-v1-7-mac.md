## 概述

一句话需求 → Agent 把配音、字幕、配乐、转场全部排进**剪映时间轴**，打开剪映直接微调、导出。作者实测 12 秒成片草稿不到 2 分钟（手动起步 15 分钟）。v1.7.0（2026-09-11）的意义是 **Mac 用户转正**：旧版在 Mac 上生成的草稿常报"媒体丢失"，新版把素材全部自包含进草稿目录。

- 适配：WorkBuddy、Claude Code、Cursor、Trae 等 Agent 编辑器
- 仅支持**国内版桌面剪映专业版**（不支持国际版 CapCut、手机端）
- 原理：它不是剪辑软件也不是插件——剪映草稿本质是描述时间轴的数据文件，skill 按剪映格式生成这份文件放进草稿目录

## 一句话变草稿的五步

以"写一段口播文案，配男声和字幕，再找个不吵的 BGM"为例：
1. **拆句**：按标点拆成逐句
2. **配音**：逐句调用剪映自带音色库合成（日志 `SAMI Success` = 剪映官方语音服务返回）
3. **对齐字幕**：用每句配音的**真实音频时长**反推字幕起止，而非按字数估算
4. **分轨**：配音、字幕、标题各走各的轨道
5. **暂存素材**：音频、音乐统一复制进草稿目录（v1.7 修复的核心，草稿拷到别的机器也不丢）

实测结果：12 秒竖屏片，8 句配音全部成功，8 句字幕对齐误差为零，BGM 从剪映云端曲库下载、音量自动压到 35%，一次保存成功。

## 十项能力（Mac 可跑九项）

文案成片；按名字搜素材库并应用滤镜/转场/特效；关键帧运镜；录屏并自动给鼠标点击处加变焦和红圈；网页动效录成视频素材；影视解说自动生成分镜等。可调素材库：场景特效 1,097、滤镜 972、云端音乐 616、转场 433、音色 163、入场/出场动画 155/124；收藏的音乐和样式可同步为可调用资源。

**唯一 Mac 缺口**：一键导出 MP4 只支持 Windows（模拟鼠标点击，剪映 5.9 版最稳），Mac 需在剪映里手动点导出。

## 安装（交给 Agent）

把这段话发给能操作电脑的 Agent：

> 帮我安装 GitHub 上的 jianying-editor 技能：仓库地址是 github.com/luoluoluo22/jianying-editor-skill。请把仓库放到我项目目录的 skills 文件夹下，装好它需要的 Python 依赖（Windows 记得带上界面自动化那个包，Mac 上跳过它），再把网页录制功能需要的浏览器内核装好。装完运行它自带的诊断脚本，把剪映草稿目录、依赖状态和测试结果告诉我。

更新时让 Agent 拉一遍最新代码即可。

## 三个常见坑

1. **字幕和标题挤在同一轨** → 报"片段重叠"；标题单独开一条轨。
2. **下载的音乐找不到** → 云端缓存目录按"技能安装位置往上推三层"计算，装得深时可能落在用户根目录，找 `cloud_cache` 文件夹。
3. **草稿生成了剪映里看不见** → 剪映不实时刷新，重启剪映或点进一个旧草稿再退出。

## 短板

- 不替代剪映：渲染、预览、导出仍由剪映完成，它只搭时间轴
- Mac 不能自动导出
- 依赖剪映实时处理的功能调不动：智能抠图、美颜、语音识别字幕
- 剪映内置"一键成片""图文成片"没有开放入口
- 不支持国际版与手机端；需要 Python 环境
