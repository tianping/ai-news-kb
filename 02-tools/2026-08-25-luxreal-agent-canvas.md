## 核心定位：Agent 起稿 + 自由画布精修

AI 视频平台的两大流派：**Agent** 适合从 0 到 70（剧本/角色/场景/初版镜头很快出来），**画布** 有掌控感（移动人物、换机位、单独改节点，不用整段重生成）。LuxReal 把两者接起来：流程式 Agent 快速起稿 → 初稿成型后一键进入自由画布精修，原有资产和流程全部保留。

## 工作流实录（《怪兽的毕业考试》：实习怪兽咕噜帮小孩赶走噩梦黑魇）

1. **项目配置**：画风、生成模型、分辨率、画幅、时长可调，可配置 Agent Skill
2. **剧本分析**：上传剧本后 Agent 自动提取角色、场景、道具；角色在不同剧情阶段的状态一并考虑；道具以独立资产生成供分镜调用。约 5 分钟把一段文字变成可用资产
3. **叙事单元拆分**：Agent 按剧情推进自动拆分
4. **3D 片场**（关键差异点）：场景资产可转成完整 **3D 场景**——床、窗帘、书柜有相对位置，相机可进入房间任意找角度；可上传人物模型绑定角色、摆站位定动作
   - 痛点：传统 2D 场景图缺乏 3D 空间表达能力，切机位后人物位置/朝向/空间关系容易变，推拉摇移更难控
   - 3D 片场解决「这场戏人物怎么站、镜头从哪拍」，多人物同场戏的前后镜头站位能接上
5. **智能镜头动态预览**（第二个关键差异点）：
   - 传统做法：Image2 生成九宫格关键帧 → 参考生成视频。九宫格只约束几个独立画面，人物移动、镜头推进、动作衔接全靠 AI 推断，容易跑偏
   - LuxReal：先用智能镜头生成一段**动态预览**，再从中截取关键帧。所有参考图来自同一段连续视频，人物状态、空间关系、镜头节奏天然一致
   - 一句话：九宫格是先有关键画面让 AI 补剧情；智能镜像是先把剧情跑通再提关键帧
6. **节点式精修**：每个叙事单元/画面/视频都是独立节点，哪个镜头有问题回对应节点调，不用全部重跑
7. **成片 + 团队协作**：多人共同编辑项目、共享资产和 Skill，负责人可分配并查看积分消耗
