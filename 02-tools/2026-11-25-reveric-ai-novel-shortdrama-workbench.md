## 一句话

把"小说 → 剧本 → 分镜 → 生图 → 视频 → 剪辑"六步收进一个桌面应用，**整部作品就是智能体的工作区**：你说"写第三章"，它自己去查前两章、关系图谱、埋过的伏笔，不用把设定一段段贴进对话框。

## 基本信息

- 作者 looplj，此前做过 Go 写的 AI 网关 AxonHub（约 5400 star）
- 2026-10-22 建仓，AGPLv3
- Flutter 写的，macOS / Windows / Android 都能跑
- **数据全存本地 SQLite**
- 主分支就叫 `unstable`，项目仍在早期

## 五个模块

| 模块 | 干什么 |
|---|---|
| 小说编辑器 | 管设定库：人物、势力、伏笔、地图互相关联；写完一章可让 AI 提取关键事实、核验前后连续性（防吃书） |
| 剧本编辑器 | 按影视行业格式来，场次、对白、转场；左边原著右边剧本 |
| 无限画布 | 分镜段落、定妆照、提示词铺成节点，镜头上下游引用一眼看清 |
| 3D 导演台 | 摆角色站位、设特写和正反打机位、规划运镜，按时间轴预演整场戏 |
| 多轨剪辑台 | 六轨时间线（视频/叠加/对白/音效/音乐/字幕），剪刃分割、波纹删除，直接导出成片 |

智能体在每一步都能直接上手，不是只在侧边栏聊天。

## 上手

1. Releases 页下安装包；桌面端拖装，Android 8.0+ 装 apk
2. 设置里填模型 API Key：OpenAI、Claude、Gemini、DeepSeek、智谱、Kimi、即梦、可灵都接，自建 Ollama 网关也行
3. 新建作品，导入 TXT 原稿或让 AI 生成开篇设定
4. 开始写

自己编译：
```bash
git clone https://github.com/looplj/reveric.git
cd reveric && make deps && make codegen
make run-macos
```

## 比对话框强在哪

- **长期规则**：文风、视角、禁忌写法可以写成规则让它长期遵守，不用每次重申
- **可装技能**扩展能力
- **自动检索上下文**：前文、设定、伏笔由它自己去查，而不是你手动喂 prompt

## 点评

- 和库里 OpenMontage 的差别：OpenMontage 是给 AI 编程助手用的流水线知识包，没有界面；Reveric 是有完整 GUI 的桌面应用，自带编辑器、画布、导演台和剪辑台，适合不想在终端里干活的创作者
- 真正有意思的设计是"作品即工作区"——把设定库、关系图谱、伏笔做成结构化数据供 AI 检索，这比"把世界观贴进对话框"根本性地好用，也是长篇创作最痛的点
- 3D 导演台 + 六轨剪辑台放在一个开源项目里算野心很大，但越早期的项目这类重模块越可能只是雏形，建议先下 Release 跑一遍再决定投入
