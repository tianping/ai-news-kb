## 对生信从业者的影响（原文观点）

- 过去大量时间消耗在写脚本、调流程、批量处理组学数据
- Agent 可自主调用工具、迭代纠错、产出分析代码，基础数据处理工作会被大幅替代
- 未来生信人员的核心竞争力：
  - 懂得驾驭 Agent 工具
  - 聚焦科学问题设计、实验方案权衡
  - 对 AI 输出做严格甄别
- 人机协同将成为主流；生信人才需强化生物学认知、弱化纯脚本搬砖能力，向"AI + 生物问题解读"复合型方向转型
