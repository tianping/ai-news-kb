## 概述
OpenClaw 9月5日发布大版本更新，官方更新日志一万一千多行。本期梳理最值得感知的六件事，核心主线：把 agent 从「关在终端里的工具」变成能进团队、进会议、跟你并排看同一个网页的常驻角色。已知开源 agent 网关里活跃度最高档：单版 4,179 个 PR、64 次直接提交、502 个贡献账号。截图用虚构发布团队和样例对话，别当真。金额、机制对着官方 changelog 核过源。

## 六件最值得感知的事

### 1. 原子更新（升级不再赌人品）
- 流程三步：在当前 Gateway 不动的情况下，拿配置的私有副本验证新版本 → 验证通过切换 → 切换完再验一遍。任何一步不对，数据兼容前提下可回退到旧版。
- 唯一提醒：升级前必须先备份，回滚救不了数据库迁移——这版改了会话数据表。

### 2. 插件即装即用，不用重启
- 装或重载插件，命令行一条或在授权的聊天里发指令，装完立刻生效。
- 挂多个集成、跑长任务的人很实在，不用再挑深夜重启试插件。

### 3. 会话分享，多人进同一个窗口
- 共享会话可多人同时在里面干活。
- 打字时出现浅灰色气泡显示「Typing · not sent」或各自的输入点。
- 临时预览只在你「正在输入」时存在，发出去前不进模型上下文，不会被记进会话。

### 4. GPT Live 进会议和通话
- 在支持的 Meet、Teams、Zoom 会议里可以开口说话，GPT Live 实时回话，也能在会议中随时切到咨询 OpenClaw agent。
- 电话场景同样支持流式交互。
- 需要在对应设置里显式选择 Live，不是默认开。Talk 里没有固定会话会自动按配的 OpenAI 权限选 Live，已固定的模型不动。

### 5. 浏览器页面跟 agent 同框
- 浏览器页签直接出现在聊天面板头部，给页面腾更多空间。
- agent 看可访问性快照，跟你在同一张页面对齐要做什么。
- 比「丢链接给它、它自己打开」更自然：左边你看着网页，右边 agent 对着同一页面干活。

### 6. 对话归档，历史不丢也不占地方
- 长时间不用的旧对话被压缩归档，随时重新打开，恢复完整历史、重新可搜索。
- 设置里能看到每个 agent 的会话各占多少存储，可手动触发归档。
- 冷存储默认关闭，不活跃满 30 天才会归档，间隔可调。
- 每天大量上下文的 agent，这条能明显省空间。

## 主线总结
六条并排放在一起的主线：agent 不再是一个人对着终端的工具，而是有人跟你共享同一个页面、同一通会议的那一席。会话分享、GPT Live 进会议、浏览器同框——三条是同一方向。
