## 数据规模

- **2234 个**独立三维结构
- **15 个人体系统**（骨骼、肌肉、消化、呼吸等）
- **3432 个**可搜索的解剖学术语
- 数据源：**BodyParts3D 4.0 成人男性**参考人体数据

## 核心玩法

- 完整 3D 人体：鼠标旋转、滚轮缩放，正面/背面/侧面
- 左侧系统开关：只看骨头就把其它系统全关掉
- 点选结构 → 单独保留（隔离），不用隔着其它结构猜位置
- **爆炸图（Explode Anatomy）**：拖动滑杆，骨骼/器官/肌肉从原位置散开，像减速机零件表；只开某系统就只拆某系统
- 搜索：输器官/骨骼/解剖术语直接定位 → 点一下 → 单独看（零学习成本）
- 桌面端/移动端展开布局做了适配（2000+ 结构散开不挤成一坨）

## 本地运行（Node.js 22.13+）

```bash
git clone https://github.com/ashemag/human-atlas.git
cd human-atlas
npm ci
npm run dev        # http://localhost:3016
npm run build      # 静态文件在 dist/，任意静态服务器可跑
```

不想折腾直接开在线版：https://human-atlas-seven.vercel.app/
