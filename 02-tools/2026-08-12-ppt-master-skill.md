# ppt-master Skill：丢进原材料，生成能讲能改的真 PPT

> 来源：[分享神级 skills：ppt-master](https://mp.weixin.qq.com/s/3MWuLXKzNaAk__Ns0xQinA) · 2026-08-12

## 概述

ppt-master 是一个面向演示文稿生产的 Claude Code Skill。不是生成一组漂亮图片，而是把原材料重新组织成结构清楚、叙事完整、版式统一、后续可编辑的 PowerPoint 文件。

## 核心理念

### "能不能讲" 比 "好不好看" 重要

多数 AI PPT 工具跳过了最关键的一步：判断这份 PPT 是拿来干什么的。

同一份材料，给老板讲、给客户讲、给团队讲、给投资人讲，结构完全不一样：
- 老板关心结论和风险
- 客户关心价值和落地路径
- 团队关心任务拆解和责任边界
- 投资人关心趋势、壁垒、增长和回报

ppt-master 先判断演示场景（10分钟汇报还是40分钟培训？让对方拍板还是团队对齐？），再据此组织内容主线。

### 真 PPT = 回头还能改

AI 生成的 PPT 常见问题：输出只是一组图片，每次修改都要重新生成。

真 PPT 的要求：标题、文本框、形状、图表、备注、页面顺序都可继续编辑。能删页、换文字、调颜色、改数据、插新图。因为好 PPT 是讲一遍、改一遍、再讲一遍慢慢磨出来的。

### 第一页是判断题，不是封面

决定 PPT 成败的不是封面，而是结构。ppt-master 先判断叙事框架：
- 问题 → 原因 → 方案 → 行动
- 现状 → 判断 → 机会 → 路径
- 过去做了什么 → 现在卡在哪里 → 下一步怎么打
- 用户痛点 → 产品能力 → 交付案例 → 商业价值

结构选错，后面每一页都跟着别扭。

### 逼你少放废话

PPT 是给讲的人铺路的，不是让观众自己读完的。一页只回答一个核心问题。ppt-master 帮你做取舍：有些放正文，有些放备注，有些做成图表，有些直接删掉。

## 适合的四类场景

1. **临时汇报**：材料已有但结构没成型，需快速整理出能讲的版本
2. **项目复盘**：把结果、问题、原因、经验和下一步拆清楚，避免流水账
3. **客户方案**：讲清业务关联、解决问题、落地路径、风险，而非堆功能清单
4. **知识分享/培训**：长文章/课程稿/内部文档转 PPT，需拆成节奏、例子、图解和讲述顺序

## 推荐使用方式

不要只说"用 ppt-master 根据这些材料生成一份 PPT"，太宽了。更好方式是把演示目标交代清楚：

```
用 ppt-master 把下面这些材料整理成一份 12 页左右的项目复盘 PPT。
听众是业务负责人和产品团队。
目标不是邀功，而是讲清楚这次项目为什么延期、我们学到了什么、下一阶段怎么避免。
需要输出可编辑 PPT，并保留演讲备注。
```

```
用 ppt-master 做一份客户方案 PPT。
客户是制造业集团的信息化负责人。
材料包括产品介绍、竞品对比、报价说明和两个案例。
请先提炼一条 15 分钟能讲完的销售主线，再生成可编辑 PPT。
重点放在业务价值和落地路径，不要堆功能清单。
```

## Skill vs 普通 Prompt

普通 prompt 像一次性提醒，skill 像长期有效的作业规程。Claude Code 遇到 PPT 任务时，自动进入流程：读材料 → 判断场景 → 提炼主线 → 拆页 → 设计版式 → 生成文件 → 检查可讲/可改/可交付。

不用每次提醒：不要做成图片、不要照搬原文、不要每页塞满 bullet、不要只有好看没有逻辑、不要忘了给讲的人留备注。

## 更大启发

PPT 不只是文件格式，是组织里的协作界面。它连接材料、判断、沟通、决策和行动。AI 做 PPT 不能只追求"更快生成页面"，而是把一堆材料变成一次有效沟通。
