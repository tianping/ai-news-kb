## 概述

WorkBuddy 新增浏览器操控（browser use）功能：直接在用户**已登录**的浏览器里打开网页、点击、翻看、填写表单。它在独立的「WorkBuddy 标签页组」中工作，有自己的鼠标光标，不抢用户鼠标、不占当前窗口——它干它的，你干你的。配合手机端可远程给电脑派活。作者认为这补齐了此前 Codex 的亮点能力。

实践分享同步在《WorkBuddy 实战蓝皮书》：https://github.com/AlephAITech/WorkBuddyGuide

## 四个实战场景

### 1. 读官方文档，整理玩法
把官方文档站发给 WorkBuddy，它自行拆成四步：
1. 打开文档站，梳理目录结构（多少篇、讲什么）
2. 按主题给案例分类（浏览器自动化 / 办公提效 / 数据整理…）
3. 逐篇精读，提炼玩法、前置条件、解决的问题
4. 汇总成学习地图（新手从哪入手、按什么顺序学）

过程中边翻边在对话里同步进度，不到 10 分钟完成。

### 2. 填报销（企业 OA）
先手动登录 OA，再把报销信息与要求发给它：找到报销申请 → 核对字段（金额、事由、日期）→ 填表。**提交前会先列出填好的信息让用户确认**，再提交——涉及写操作时的安全设计。

### 3. 扮演小白体验网站（可用性测试）
让它以零基础用户身份体验作者升级后的 CodexGuide 网站：逛首页→顺导航找教程→跟着走一遍；每条路径记录问题、按严重程度排序；还会回首页换路径复验问题是否普遍存在。输出体验报告 + 修改建议 + 页面设计方案。

### 4. 手机派活：复盘 B 站评论
在手机小程序/App 选定某台已登录设备派任务（可多设备同时派活），对话和文件跨端同步。几分钟产出复盘：转化比、评论活跃度、情绪态度、高频话题归类、典型留言、后续视频调整建议。

## 开启方法

1. WorkBuddy 客户端更新到最新版
2. 设置 → 智能体 → 前往安装浏览器扩展（支持 Chrome / Edge / QQ 浏览器）
3. 回到设置页打开「允许 WorkBuddy 控制浏览器」
4. 自然语言下需求即可

## 注意事项

- 操作的是你已登录的网站，遇到验证码、滑块、页面加载慢、网站改版时可能需要人工接手或重试
- 别急着把所有事都交给它，提交类操作留意确认环节
