## 概述

这是一篇面向程序员的 Blender 入门：Blender 不只是「图像混合」，而是覆盖建模、材质、灯光、动画、渲染、合成和剪辑的整套三维内容制作环境。程序员最该关注的是它的 **Python 接口（bpy）和命令行后台运行**，许多视觉操作因此能写成可重复执行的程序。AI Agent 擅长写脚本、调工具，正好可以把三维制作接进开发者熟悉的自动化流程。作者措辞克制，明确区分了「已有能力」和「未来判断」。

## 关键内容

### 用一个杯子看懂制作流程

1. **建模**：网格由顶点、边、面构成；雕刻工具可以像捏黏土一样调整形状
2. **材质、灯光、相机**：同一个形状，换陶瓷或金属材质效果完全不同；灯光决定明暗阴影，相机决定视角和画面范围
3. **动画**：设关键帧，软件自动插值中间状态；角色动画还需要骨骼绑定
4. **渲染**：Cycles 是路径追踪，追求真实光照；EEVEE 是实时渲染，适合快速预览和部分成片
5. **合成与剪辑**：组合渲染结果、调色、加遮罩；时间线上可以剪辑视频

### 怎么判断它的成熟度

- 历史可追溯到 1994 年，2002 年开源
- Ubisoft 2019 年加入 Blender Development Fund，旗下动画工作室用它制作，并派开发者参与
- Blender Studio 的开放电影项目：工具进入实际制作，制作中的问题又反过来推动工具发展
- 注意：`github.com/blender/blender` 只是官方镜像，主要协作和问题跟踪在 Blender 自己的平台上，只看 GitHub 判断活跃度并不完整
- 仓库结构：`source/` 主源码、`scripts/` Python 脚本、`intern/` 与 `extern/` 内部组件和外部依赖、`build_files/` 构建。做自动化不需要先读懂源码

### 程序员的切入点：规则明确、需要重复执行的任务

- **批量产品图**：固定相机和灯光，只替换颜色、材质、标签
- **空间关系演示**：设备内部结构、零件拆装、相机绕物体观察。只讲请求流转或服务依赖的话，二维图更直接
- **三维资产处理**：批量导入、统一命名、检查尺寸、调整朝向、导出格式，本质是数据整理
- **按规则生成场景**：按间距排货架、按参数生成窗户、沿路径放置重复物体。Geometry Nodes（几何节点）把几何操作连成可调的数据流，程序员会觉得这种思路很熟悉

### Agent 怎样接入 Blender

后台运行脚本的命令：

```bash
blender --background --python-exit-code 1 --python build_scene.py
```

- `--background`：不打开界面
- `--python-exit-code 1`：脚本抛出 Python 异常时返回非零退出码，方便外部程序识别失败。参数按顺序处理，所以要放在 `--python` 之前
- `bpy` 可以访问场景、物体等数据。注意区分**直接改数据**和**调用界面操作**：部分 `bpy.ops` 依赖当前选择、模式或编辑器上下文，照搬界面操作在后台可能失败
- Agent 的价值不只是代替人点按钮，而是拆解需求、写脚本、执行、读报错、再调整。接入方式可以是本地进程，**不一定需要额外的 MCP 插件**
- **检查回路比一次性生成脚本更重要**：脚本跑完只说明执行结束了
  - 程序层面：模型是否存在、相机是否设置、文件是否输出、帧数是否正确
  - 视觉层面：物体是否被裁掉、把手是否穿进杯身、反光是否盖住细节、运动是否自然。需要看实际画面；就算用视觉模型检查，也要定明确标准，重要结果由人确认

### AI 降低门槛，但不替你判断

- 空间和视觉知识：焦距、比例、材质粗糙度、灯光位置。不懂这些，就说不清哪里不对
- 资产质量：复杂人物需要合理的网格、贴图、骨骼、动作；正面截图好看，换角度或动起来可能就露馅
- 计算成本：Agent 只是让你更快地发出渲染任务，渲染照样耗时、耗内存和显存。先用低分辨率、少量帧验证构图和动作，再提高输出质量
- 如果只是文字讲解、流程图、简单二维动效，SVG、HTML 或现成视频工具更省事。需要立体结构、多角度、真实光照或可复用三维资产时，Blender 才值得投入

### 第一次尝试：最小闭环

1. 在界面里手动完成一次：建一个简单物体，设相机和灯光，输出一张图
2. 让 Agent 把同样的步骤改写成 Python 脚本
3. 改一个明确参数（颜色或相机角度）再跑一次，对比两张图
4. 进阶：批量输出几种颜色，或加一个简单旋转动画
5. 保留场景文件、脚本、Blender 版本和输出设置，以后出现差异时方便定位原因
6. 起步阶段不用克隆源码或自己编译
