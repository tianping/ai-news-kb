# music-dance-video Skill：给Codex一首歌，自动生成舞蹈视频

> 来源：微信公众号文章 · 2026-08-11 · [原文链接](https://mp.weixin.qq.com/s/2dPguQOIVtI4y-M36W_F1A)

## 概述

作者（维克兹）开源了一个 `music-dance-video` Skill，让 Codex 从一首歌开始，自动完成音乐理解、片段选择、人物设计、舞蹈规划、视频生成和音乐合成的全流程，最终输出带原音乐的完整舞蹈视频。

- **项目地址**：GitHub 开源
- **版本**：1.0（一天完成）
- **定位**：十几秒到几十秒的音乐舞蹈短片

## 与传统 AI 视频生成的区别

传统做法：先想画面 → 写提示词 → AI 生成视频

音乐舞蹈视频起点不同：**起点是一首歌**，需要先理解音乐再设计画面。

## 六步工作流

### 1. 选择视频模型
- Codex 先让用户选择视频模型厂商
- 指导用户在本地配置对应 API（不发送到聊天中）
- 不同模型支持的时长、比例、参考素材和费用不同

### 2. 理解歌曲
- Codex 根据歌曲名称查找公开资料，了解主题、情绪和表达方向
- 网上找不到可靠资料时，回到音乐本身分析节奏、能量、段落变化和自然切点
- 据此推荐画风、舞蹈类型和场景

### 3. 选择音乐范围
- 优先让用户自己选择片段（"选取xx:xx到xx:xx"）
- 也可以让 Codex 判断高潮部分后由用户选择
- 支持整首歌生成（但调用次数多，钱包要够厚）

### 4. 确定比例和统一画风
- Codex 确认视频比例（不同平台提供不同比例选择）
- 结合歌曲方向给出几个视觉方案：写实电影感 / 国风动漫 / 现代舞台 / 东方园林
- 用户选定后，整理人物外观、服装、场景、主色、光线和镜头语言为统一风格规则
- 后续所有片段沿用同一套规则，减少人物和画风漂移
- 支持用户提供参考图，或根据确定画风生成虚构角色

### 5. 规划舞蹈和切镜
- 根据音乐强弱安排舞蹈动作、情绪推进和镜头节奏
- 平缓部分用克制的动作，强烈节拍放大动作
- 多段生成时寻找适合切换的节拍或段落位置
- 各段复用同一套人物和画风设定
- **不足**：不能保证专业编舞级逐帧卡点，可能有动作和人物细节漂移

### 6. 付费前确认，生成后交付
- 正式调用前给出最终简报：模型、音乐片段、视频比例、画风、参考素材、预计调用次数
- 用户确认后才提交视频任务
- 生成完成后下载结果，把原音乐片段重新合入视频
- 检查时长、画面和音轨是否正常

## 实测案例

### 案例1：《泡沫》——24秒国风动漫版
- 2D国风少女，雨幕和泡沫采用水墨感视觉元素
- 中间安排一次主动转场，前后两段变化类似设计过的切镜

### 案例2：《多远都要在一起》——中国古风少女版
- Codex 自主分析歌曲，从推荐范围选取15秒
- 竹林园景、古风少女、古典舞与现代节奏动作融合

## 核心价值

> AI 真正有价值的地方，不是帮你完成一次任务，而是帮你建立一套可以不断复用的能力。

- 把零散操作整理成可复用流程
- 换一首歌只需做几个关键选择，重复的分析/执行/检查交给 Codex
- 人负责创造（方向决策），AI 负责执行（分析、调用、检查）

## 局限性

- 1.0 版本，一天完成
- 适合十几秒到几十秒短片，更长效果不够好
- 无法保证逐帧卡点
- 生成模型可能出现动作和人物细节漂移
