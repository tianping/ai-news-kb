## 概述

解决「微信里看到的东西怎么存进 Obsidian」：微信小程序当收件箱，云端（腾讯 CloudBase）临时中转，Obsidian 插件自动拉取并生成 Markdown 笔记。链路：**微信小程序收 → CloudBase 中转 → Obsidian 落地**。

## 安装（两部分）

1. **微信端**：小程序搜「obsidian内容同步助手」→ 底部菜单「绑定Obsidian」→ 弹出电脑绑定码，复制。
2. **Obsidian 电脑端**：设置 →「第三方插件」搜索「WeChat Inbox Sync」安装 → 粘贴绑定码完成绑定。

## 使用体验

- 文本内容保存方便；把公众号文章链接粘贴进小程序，电脑端同步后生成一篇 Markdown 笔记，标题即文章名。
- **收费**：视频内容同步需 Pro 会员；免费版每日 5 次（看广告可加次数）；Pro 有 7 天免费试用。
- **云端只临时存放**，同步完即清理；长时间不开 Obsidian，云端记录可能被删——依赖定期打开电脑。
- 作者结论：解决的是真实问题，但能否成为日常习惯待观察；下一步试 git 同步。
