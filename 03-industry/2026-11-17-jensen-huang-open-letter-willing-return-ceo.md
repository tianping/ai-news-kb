# 黄仁勋辞职后首次公开发声：在 X 发公开信认错，董事会认为合适就愿回任 CEO（新智元）

> 来源：[老黄辞职后首度喊话董事会，愿重返英伟达当CEO！](https://mp.weixin.qq.com/s/g0_ZiSKJ4hOx_fWxQe7xJg) · 新智元 · 编辑：马可 摩西 · 2026-11-17
> 原始出处：[黄仁勋 X 帖子](https://x.com/JensenHuang/status/2122726005219737649)
> 分类：03-industry（黄仁勋事件后续）

## 一句话

辞职后沉默了近两周，黄仁勋 11-17 在 X 上发了一封公开信：承认"在个人生活中犯下了严重错误"，说会全力配合董事会的独立调查；还表示**如果董事会认定他回来对股东、员工和公司最有利，他愿意重新出任 CEO**。他的 X 资料已经去掉英伟达认证和 CEO 头衔，只留下"Founder of NVIDIA"。

## 公开信要点

1. **致谢**：感谢朋友、同行和陌生网友对他和家人的善意。
2. **认错**："我没有达到英伟达对每一个人的要求，也在个人生活中犯下了严重错误。我给董事会带来了麻烦，对此深感懊悔。"
3. **担责**："我的错误，我完全承担。我会全力配合董事会的独立调查。"
4. **愿意回来**：他说离开后员工、投资者、合作伙伴和客户都在呼吁他回来，很多人现在还直接联系他；"英伟达是一代人才出一家的公司"，只要董事会认定他回来最有利，他会很荣幸地回来当 CEO。
5. **写给家人**："我爱你们，余生我都会努力配得上你们的爱。"

## 时间线（10 天）

| 日期 | 事件 |
|---|---|
| 11-08 | 给全体员工发信认错道歉；董事会启动独立调查，当时仍表示对他的领导有信心 |
| 11-12 | 宣布辞去总裁、CEO 和董事职务，即刻生效；CFO Colette Kress 任临时 CEO，Harvey Jones 成为英伟达史上首位董事长 |
| 之后 | 英伟达内网上千条留言要求请回老黄 |
| 11-13 | 马斯克在 X 上说自己签了「Stand with Jensen」联署，要求调查期间让他复职 |
| 至今 | 联署签名近 20 万（原文小标题写 18 万），Travis Kalanick、Tim Sweeney 等在列 |
| 11-17 | X 公开信：认错，并表态愿意回任 CEO |

## 看点

- 公开信是**有条件的表态**：要等董事会做决定，也要等独立调查的结果，他本人并没有提出复职要求。
- 英伟达创立 33 年，CEO 一直是黄仁勋，直到上周。他能不能回去，取决于董事会。
- 公开信发出时离当天盘后的三季度财报只有几个小时（见下方关联笔记）。
