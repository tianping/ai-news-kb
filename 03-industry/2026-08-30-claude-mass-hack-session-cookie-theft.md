# 突发！Claude遭大规模盗号，大批用户被强制注销

> 来源：新智元 · 2026-08-30
> 链接：https://mp.weixin.qq.com/s/imCcRWWi51HyU0d0zoY3ww

## 事件概要

Anthropic 突发大规模账号安全事件：大批 Claude 用户被强制注销登录，绑定的信用卡/Visa/Mastercard 被官方紧急清空。这不是官方作妖，而是在"拔网线救人"——一场针对 AI 用户的隐秘猎杀行动已经爆发，黑客不再盯银行卡，而是偷 AI 算力。

## 攻击手法：偷 Session Cookie，绕过 2FA

黑客利用信息窃取木马从用户电脑盗取 Claude 的登录 Session（会话凭证），直接潜入账户疯狂消耗使用额度。

- **密码和 2FA 无效**：Session Cookie 相当于"VIP 通行卡"，黑客绕过前台直接偷通行卡，免密登录，绕过 2FA
- **仅仅改密码没用**：必须撤销所有活跃会话，否则攻击者继续骑在旧会话上

## 六大木马名单

**Windows：**
1. **Vidar** — 老牌窃密木马，搜刮浏览器密码、浏览历史、加密钱包密钥
2. **Lumma (LummaC2)** — 近期极其猖獗，Windows Defender 频繁报警拦截
3. **StealC** — 轻量级 MaaS，Lumma 熄火后主要接盘者，2026 年初仍属四大活跃家族
4. **RedLine** — 最老牌家族之一，2024年10月被荷兰警方与 FBI 端掉服务器
5. **Acreed** — 2月10日首次被观察到，头一周上传4000+条日志，很快超过 Raccoon/RedLine/Vidar/StealC

**Mac：**
6. **Atomic Stealer (AMOS)** — 专门针对 macOS 的窃密木马，通过破解软件/虚假应用更新潜入，直接卷走 Keychain 和浏览器 Cookie

## 入侵途径

Reddit 受害者承认下载了破解版游戏（俄罗斯破解游戏论坛 Steam Underground），木马伪装在破解文件中。攻击链：RenPy Loader → PavinLoader → Amatera Stealer。

## 黑产变现模式

1. **套壳共享收割机** — 上百个被盗 Session 集成到套壳网站，以"9.9元无限畅聊"卖给不知情用户，消耗原账号额度
2. **API 黑市白嫖** — 利用盗取的 Session 生成 API Key，接入中转 API 平台按 Token 计费卖给开发者，零成本100%利润
3. **不直接盗刷信用卡的原因** — 银行风控敏锐，异地大额盗刷立马冻结；而"偷算力"在法律和风控上仍处灰色地带

## 自查症状

- **薛定谔的额度**：没聊几句突然提示额度达上限
- **幽灵历史记录**：侧边栏出现没问过的问题（全英文代码请求等）
- **突然被要求重新登录**：平时直接打开，今天跳到登录页
- **钱包被清空**：Settings 里绑定的卡消失（官方救了你）

## 防御指南

1. **全网注销** — 登录所有核心账号，安全设置里"退出所有设备的登录"
2. **清理浏览器 Cookie** — 清除所有时间的"Cookie及其他网站数据"
3. **停止下载破解** — 不从非官方渠道下载破解版/绿色版软件
4. **重装系统** — 确定感染高危木马后，备份重要文件，物理清盘

## 趣闻：用 Claude 当杀毒软件

受害者用 Claude Opus 5 Max 开放全局无权限模式做杀毒：Opus 5 精准锁定病毒、逆向工程、停用并打包病毒尸体。攻击链与 Malwarebytes 2026年7月记录完全匹配。但网友提醒：LLM 不可完全信任，尤其系统底层被植入 Rootkit 时，最安全永远是物理清盘重装。
