# 天工"捂脸跑"夺冠：机器人自己想出来的跑姿

> 来源：[凤凰网科技 / IT之家、红星资本局](https://tech.ifeng.com/c/8vqEVRQntVu) · 2026-08-24

## 事件

第二届世界人形机器人运动会 8 月 22 日在国家速滑馆（冰丝带）开幕。400 米（小型组）决赛中，天工 Omni 以标志性的"捂脸跑"姿势完赛，并以 **45.66 秒**的成绩夺冠。

## 团队回应

天工 Omni 400 米小型组研发团队负责人、北京人形机器人创新中心运动控制算法专家韩刚赛后表示：

- **不是模仿人类**：并非找了个"小姑娘"去模仿跑姿，"捂脸跑"是天工 Omni **自己迭代出来的**。
- **仿真优化的产物**：机器人是在仿真环境里不断用数据迭代训练出来的。最初设计的是正常人百米跑步模式，但它在学习过程中"感觉""捂脸跑"比摆臂跑更舒服，于是自己选择了这种跑法。
- 相当于机器人**自主决定**了奔跑策略。

## 天工 Omni 规格

| 参数 | 数值 |
|------|------|
| 身高 | 1.35 m |
| 整机重量 | 39 kg |
| 定位场景 | 狭窄空间、应急救援、家庭服务 |
| 开放性 | 开放二次开发体系：关节、传感器、系统、运控 API |

## 点评

- "捂脸跑"是**强化学习/仿真优化涌现行为**的典型案例：算法在奖励驱动下找到人类直觉之外的局部最优解，类似早期 quadruped 机器人学到的"反直觉步态"。
- 对人形机器人行业而言，这再次说明运控的终点未必是"像人"，而是"稳定高效地完成任务"——拟人姿态只是审美偏好，不是性能指标。
- 北京人形机器人创新中心开放 API 生态的打法，意在复制安卓式的开发者飞轮。
