# 黄仁勋 129 亿美元买下 Hugging Face，AI 圈的 GitHub 改姓黄了

- **来源**: [微信公众号文章](https://mp.weixin.qq.com/s/bcIlum1RvNJol-SYj-igUQ)（新智元转引 SEC 8-K / 英伟达官方博客）
- **日期**: 2026-09-04
- **类型**: AI 行业并购 / 开源生态

## 交易概要

| 项目 | 数值 |
|------|------|
| 收购方 | NVIDIA（市值约 5.4 万亿美元） |
| 被收购方 | Hugging Face |
| 交易金额 | **129.303 亿美元**（英伟达史上最大整体收购） |
| 支付结构 | ~119 亿付原股东 + 最高 ~10 亿员工留任股权 |
| 预计交割 | **2027 年上半年** |
| SEC 文件 | 2026-09-03 提交 |

## 反转：从拒 5 亿到卖 129 亿

去年年底英伟达按 70 亿美元估值投资 5 亿美元拿少数股权，Clément 拒了——理由是"不想让股东行列出现一家独大的巨头"。

今年夏天 Clément 称"行星连珠了"，主动找黄仁勋谈收购。

转折原因：**Hugging Face 想做大但资源有限**
- 目标：开发者从 1800 万做到 1 亿（翻五倍）
- 靠订阅/融资撑不起这条基建
- 算力、基础设施、全球渠道——三样都不缺的公司只有英伟达

## 英伟达为什么要花 129 亿买一个不卖 GPU 的平台？

**买的是战略影响力，不是当期利润。**

英伟达已有：GPU + CUDA + DGX Cloud。唯独缺的环节是——**模型的发现、评测、下载、分发**。

买下 Hugging Face = 买下开源 AI 的**超级路由器**。

更深一层：对冲 Meta/OpenAI/微软自研芯片的风险
- 这几家是大客户又最想摆脱英伟达
- 开放模型繁荣 → 长尾企业自己微调推理 → 买卡不再只靠几个巨头
- 几百万开放模型跑在谁的卡上？分量不比一张巨头订单轻
- SEC 风险披露已写："开源模型开发/分发受监管限制，将实质影响英伟达业务"

## 承诺："算力中立"

三方口径一致：
- 开发者可选自己想要的模型、框架、云、推理服务商
- "英伟达算力不是在 HF 上开发或部署的前提"
- 多云、多加速器继续支持

但承诺**没有期限、没有独立治理机制、没有违约条款**。
交割后 HF 法律上归英伟达所有，"独立"只能理解为运营和技术选择层面的相对独立。

BlueRock CEO 大实话："技术手段会被用来制造竞争优势，这是商业常识，不是阴谋论。"

## 真正该盯的四个默认选项

1. **模型推荐排序**：会不会把英伟达优化版往前排？
2. **评测榜单硬件基准**：只剩 H 系列和 B 系列的数字？
3. **一键部署默认目标**：悄悄滑向 DGX Cloud？
4. **推理服务优先级**：用英伟达算力是否更便宜更快排队更短？

四个都不违反承诺，但每一个都可能让"不绑 N 卡"变成正确的空话。

## 对谁有利？

### 短期：利好
- 服务器宕机、下载慢、推理排队——这些让开发者头疼的痛点，有"能砸钱的东家"来填
- 英伟达承诺用基础设施/工程团队/全球网络补 HF 短板

### 长期：两类群体首当其冲

**第一类：不用 N 卡的开发者**
- transformers 等底层开源库过去绝对跨硬件（AMD/TPU 都能跑）
- 新模型首日 N 优化版可跑，其他硬件适配可能要等几周
- 开发者会用脚投票："哪张卡首日能跑就买哪张"
- "硬件中立最先崩塌的地方，往往藏在某个代码库的更新日志里"

**第二类：发布模型的厂商**
- 英伟达自称 HF 最大开放模型贡献者（500+ 模型、250+ 开放数据集）
- Nemotron 系列已发 500+ 模型
- **既当货架主人又当货架品牌**——Meta/Mistral 的模型还能上架，但摆哪层、贴不贴推荐标签由竞争对手说了算
- 这笔交易前从未有过的变数

## 核心判断

> "拥有开源智能的人确实会越来越多，只不过，Hugging Face 这条美国开源 AI 最宽阔的道路，几个月后就要改姓黄了。"
>
> "答案不在声明里，在 Hugging Face 的默认选项里。"
